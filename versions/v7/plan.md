_Source: `versions/v7/spec.md` (2026-10-23). Core plan: `Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R64 (main agent unlimited, already in code since `4614ced`: verify
only), R65 (`TestMainCancelLongTurn`, new), R66 (docs, already done: verify only), R67 (rewrite the
main-50 assertions of `scripts/verify/v5/T401.sh` and `T799.sh`), changed R6/R54, removed R6 part.

to the subagent limit 500 or `max_subagents`; the pre-existing `scripts/verify/v1/T403.sh` "HTTP
error shown" failure; edits to `versions/v1/`, `versions/v5/` spec/plan/task files.

## Architecture changes
- **internal/agent** loop (changed, already committed): `MaxIterations = 0` = unlimited for the main
  agent; `runLoop` loops `limit == 0 || i < limit`; `MaxSubagentIterations = 500` unchanged. The
  main turn ends only on a reply without tool calls, a provider error after R37 retries, or a cancel.
- Removed: error `iteration limit (50) reached` (main agent). `iteration limit (500) reached` stays.
- `Plan.md` architecture line of internal/agent and Risks updated accordingly; Commands unchanged.
