# T101: Two-row status area

Phase 1 · Model: sonnet: one TUI view rework with test adaptation · Depends-on: T000 · Covers: R15 (status, changed), R15 (removed slash token format)

## Brief
Replace the single status line under the input with two rows.

Files: `internal/tui/status.go`, `internal/tui/model.go` (layout constants / `View`), tests in
`internal/tui/status_test.go`, `internal/tui/model_test.go`, and any other existing test that
asserts the old one-line format (`grep -rn 'in 0 / out\|/ out \|StatusLine' internal/tui e2e`).

Behaviour:
- Row 1 (default colour): `<cwd> · <provider/model> · <effort> · <mode> (shift+tab to toggle)`,
  e.g. `/work/dir · fake/m1 · medium · manual (shift+tab to toggle)`. `model` is `no model` when
  none is configured; effort stays dimmed (existing `dimStyle`) when `ReasoningEnabled()` is false.
  Row 1 never contains token counts or `ctx`.
- Row 2 (whole row in `lipgloss.Color("244")`): `in N · out N · total N · ctx used[/limit]`, e.g.
  `in 100 · out 20 · total 120 · ctx 100/8000` (`ctx 0` without a limit). The old
  `in N / out N / total N` slash format is removed everywhere.
- Width: when row 1 is wider than the terminal, only the cwd is shortened from the left with a
  leading `…` (keep the existing `shortenLeft`); model, effort, mode and the hint are never
  dropped. Row 2 is not shortened.
- No `cost`, `price` or `$` in either row. All text from the session passes `m.redact`.
- API: add `func (m Model) StatusRows() (row1, row2 string)`; keep `StatusLine() string`, now
  returning `row1 + "\n" + row2` (e2e tests call it). `View()` ends with the two rows under the
  input box; set `statusRows = 2` so the total height stays the terminal height (the viewport
  shrinks by one line).
- Do not add colours to the mode word yet (another task does), but the hint text must already be
  exactly ` (shift+tab to toggle)` after the mode.

Tests (new, in `internal/tui/status_test.go`, all start with `TestStatus`):
- `TestStatusTwoRows`: fake provider response with `Usage{Prompt: 100, Completion: 20}`; after
  the turn, `StatusRows()` row 1 contains the start dir, `fake/m1`, `medium`, `manual`,
  `(shift+tab to toggle)` and none of `in `, `out `, `ctx`; row 2 contains `in 100`, `out 20`,
  `total 120`, `ctx`; `View()` ends with these two rows.
- `TestStatusRow2Color`: under `withColorProfile(t, termenv.ANSI256)` row 2 contains `38;5;244`.
- `TestStatusNarrowTwoRows`: width 60 with a long start dir: row 1 starts with `…`, still holds
  model, effort, mode and `(shift+tab to toggle)`, and `lipgloss.Width(row1) <= 60`.
- `TestStatusNoCostTwoRows`: neither row contains `cost`, `price` or `$` (case-insensitive).
Use the existing `newSessionModel(t, srv)` helper from `session_test.go` and
`providertest.New(...)`. Adapt the existing `TestStatus*` and `TestSkeleton*` tests to the new
format instead of deleting them.
