# T203: Turn clock and Thinking line

Phase 2 · Model: sonnet: new TUI state with an injectable clock and tick scheduling · Depends-on: T000 · Covers: R24, §5 (injectable clock)

## Brief
Add a turn clock and the live busy line. New file `internal/tui/turn.go`; changes in
`internal/tui/model.go` (`Options`, `New`, `Update`, `Command`, `apply`, `View`) and
`internal/tui/init.go`.

- `Options.Now func() time.Time` (nil → `time.Now`); `New` stores it in the existing `m.now`
  (Ctrl+C timing keeps using `m.now`).
- Turn state on the model: `turnActive bool`, `turnStart time.Time`, `turnOut0 int` (session
  `Tokens().Out` at submit), `openCalls int` (main-agent tool calls without result).
- `func (m *Model) startTurn() tea.Cmd`: called after every successful `sess.Submit` in
  `Command` and after a successful `sess.Init()` in `cmdInit`; sets the state and returns the
  tick command. `Command` / `cmdInit` return that command (so `Command` on a message now returns
  a non-nil `tea.Cmd`; adapt the `cmd != nil` assertion in `TestSendMessageStreams`).
- Tick: `type tickMsg time.Time`; the command is
  `tea.Tick(time.Second, func(t time.Time) tea.Msg { return tickMsg(t) })`. On `tickMsg`,
  `Update` returns the next tick only while `turnActive`; otherwise it returns `nil` (no timer
  while idle, nothing else schedules ticks).
- `apply`: main-agent (`AgentID` `agent.MainAgentID` or empty) `EvToolCall` → `openCalls++`;
  main-agent `EvToolResult` → `openCalls--` (not below 0); `EvTurnDone` → `turnActive = false`,
  `openCalls = 0`.
- The line, shown only while `turnActive`, directly above the input box (below the subagent
  panel):
  `✻ Thinking… (12s · ↓ 1.2k tokens · esc to interrupt)`. Verb `Working…` instead of
  `Thinking…` while `openCalls > 0`. `✻ ` + verb in `lipgloss.Color("#D77757")`, the parenthesis
  part (with its leading space) in `lipgloss.Color("244")`. Static glyph. The token part
  `↓ N tokens · ` is omitted while N is 0, N = `sess.Tokens().Out - turnOut0`.
- Helpers in `turn.go`: `formatElapsed(d time.Duration) string` (whole seconds, truncated:
  below 60 s `Ns`, else `Nm SSs` with two-digit seconds, e.g. `1m 15s`, `1m 05s`, `12m 00s`) and
  `formatTokens(n int) string` (`< 1000` → `N`; `< 1,000,000` → `%.1fk`, e.g. 1234 → `1.2k`,
  1000 → `1.0k`; else `%.1fM`). Later tasks reuse both.
- Layout: the line must not change the total `View()` height: take one line from the top of the
  viewport view, as `withPanel` in `agents.go` does for the panel (keep at least one viewport
  line).

Tests (new file `internal/tui/turn_test.go`, names start with `TestThinking`). Add to a new file
`internal/tui/clock_test.go`:
`type fakeClock struct{ t time.Time }` with `Now() time.Time` and `Advance(d time.Duration)`, and
`newClockModel(t *testing.T, srv *providertest.Server) (Model, *agent.Session, *fakeClock)`
which builds the model exactly like `newSessionModel` in `session_test.go` but with
`Options.Now = clock.Now` (refactor `newSessionModel` into a shared helper taking an
`func(*Options)` editor if that is simpler; keep `newSessionModel`'s signature). To keep a turn
busy use a fake provider response with `Delay: 30 * time.Second` and cancel it with `Esc` at the
end of the test; to get tokens while busy, answer request 0 with a `glob` tool call (not gated)
and `Usage{Prompt: 10, Completion: 1234}` and request 1 with a delayed response.
- `TestThinkingLine`: right after `m.Command("hi")` the plain view contains
  `✻ Thinking… (0s · esc to interrupt)`; after `clock.Advance(75 * time.Second)` and a
  `tickMsg` it contains `(1m 15s · esc to interrupt)`.
- `TestThinkingTokens`: after the 1234-token response is drained the line contains
  `↓ 1.2k tokens · esc to interrupt`.
- `TestThinkingEarlierTurnNotCounted`: a first finished turn with `Completion: 500`; in the
  second turn, before any of its usage arrives, the line has no `↓`.
- `TestThinkingWorkingVerb`: after a main `EvToolCall` without result the line says `Working…`;
  after its `EvToolResult` it says `Thinking…` again.
- `TestThinkingColors`: under `withColorProfile(t, termenv.TrueColor)` the line contains
  `38;2;215;119;87` and `38;5;244`.
- `TestThinkingGoneAfterTurn`: after the turn ends (`waitSession`, `Drain`) neither `Thinking…`
  nor `Working…` is in the view.
- `TestThinkingNoTickWhileIdle` (negative): `Update(tickMsg(...))` on an idle model returns a nil
  command; while busy it returns a non-nil one.
- `TestThinkingFormat`: table test of `formatElapsed` (0, 400ms, 59s, 60s, 75s, 65s) and
  `formatTokens` (0, 999, 1000, 1234, 1500000).
