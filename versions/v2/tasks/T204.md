# T204: Finished marker

Phase 2 · Model: sonnet: one new block kind driven by existing turn state · Depends-on: T203 · Covers: R26, R24 (end of turn, changed)

## Brief
When a TUI-started turn ends, append one permanent line to the conversation. Code in
`internal/tui/turn.go` (turn state, `formatElapsed`, `startTurn` and the `turnActive` flag
already exist there) and `internal/tui/model.go` / `internal/tui/blocks.go`.

- New block kind `blockMarker`. On the main-agent `EvTurnDone` while `turnActive` is true
  (i.e. a turn started by `Command` or `/init`), append exactly one marker block, at the same
  moment the live `Thinking…` line disappears:
  - `✻ Worked for <elapsed>` normally,
  - `✻ Interrupted after <elapsed>` when the user interrupted the turn,
  where `<elapsed>` is `formatElapsed(m.now().Sub(m.turnStart))` (same clock and format as the
  `Thinking…` line, e.g. `Worked for 0s` for 0.4 s, `Worked for 1m 15s`).
- The marker text is fixed when the block is created (never recomputed later). Rendering: `✻`
  in `lipgloss.Color("#D77757")`, a space, the rest in `lipgloss.Color("244")`; the plain text is
  exactly `✻ Worked for 1m 15s`. It is a normal block (scrolls, one blank line around it like
  other blocks).
- Interrupt flag `interrupted bool` on the turn state: set when `Esc` cancels a busy turn and
  when the first `Ctrl+C` cancels a busy turn; reset by `startTurn`.
- No marker for slash commands that do not start a turn (`/mode`, `/effort`, `/compact`,
  `/undo`, `/help`, ...) and none for an `EvTurnDone` while `turnActive` is false.
- `/new` clears the markers with the rest of the conversation (it resets `m.blocks`; make sure
  it also clears the turn state).

Tests (new, in `internal/tui/turn_test.go`, names start with `TestFinished`; use
`newClockModel(t, srv)` and `fakeClock` from `internal/tui/clock_test.go`, and a fake provider
response with `Delay` plus `Esc` where a turn must stay open while the clock moves):
- `TestFinishedWorkedFor`: a turn whose provider response is held (e.g. `providertest.NewFunc`
  blocking on a channel the test closes) while the clock advances 75 s; after it ends and is
  drained, the last block's plain text is `✻ Worked for 1m 15s` and the view has no `Thinking…`.
- `TestFinishedUnderOneSecond`: 400 ms → `✻ Worked for 0s`.
- `TestFinishedInterrupted`: busy turn, clock +12 s, `Esc` → after draining, `✻ Interrupted after 12s`.
- `TestFinishedOnePerTurn`: two turns (+5 s and +7 s) → exactly two marker lines, `Worked for 5s`
  then `Worked for 7s`.
- `TestFinishedNotForSlash` (negative): `m.Command("/mode auto")` and `/effort low` add no marker.
- `TestFinishedColors`: under `withColorProfile(t, termenv.TrueColor)` the marker line contains
  `38;2;215;119;87` and `38;5;244`.
- `TestFinishedClearedByNew`: after a finished turn, `m.Command("/new")` removes the marker.
When you block a fake-provider handler on a channel, close the channel in `t.Cleanup` before the
server is closed (register the server's `Close` first).
