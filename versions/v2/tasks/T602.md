# T602: Clipboard writer

Phase 6 · Model: opus: consequential second exec path in the binary (fixed tools, secret-free input) · Depends-on: T000 · Covers: R21 (OSC 52 + external tool), §5 (deps direct, CLAUDE.md exec note, injectable clipboard)

## Brief
Add the injectable clipboard writer used by copy-on-select. Files: new
`internal/tui/clipboard.go` and `internal/tui/clipboard_test.go`; `internal/tui/model.go`
(`Options`, `New`); `go.mod`; `CLAUDE.md` (Architecture notes only).

- `go.mod`: move `github.com/atotto/clipboard v0.1.4` and `github.com/aymanbagabas/go-osc52/v2 v2.0.1`
  into the direct `require` block (no `// indirect`). Both are already in `go.sum`: no download
  (run go commands with `GOPROXY=off` to be sure); `go.sum` must not gain new modules.
- `internal/tui/clipboard.go` is the only file in the repository that imports
  `github.com/atotto/clipboard` or `github.com/aymanbagabas/go-osc52/v2`. It does not import
  `os/exec` itself and never builds a shell command; `atotto/clipboard` runs only its fixed
  `wl-copy` / `xclip` / `xsel` binaries with the text on stdin.
  - `func writeClipboard(w io.Writer, useTool bool, text string) error`: writes the OSC 52
    sequence `osc52.New(text).String()` to `w` in one `Write` (no tmux/screen wrapping); then,
    when `useTool` is true, calls `clipboard.WriteAll(text)`. Errors are ignored (return nil):
    the caller shows its notice anyway.
  - `func defaultClipboard(text string) error { return writeClipboard(os.Stderr, !clipboard.Unsupported, text) }`
    (stderr is the terminal; stdout belongs to the renderer).
- `Options.Clipboard func(string) error` (nil → `defaultClipboard`); `New` stores the chosen
  function in `Model.clip`. Callers pass text that is already the redacted plain rendering.
- No test may call `defaultClipboard` or `writeClipboard` with `useTool == true`.
- `CLAUDE.md`: outside the "Delegation workflow" section, add `clipboard.go` to the
  `internal/tui` architecture line ("OSC 52 + `atotto/clipboard`, the only exec besides
  `bash.go`: fixed `wl-copy`/`xclip`/`xsel`, text via stdin, only redacted view text"), and adjust
  the sentence that calls `bash.go` the only `os/exec` user so that it stays true (it remains the
  only direct `os/exec` importer). Do not change anything from `## Delegation workflow` on.

Tests (in `internal/tui/clipboard_test.go`, names start with `TestCopy`):
- `TestCopyOSC52Sequence`: `writeClipboard(&buf, false, "hello")` writes exactly
  `osc52.New("hello").String()`, which contains `]52;c;aGVsbG8=`.
- `TestCopyOSC52Unicode`: `héllo ✻` round-trips: the base64 payload in the buffer decodes to the
  input.
- `TestCopyClipboardOption`: a model built with `Options{Clipboard: fake}` has `m.clip` that,
  when called with `x`, calls the fake with `x`; a model built without it uses
  `defaultClipboard` (compare with `reflect.ValueOf(...).Pointer()`, do not call it).
