# T403: Collapsed paste placeholders

Phase 4 · Model: opus: consequential privacy rule (paste buffers in memory only) and untrusted pasted input · Depends-on: T402 · Covers: R22

## Brief
Large bracketed pastes are shown as a placeholder and expanded only for the model. Code in
`internal/tui/input.go` and `internal/tui/model.go` (`Update`, `Command`).

- A bracketed paste arrives as `tea.KeyMsg` with `Paste == true` (text in `Runes`). Normalise
  `\r\n` and lone `\r` to `\n`. If the text contains `\n` or has more than 80 runes, do not insert
  it; instead insert a placeholder at the cursor:
  - `[Pasted text #N +L lines]` where L = number of lines after trimming one trailing `\n`, when
    L > 1;
  - `[Pasted text #N · C chars]` (C = rune count after trimming one trailing `\n`) when it is a
    single line.
  N starts at 1 and counts up for the whole process (never reset, also not by `/new`).
  Shorter pastes without a newline are inserted verbatim (pass the key to the textarea).
- Store: `Model.pastes *pasteStore` (pointer, created in `New`) mapping each placeholder string
  to its full text, memory only (never written anywhere).
- On send of a message (`Command` for a non-slash line): the conversation block (`> ...`) and the
  input history (which stores the input text as typed) show the text with placeholders; the text
  passed to `sess.Submit` has every exact, unedited placeholder that exists in the store
  replaced by its full text: `func (p *pasteStore) expand(s string) string`. A placeholder the
  user edited (any character changed) or deleted is not expanded; an edited placeholder is sent
  literally. Slash commands are not expanded.
- Expansion applies wherever the message comes from (typed, recalled from history), because it
  happens in `Command`.
- The placeholder's full text is never rendered in the conversation or the input.

Tests (in `internal/tui/input_test.go` (create if missing), names start with `TestPaste`; a
paste is `tea.KeyMsg{Type: tea.KeyRunes, Runes: []rune(text), Paste: true}`; use
`newSessionModel(t, srv)` from `session_test.go` and `srv.Requests()` of the fake provider):
- `TestPasteMultilinePlaceholder`: pasting `alpha\nbeta\ngamma` makes the input value exactly
  `[Pasted text #1 +3 lines]`; the view does not contain `beta`.
- `TestPasteLongSingleLine`: 100 × `x` → `[Pasted text #1 · 100 chars]`.
- `TestPasteShortVerbatim`: a 10-character paste `0123456789` is inserted verbatim.
- `TestPasteExpandedOnSend`: type `see ` then paste the 3-line text, `Enter`; after the turn the
  last user message of the fake provider request contains `see alpha\nbeta\ngamma`; the view
  shows `> see [Pasted text #1 +3 lines]` and not `gamma`; `Up` recalls `see [Pasted text #1 +3 lines]`.
- `TestPasteEditedSentLiterally` (negative): paste, then change the placeholder (e.g. backspace
  once, type `X`) and send: the request contains the edited placeholder text literally and not
  `beta`.
- `TestPasteCounter`: two large pastes in one model give `#1` and `#2`; after `/new` the next is `#3`.
- `TestPasteCRLF`: `a\r\nb` → `[Pasted text #1 +2 lines]` and the request contains `a\nb`.
