# T603: Copy-on-select

Phase 6 · Model: opus: secrets must never reach the clipboard (redacted text only) · Depends-on: T204, T601, T602 · Covers: R21, R16 (redaction on copy), R26 (marker copied without ANSI)

## Brief
Drag with the left mouse button over the conversation to select and copy text. Code in
`internal/tui/mouse.go` (create if missing) and `internal/tui/model.go` (`Update`, `View`,
`refreshTo`). Existing pieces: `m.clip func(string) error` (the injected clipboard writer, from
`Options.Clipboard`), `m.now()` (injected clock `Options.Now`), mouse capture is on in `cmd/yip`,
the wheel already scrolls the viewport.

- Keep the rendered conversation lines: in `refreshTo` store the lines of the content passed to
  `m.viewport.SetContent` (already redacted, since every block passes `m.redact`). Copy text is
  taken only from these lines, never from raw block text: `mouse.go` must not read `m.blocks`
  or a block's `text` field.
- `tea.MouseMsg` with `Button == tea.MouseButtonLeft`: `Action` press inside the conversation
  area starts a selection at (content line, display column); motion extends it; release ends it.
  Map the screen row to the content line with `m.viewport.YOffset`, accounting for the overlay
  lines (subagent panel, `Thinking…` line, queue block, notice) that `View()` takes from the top
  of the viewport view; clamp rows to the visible viewport and columns to the line width. Presses
  outside the conversation (input box, status rows) do nothing.
- Selection is a stream from the start cell to the end cell (either direction): first line from
  the start column, full middle lines, last line up to and including the end column. Text =
  `ansi.Strip` of those lines cut by display cells (use `github.com/charmbracelet/x/ansi`
  helpers such as `ansi.Cut`), trailing spaces trimmed per line, lines joined by `\n`.
- While dragging, the selected cells are shown in reverse video (`\x1b[7m`, e.g.
  `lipgloss.NewStyle().Reverse(true)` over the stripped text of the selected part).
- On release after motion with a non-empty text: call `m.clip(text)`, clear the selection, and
  show the notice `N characters copied` (N = `utf8.RuneCountInString(text)`) in
  `lipgloss.Color("#B1B9F9")` on one line directly above the input box (below the queue block),
  for 3 s: store `noticeUntil = m.now().Add(3 * time.Second)`; `View()` shows it only while
  `m.now()` is before that; also return `tea.Tick(3*time.Second, ...)` so the real program
  redraws. Like other overlay lines it takes its line from the top of the viewport view.
- A press and release without motion (a click) copies nothing and shows no notice.

Tests (new file `internal/tui/copy_test.go`, names start with `TestCopy`; every model gets
`Options.Clipboard` = a fake recording the texts and `Options.Now` = `fakeClock.Now`
(`clock_test.go`); use `newClockModel(t, srv)` for session models and set the clipboard via a
helper or `m.clip = fake.write` directly; mouse events are
`tea.MouseMsg{X: x, Y: y, Button: tea.MouseButtonLeft, Action: tea.MouseActionPress / tea.MouseActionMotion / tea.MouseActionRelease}`):
- `TestCopySelection`: with the two info blocks `alpha beta` and `gamma delta` (rendered with
  one blank line between them), pressing on the `b` of `beta`, moving, and releasing on the last
  `a` of `gamma` puts exactly `beta\n\ngamma` into the fake clipboard (one call).
- `TestCopyTrailingSpacesTrimmed`: a selection over full-width lines has no trailing spaces.
- `TestCopyHighlightReverse`: between press and release (after motion) `View()` contains `\x1b[7m`.
- `TestCopyNotice`: after release the plain view shows `N characters copied` with the right rune
  count (use a non-ASCII selection such as `✻ Worked`), under `withColorProfile(t, termenv.TrueColor)`
  rendered with `38;2;177;185;249`; after `clock.Advance(3 * time.Second)` it is gone.
- `TestCopyClickNoDrag` (negative): press + release at the same cell → the fake clipboard got
  nothing and no notice.
- `TestCopySecretNeverCopied` (negative): with `newClockModel` (its config key resolves to
  `SECRET123`) and a fake provider reply `the key is SECRET123 ok`, selecting the whole reply
  copies text containing `[redacted]` and never `SECRET123`.
- `TestCopyFinishedMarkerPlain`: selecting the finished-marker line `✻ Worked for 1m 15s`
  copies exactly that text, without `\x1b`.
