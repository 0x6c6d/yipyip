`docs/usage.md` (keep its existing sections and order; edit them, add subsections where needed):
- Modes: yipyip starts in `auto` mode by default (tools such as `bash`, `write_file`,
  `edit_file`, `spawn_agent` run without asking); `Shift+Tab` or `/mode manual` switches to
  manual approval; the status shows `auto (shift+tab to toggle)` with `auto` highlighted.
- Status: two rows under the input: row 1 `cwd · provider/model · effort · mode (shift+tab to toggle)`,
  row 2 `in N · out N · total N · ctx used/limit`; no costs. Rewrite the old status-line
  paragraph in "Undo, compaction and the status line": the v1 format `in N / out N / total N`
  must no longer appear anywhere in the file.
- Conversation: `> ` user messages, `●` replies and tool calls, `⎿` results collapsed to 3
  lines (`ctrl+o` expands); the `✻ Thinking… (12s · ↓ 1.2k tokens · esc to interrupt)` line while
  busy (`Working…` while a tool runs); the finished marker `✻ Worked for 1m 15s` or
  `✻ Interrupted after 12s` at the end of each turn.
- Subagents: one live block per subagent (`● Subagent a1 (task)`, latest tool call,
  `Running… (N tool uses · tokens · time)` then `Done`/`Failed`/`Cancelled`); panel line
  `● a1 task (14s · 1.2k tokens)`; `/agents <id>` shows the transcript.
- Input: `/` suggestions as grey ghost text accepted with `Tab` or `Right`; `Up`/`Down` input
  history (memory only, kept across `/new`, at most 500 entries); large pastes become
  `[Pasted text #N +L lines]` and are sent in full to the model.
- Typing while busy: `Enter` queues the message (shown dimmed above the input); queued messages
  are sent together as the next turn when the current one ends; `Esc`/`Ctrl+C` cancel and move
  them back into the input; `Up` on an empty input pulls them back for editing.
- Scrolling and copying: mouse wheel (3 lines), `PgUp`/`PgDn`, `Ctrl+Home`/`Ctrl+End` (`Home`/`End`
  with an empty input); drag with the left button to select, release copies (OSC 52 and
  `wl-copy`/`xclip`/`xsel` when installed) and shows `N characters copied`; because yipyip
  captures the mouse, use `Shift`+drag for the terminal's own selection. Copied text is the
  redacted screen text: secrets are never copied.
- Keys: the full key list as printed by `yip --help`.

`CLAUDE.md` (outside the Delegation section): the `internal/tui` architecture line lists the v2
files with one phrase each: `turn.go` turn clock, `Thinking…` line and finished marker;
`subagents.go` live subagent blocks; `input.go` suggestions, history, paste placeholders and
the queue; `mouse.go` wheel scrolling and copy-on-select; `clipboard.go` clipboard writer (keep
the existing clipboard/exec wording if already present). Keep the Commands section accurate.
