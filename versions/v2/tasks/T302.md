# T302: Subagent panel format

Phase 3 · Model: haiku: one format string with a clear test · Depends-on: T301 · Covers: R9 (panel, changed), R25 (panel line)

## Brief
Change the panel above the input (one line per running subagent, `panelLines()` in
`internal/tui/agents.go`) from `a1 running <task> N tokens` to:
```
● a1 <task> (14s · 1.2k tokens)
```
- `●` in `lipgloss.Color("#D77757")`; the rest (` a1 <task> (14s · 1.2k tokens)`) in
  `lipgloss.Color("244")`.
- `<task>` = `shortTask(s.Task, taskWidth)` (existing helper); tokens = `formatTokens(s.Tokens)`
  and elapsed = `formatElapsed(m.now().Sub(start))`, both helpers in `internal/tui/turn.go`.
- `start` is the subagent's start time tracked by the TUI: `m.subs[s.ID].start`
  (`Model.subs map[string]*subState` in `internal/tui/subagents.go`). When there is no entry yet
  use `m.now()` (elapsed `0s`).
- Only subagents with status `agent.SubRunning` are listed (unchanged); the line is redacted and
  limited to the terminal width as now.

Tests (in `internal/tui/agents_test.go` or `internal/tui/subagents_test.go`; names start with
`TestSubagent`; use `newClockModel` + `fakeClock` from `clock_test.go` and the test seam
`m.subInfo` (a `func() []agent.SubInfo` field on `Model`) to script one running subagent `a1`
with task `check the logs` and `Tokens: 1200`; create its state by sending
`EventMsg{Event: agent.Event{Kind: agent.EvSubagent, AgentID: "a1"}}`, then advance 14 s):
- `TestSubagentPanelFormat`: the plain view contains the panel line `● a1 check the logs (14s · 1.2k tokens)`
  above the input box; under `withColorProfile(t, termenv.TrueColor)` the
  line contains `38;2;215;119;87` and `38;5;244`.
- `TestSubagentPanelOnlyRunning`: a subagent with status `done` has no panel line.
Adapt the existing `TestSubagentPanel` (it looks for `a1 running`) to the new format.

## Verification
`scripts/verify/v2/T302.sh` exits 0. It runs the two new tests, the adapted `TestSubagentPanel`
and all `Subagent`/`Agents` tests, and checks the old `running %s %d tokens` format is gone;
negative checks: no protected path and nothing in agent/tools/provider/config changed; then
`make check`.
