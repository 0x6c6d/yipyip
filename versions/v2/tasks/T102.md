# T102: Mode label colours and key hint

Phase 1 · Model: opus: the mode label is the only visible signal of the consequential auto-mode default · Depends-on: T101 · Covers: R28 (label), R7 (changed)

## Brief
Row 1 of the status area (`StatusRows()` in `internal/tui/status.go`, which already shows
`<cwd> · <provider/model> · <effort> · <mode> (shift+tab to toggle)`) gets the mode colours:
- the word `auto` in `lipgloss.Color("#E8A33D")` (renders `38;2;232;163;60` under TrueColor: termenv truncates 61 to 60);
- the word `manual` in the default colour (no foreground style at all);
- the hint `(shift+tab to toggle)` in `lipgloss.Color("250")` (renders `38;5;250`), for both modes.
  The hint always reads exactly `(shift+tab to toggle)`; it never mentions `/mode`.
- A too narrow terminal shortens only the cwd (existing `shortenLeft`, width measured with
  `lipgloss.Width`, which ignores ANSI codes); the mode word and the hint are never cut or dropped,
  even at width 40.
The label must follow every mode change: `Shift+Tab`, `/mode auto`, `/mode manual`, `/mode`
(toggle); `/new` keeps the mode (it already does: `Session.Reset` does not change it).
Do not change `internal/agent` (its constructor default stays `manual`).

Tests (new, in `internal/tui/status_test.go` or a new `internal/tui/mode_test.go`, names start
with `TestMode`; use `newSessionModel(t, srv)` from `session_test.go`, `sess.SetMode(agent.ModeAuto)`
to start in auto, and `withColorProfile(t, termenv.TrueColor)`):
- `TestModeLabelAutoColored`: row 1 plain text (`ansi.Strip`) contains `auto (shift+tab to toggle)`;
  raw row 1 contains `38;2;232;163;60` and the hint is rendered with `38;5;250`.
- `TestModeLabelManualPlain`: after one `Shift+Tab` (`tea.KeyMsg{Type: tea.KeyShiftTab}`) the
  plain row 1 contains `manual (shift+tab to toggle)`; raw row 1 contains no `38;2;232;163;60`;
  the hint still uses `38;5;250`.
- `TestModeLabelCommandUpdates`: `m.Command("/mode manual")` then `m.Command("/mode auto")`
  update the label accordingly.
- `TestModeLabelKeptByNew`: in auto, `m.Command("/new")` keeps `auto (shift+tab to toggle)`.
- `TestModeLabelNarrow`: width 60 (`tea.WindowSizeMsg{Width: 60, Height: 24}`) and a start dir
  longer than 60 runes: plain row 1 starts with `…`, ends with `auto (shift+tab to toggle)`, and
  `lipgloss.Width(row1) <= 60`.
- `TestModeHintNeverMentionsSlashMode` (negative): in both modes row 1 does not contain `/mode`.
Adapt existing tests that compare row 1 byte for byte (e.g. in `model_test.go`,
`commands_test.go`) by comparing `ansi.Strip` of the row.
