# T701: Help lists the new keys

Phase 7 · Model: haiku: static help text with a mechanical test · Depends-on: T000 · Covers: R11 (changed)

## Brief
`/help` and `yip --help` both print `HelpText()` from `internal/tui/help.go`. Replace its `keys`
table with exactly these entries, in this order (keep the existing alignment code):
```
Enter               send; while the agent is busy: queue the message
Alt+Enter           new line
Esc                 cancel the running turn; queued messages return to the input
Shift+Tab           toggle auto/manual mode (auto is the default)
Ctrl+C              twice: quit
Tab/Right           accept a suggestion or complete a command
Up/Down             input history (Up first restores queued messages)
Ctrl+O              expand tool results
PgUp/PgDn           scroll
Mouse wheel         scroll 3 lines
Ctrl+Home/Ctrl+End  scroll to the first/last line (Home/End with an empty input)
Mouse drag          select text; releasing copies it to the clipboard
```
The command list above the keys is unchanged. No `cost`, `price` or `$` anywhere.

Tests:
- `internal/tui/help_test.go`: `TestHelpTextListsNewKeys`: `HelpText()` contains `Up/Down`,
  `Ctrl+Home`, `Ctrl+End`, `Tab`, `Mouse drag`, `copies`, `queue`, `restores queued`, and
  `auto is the default`.
- `cmd/yip/main_test.go`: `TestHelpFlagNewKeys`: `run([]string{"--help"}, &stdout, &stderr)`
  returns 0 and stdout contains `Up/Down`, `Ctrl+Home`, `Ctrl+End`, `Tab` and `queue`.
The existing `TestHelpTextListsCommands`, `TestHelpTextNoCost`, `TestHelpCommand`,
`TestHelpFlag` must keep passing.

`scripts/verify/v2/T701.sh` exits 0. It runs the two new tests and the four existing help tests by
