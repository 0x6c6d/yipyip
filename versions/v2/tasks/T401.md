# T401: Command autosuggest ghost text

Phase 4 · Model: sonnet: input-view feature with key handling · Depends-on: T000 · Covers: R19, R15 (completion, unchanged and now with ghost text)

## Brief
Show the rest of the first matching completion as grey ghost text after the cursor. New file
`internal/tui/input.go`; changes in `internal/tui/model.go` (`Update` keys, `View`).

- Active only when the input value is a single line (no `\n`), the cursor is at its end (row 0
  and column = rune length of the value; use the textarea's `Line()` and `LineInfo()`), and the
  value starts with `/`. No ghost while an approval prompt or the model picker is open.
- `func (m Model) suggestion() (ghost string, accept string)`: `ghost` is what is shown, `accept`
  is the full input after accepting (`""` when the ghost is only a hint).
  - No space in the value: candidates are the command names in `Commands()` order; the first one
    that has the value as a proper prefix gives ghost = the remainder (`/eff` → `ort`,
    accept `/effort`). An exact match gives no ghost.
  - `/effort ` + arg: values `low`, `medium`, `high`; `/mode ` + arg: `auto`, `manual`;
    `/model ` + arg: the configured ids from `Session.Models()` in that order (none without a
    session). Empty arg → hint ghost `[low|medium|high]`, `[auto|manual]`, `[provider/model]`
    (accept `""`). Non-empty arg → remainder of the first candidate with that prefix
    (`/effort m` → `edium`, accept `/effort medium`); exact match or no match → no ghost.
- Rendering: the ghost appears in `View()` directly after the typed text on the input line, in
  `lipgloss.NewStyle().Foreground(lipgloss.Color("244"))`, without changing the input box size.
  It is never part of `m.input.Value()`.
- Keys: `Tab` or `Right` with a non-empty `accept` set the input to `accept` with the cursor at
  the end. `Tab` without an acceptable ghost keeps the v1 behaviour (`completeInput` when
  `completions()` match). `Right` without an acceptable ghost moves the cursor as before. Hints
  are never accepted.
- The existing completion line over the viewport (`completions()`) stays as it is.
- Sending (`Enter`) uses only `m.input.Value()`: the ghost is never sent or stored.

Tests (new file `internal/tui/input_test.go`, names start with `TestSuggest`; set the input with
`m.input.SetValue(...)` and `m.input.CursorEnd()`, or by sending `tea.KeyMsg{Type: tea.KeyRunes, Runes: ...}`;
use `newSessionModel(t, srv)` with `providertest.ConfigJSON` (it configures model ids) where a
session is needed):
- `TestSuggestCommand`: `/eff` → ghost `ort`.
- `TestSuggestEffortHint`: `/effort ` → ghost `[low|medium|high]`; `/mode ` → `[auto|manual]`;
  `/model ` → `[provider/model]`.
- `TestSuggestEffortPrefix`: `/effort m` → ghost `edium`.
- `TestSuggestModelIDs`: `/model f` → ghost is the remainder of the first id of `sess.Models()`.
- `TestSuggestTabAccepts`: `Tab` on `/effort m` → input `/effort medium`; `Right` on `/eff` →
  `/effort`.
- `TestSuggestHintNotAccepted` (negative): `Tab` and `Right` on `/effort ` leave the value
  `/effort ` (never `[low|medium|high]`).
- `TestSuggestNoGhost` (negative): multi-line input `/eff\nx`, cursor not at the end, and input
  not starting with `/` give an empty ghost.
- `TestSuggestColor`: under `withColorProfile(t, termenv.ANSI256)` `View()` contains the ghost
  rendered as `lipgloss.NewStyle().Foreground(lipgloss.Color("244")).Render("ort")`.
- `TestSuggestNeverSent`: with a fake provider, input `hello` has no ghost; for input `/eff`
  pressing `Enter` runs `/eff` (unknown command), and the session history and the fake
  provider's requests contain no `ort`.
The existing `TestCompletion` must still pass.
