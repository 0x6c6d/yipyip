# Plan v2: a UI that feels like Claude Code

_Source: `versions/v2/spec.md` (2026-10-21). Core plan: `Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** TUI-only increment in `internal/tui` + `cmd/yip`: two-row status
(R15), auto default mode + coloured label/hint (R28, R7), Claude-Code conversation layout (R15),
`Thinking…` line (R24), finished marker (R26), subagent blocks + panel (R25, R9), autosuggest
(R19), input history (R20), collapsed pastes (R22), queueing while busy (R27, R6), mouse wheel /
`Ctrl+Home`/`Ctrl+End` scrolling (R23), copy-on-select (R21), `/help`/`--help` keys (R11),
`docs/usage.md`, the `CLAUDE.md` clipboard-exec note; adapt v1 tests whose expectations R15/R28 change.
**Explicitly deferred:** spec §7 (persisted history, `Ctrl+R`, double/triple-click, selecting in
the input, diff view, mid-turn injection, spinner animation, image paste, themes, right-click
paste, macOS/Windows clipboard); any change to `internal/{agent,tools,provider,config}`.

## Architecture changes
- **cmd/yip** (changed): `sess.SetMode(agent.ModeAuto)` after `agent.NewSession`, `tui.Options{Mode: "auto"}`, `tea.WithMouseCellMotion()` next to `tea.WithAltScreen()`; `--help` lists the new keys.
- **tui `Options`** (changed): `Now func() time.Time` (nil → `time.Now`) and `Clipboard func(string) error` (nil → default writer); `Options.Mode` "" still means manual.
- **tui/status.go** (changed): two rows, mode label colours + hint; no tokens on row 1.
- **tui/blocks.go** (changed): borderless `●`/`⎿` renderer, tool summaries, collapse `… +N lines (ctrl+o to expand)`, user background 236; removes the bordered tool block.
- **tui/turn.go** (new): turn clock, 1 s `tea.Tick` only while busy, `Thinking…`/`Working…` line, R26 marker, interrupt flag.
- **tui/subagents.go** (new; `agents.go` panel changed): per-id live block (start time, tool-use count, latest call, final status) from `EvSubagent`/`EvToolCall` + `Session.Subagents()`.
- **tui/input.go** (new): ghost-text suggest, history ring (500), paste store (`#N` → text), queue (render ≤5 + `… +N more`), placeholder expansion at send.
- **tui/mouse.go** + **tui/clipboard.go** (new): wheel/selection/notice; `clipboard.go` is the only importer of `atotto/clipboard` and `go-osc52/v2` (both made direct in `go.mod`, no new download).
