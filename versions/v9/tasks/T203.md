# T203: Bullet and numbered lists

Phase 2 · Model: opus: parses untrusted model text (nesting, continuation, marker ambiguity) · Depends-on: T101 · Covers: R75 (bullet lists with `•` and nesting, numbered lists), A11

## Brief
`internal/tui/markdown.go` has `renderMarkdown(src string, width int) string`: a line-based block
pass (a dispatcher over block rules, fence first, heading, possibly a table rule, then paragraph)
followed by an inline pass (`renderInline` or similar: bold, code spans protected). Add a **list
rule**, tried before the paragraph rule and after every other existing rule.

**Items.** Indent = number of leading spaces (a tab counts as 4).
- Bullet item: indent, then `-`, `*` or `+`, then at least one space, then the text.
- Numbered item: indent, then 1-9 digits, then `.` or `)`, then at least one space, then the text.
- Not items: `-no space`, `1.5 apples`, `+1 vote`, `**bold** start` (marker not followed by a space).

**A list** is a maximal run of item lines, continuation lines and blank lines that are followed by
another item or continuation line. A continuation line is a non-blank, non-item line whose indent
is at least the source text column of the item above it (indent + marker length + the spaces
after the marker; for `- x` that is 2). Any other line ends the list and is handled by the other
rules; a trailing blank line belongs to what follows.

**Nesting.** Per list, the indent unit `u` is set by the first item with indent > 0: `u = 2` if
that indent is less than 4, else `u = 4`. Level of an item = indent / u (integer division);
without nested items every item is level 0.

**Output**, one line per source line:
- bullet: `2·level` spaces + `•` + space + inline(text)
- numbered: `2·level` spaces + the number and its `.` or `)` as written + space + inline(text)
- continuation: as many spaces as the rendered text column of its item, then inline(trimmed text)
- blank lines stay blank.

Example: `- one`, `  more of one`, `- two **b**`, `  - nested`, `    - deeper`, `* star`,
`+ plus`, ``, `1. first`, `2) second`, `10. tenth` renders as `• one`, `  more of one`,
`• two b`, `  • nested`, `    • deeper`, `• star`, `• plus`, ``, `1. first`, `2) second`,
`10. tenth`. With a 4-space unit, `- a`, `    - b`, `        - c` renders as `• a`, `  • b`, `    • c`.

A line `---`, `***` or `___` is not an item (no space after the first marker). Keep the rule a
separate function; a later task adds blockquotes and horizontal rules before it.

**Tests** (in `internal/tui/markdown_test.go`, ANSI stripped, exact lines):
`TestMarkdownListBullets` (all three markers become `•`, inline markup inside items rendered),
`TestMarkdownListNested` (the two examples above), `TestMarkdownListNumbered` (`.` and `)`, multi
digit numbers kept), `TestMarkdownListContinuation`, `TestMarkdownListNotItems` (the four non-items
above come back unchanged except that `**bold** start` shows `bold start` without a bullet).
