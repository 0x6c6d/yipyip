# T204: Blockquotes and horizontal rules

Phase 2 · Model: opus: recursive parsing of untrusted model text (nesting depth must stay bounded) · Depends-on: T101 · Covers: R75 (blockquotes with a `│` bar, horizontal rules), A12

## Brief
`internal/tui/markdown.go` has `renderMarkdown(src string, width int) string`: a line-based block
pass (a dispatcher over block rules: fence first, heading, maybe table and list rules, then
paragraph) followed by an inline pass. Add two block rules, both tried after the fence, table
and heading rules and before any list rule and the paragraph rule; the order among the final
rules is: rule, quote, list (if present), paragraph.

**Horizontal rule.** A line whose `strings.TrimSpace` is three or more of the same character from
`-`, `*`, `_` and nothing else (no spaces in between) renders as `─` repeated `width` times
(40 times when `width <= 0`), dim style allowed. `--`, `a --- b`, `-- -` are not rules (they stay
paragraph text). A `---` line directly under a paragraph is a rule (no setext headings).

**Blockquote.** A quote is a maximal run of lines that start, after up to 3 spaces, with `>`.
Strip from each line the `>` and one following space if there is one; render the stripped lines
as one block with `renderMarkdown(inner, width-2)` (so headings, lists, tables, nested quotes and
inline markup work inside, and a nested `> >` gets a second bar); prefix every resulting line with
`│ ` (the bar may be dim). No `>` of a rendered quote is shown. Bound the nesting: at a depth of
32 nested quotes, render the remaining inner text as plain paragraph lines instead of recursing,
so input like 5000 `>` characters neither recurses deeply nor panics.

Example at width 30: `> quoted **x**`, `> > nested`, `> back`, ``, `---`, `***`, `___`, `--`
renders as `│ quoted x`, `│ │ nested`, `│ back`, ``, then three lines of 30 `─`, then `--`.
`> - item` renders as `│ • item` once a list rule exists (write that test only if the list rule
is present in the file; otherwise skip that single case).

**Tests** (in `internal/tui/markdown_test.go`, ANSI stripped, exact lines):
`TestMarkdownQuote` (the example lines), `TestMarkdownQuoteInner` (heading and bold inside a
quote, a quote with a blank `>` line), `TestMarkdownQuoteDeep` (5000 `>` then text: no panic, the
text is present), `TestMarkdownRule` (all three forms at width 30 and the 40-wide default at width
0 and -1), `TestMarkdownRuleNotRule` (`--`, `a --- b`, `-- -` unchanged).
