# T501: e2e Markdown tests: table view and copy

Phase 5 · Model: sonnet: e2e tests over existing code (the supervisor runs the secret negatives itself) · Depends-on: T102 T202 · Covers: R75 (rendered view end to end), R77 (copy = rendered, redacted view text)

## Brief
Assistant text is now rendered from markdown in the TUI (`internal/tui/markdown.go`, called for
assistant blocks after redaction): GFM tables get box borders (`┌─┬─┐`, `│`, `├─┼─┤`, `└─┴─┘`),
`**bold**` loses its stars, and no `|---|` separator is shown. Copy-on-select copies the view text
(rendered, ANSI stripped, redacted) to `tui.Options.Clipboard`. Add end-to-end tests in a new
file `e2e/markdown_test.go`.

The e2e harness is `e2e/helpers_test.go`: `newEnvServer(t, srv, envOpts{...})` builds a real
`agent.Session` (auto mode) on the fake provider `providertest` and a `tui.Model` at 160x50; the
fake key resolves to `SECRET123`; `e.submit(t, text)` sends a message and drains the events;
`e.Model.View()` is the screen. Add a field `clipboard func(string) error` to `envOpts` and pass it
as `tui.Options{..., Clipboard: o.clipboard}` in `newEnvServer` (nil keeps today's behaviour).
Change nothing else in the helpers.

Scripted answer (one `providertest.Response{Text: ...}`):

```
Here is the table:

| Name | Key |
|------|:---:|
| alpha | SECRET123 |
| beta | **bold** |

Done.
```

Tests (both must run, never skip):
- `TestMarkdownE2E`: after `e.submit(t, "show a table")`, the ANSI-stripped view
  (`ansi.Strip`, `github.com/charmbracelet/x/ansi`) contains `┌`, `├`, `└`, `│ alpha`, `[redacted]`,
  `bold`, `Here is the table:`, `Done.`; it contains no `SECRET123`, no `**bold**`, and no line
  containing `|---` or `|:---:|`.
- `TestMarkdownE2ECopy`: with a recording clipboard in `envOpts`, find the screen cell of
  `alpha` and of `beta` in the stripped view lines (x = `ansi.StringWidth` of the line prefix,
  y = line index); send `tea.MouseMsg{X, Y, Button: tea.MouseButtonLeft, Action: tea.MouseActionPress}`
  at `alpha`, a `MouseActionMotion` and a `MouseActionRelease` at column 150 of the `beta` line,
  each through `e.Model.Update` (keep the returned `tui.Model`). Exactly one text was copied; it
  contains `alpha`, `[redacted]`, `│`, `beta` and `bold`, and contains no `SECRET123`, no `**`,
  no `|---`.
