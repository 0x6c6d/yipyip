# T102: Assistant blocks through renderMarkdown with the secret guard

Phase 1 · Model: opus: Consequential assumption A1 (a render must never reassemble a secret) · Depends-on: T101 · Covers: R75 (applied after redaction, before wrapping), R76 (other blocks unchanged), R77 (view text stays redacted)

## Brief
`internal/tui/markdown.go` already has `renderMarkdown(src string, width int) string` (pure,
renders headings, bold and fences; `width <= 0` = natural width). Wire it into the assistant
block rendering in `internal/tui/blocks.go`.

Today `Model.renderBlock` does, for `blockAssistant`: `text := m.redact(b.text)`, trim trailing
`\r\n`, return `""` when blank, else `"● " + indentContinuation(highlightFences(text))`.
Change only that case to:

1. `text` = redacted, trimmed source as today (blank → `""` as today).
2. `out := renderMarkdown(text, width-2)` (the `● ` bullet and the two-space continuation
   indent take 2 columns; pass the value even when it is `<= 0`).
3. Secret guard (A1): `s := ansi.Strip(out)`; if `m.redact(s) != s`, the rendering joined pieces
   into a secret (for example `**SEC**RET123` renders as `SECRET123`): use `out = text`, the
   redacted source shown unrendered (no styling at all).
4. `return "● " + indentContinuation(out)`.

User blocks, tool blocks and results, error and info lines, markers and subagent blocks stay
exactly as they are (no markdown). Keep `highlightFences` and its tests. The outer lipgloss
width rendering in `refreshTo` stays unchanged.

**Tests** (put them in `internal/tui/markdown_test.go`):
- `TestMarkdownSkeletonView`: `feed(newBlockModel(), agent.Event{Kind: agent.EvText, AgentID: "main", Text: "# Big Title\n\nplain **bold** words"})`;
  the stripped view has a line starting `● Big Title` and a line `  plain bold words`, and no
  `**` and no `# Big`.
- `TestMarkdownSkeletonOtherBlocksRaw`: a tool result `# tool **raw**`, an info line
  `info **raw**` and a user line `> **mine**` keep their markup in the view.
- `TestMarkdownSecretReassembly`: with a session model (`newSessionModel`, `answerServer`,
  `tabTurn`; the fake key resolves to `SECRET123`): answer `joined **SEC**RET123 here` → the
  stripped view does not contain `SECRET123` and does contain `**SEC**RET123`; answer
  `key SECRET123 and **bold**` → the view shows `key [redacted] and bold` and no `SECRET123`.
  Structure it as a table of cases so later tasks can add cases.
- `TestRenderAssistantBlock`, `TestFenceHighlightedInView`, `TestCopySecretNeverCopied` and
  the other existing tests pass unchanged.
