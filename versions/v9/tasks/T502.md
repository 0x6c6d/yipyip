## Brief
Update the user documentation for three v9 changes. Edit only `docs/usage.md` and the
`## Usage` section at the end of `README.md`.

The behaviour to document:
- `/clear` empties the current tab in place: the transcript is emptied and the tab gets a fresh
  session with the same model, effort and mode; a running turn and its subagents are cancelled,
  pending approvals denied and questions cancelled; the tab count, the input history and the
  tab's saved session file stay; nothing is saved; it prints `cleared`. It works while idle and
  while a turn runs. `/new` still opens a fresh session in a new tab.
- Closing the last remaining tab (`Ctrl+W` or its `×`) discards that tab without saving it and
  leaves one new empty tab; yip keeps running. `/exit`, `/quit` and `Ctrl+C` twice quit as before.
  Closing one of several tabs still saves it first.
- Assistant replies are shown rendered from markdown: tables (box borders, padded columns, bold
  header, alignment from `:---`, `---:`, `:---:`; wider than the window → cells wrap, never
  overflow), headings (bold, no `#`), bold, italic, inline code, strikethrough, bullet lists
  (shown with `•`, nesting kept), numbered lists, blockquotes (shown with a `│` bar), horizontal
  rules, links shown as `text (url)`. Fenced code blocks keep syntax highlighting; text inside
  fences and inline code is shown as written. While a reply streams, unfinished markdown (a table
  without its separator line yet, an unclosed `**` or fence) is shown as plain text until it is
  complete. Only assistant text is rendered: your input, tool results and subagent blocks are shown
  as before. Not supported: images, HTML, footnotes, task-list checkboxes, reference-style links,
  clickable links, a raw-mode switch. Selecting text copies what is shown (the rendered text,
  with secrets as `[redacted]`). If rendering would join pieces of text into a secret, the reply is
  shown unrendered instead.
