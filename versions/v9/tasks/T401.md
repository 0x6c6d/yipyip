# T401: Closing the last tab leaves one fresh tab

Phase 4 · Model: opus: Consequential A3 (the last tab is discarded unsaved), quit path, cancellation · Depends-on: T301 · Covers: R74, changed last-tab close (was save then quit)

## Brief
Today `Model.closeTab` in `internal/tui/tabs.go` (used by `Ctrl+W` and by the `×` click of the
tab bar) saves the current tab and quits when it is the last tab:
`if len(m.tabs) <= 1 { m = m.saveTabs(); return m, m.quit() }`. Change only that branch.

`tabs.go` has `func (m *Model) resetTab(keepHistory bool) error`: it replaces the current tab in
place by a fresh tab (new agent session with the global model, effort and mode, empty
transcript; denies pending approvals, cancels pending questions, cancels the old session's turn
and subagents, stops its pump; never saves; with `keepHistory == false` the history, pastes and
input are fresh too). On error it changes nothing. It does not start the new event pump.

1. Last tab: `if err := m.resetTab(false); err != nil { m.add(blockError, "error: "+err.Error()); return m, nil }`
   then `return m, m.waitEvent()`. No `saveTab`/`saveTabs`, no `m.quit()`: the app keeps
   running and shows one empty tab (no transcript line). An earlier saved file of the tab is
   neither rewritten nor deleted. Update the doc comment of `closeTab`.
2. With 2 or more tabs nothing changes (save, remove, move left else right).
3. `/exit`, `/quit` and double `Ctrl+C` still save every tab and quit (do not touch them).
4. `help.go`: the `Ctrl+T / Ctrl+W` key line says that the last tab is replaced by an empty one
   instead of closing the app, e.g.
   `new tab (up to 8) / close the tab (saved first; the last tab is discarded and replaced by an empty one)`.

Existing tests to rewrite (they assert the old quit): `TestCloseLastTabQuitsAndSaves`
(`tabs_test.go`) and `TestTabButtonsLastTab` (`tabclick_test.go`); replace them by the new tests
below (delete the old functions). `TestCloseTabSavesSession`, `TestCloseTabSwitchesLeftNeighbour`
and the exit-save tests stay as they are.

**Tests** (in `tabs_test.go` and `tabclick_test.go` or a new `internal/tui/closelast_test.go`):
- `TestCloseLastTabCtrlW` and `TestCloseLastTabClick` (after a turn on the only tab, `Ctrl+W` via
  `m.Update(tea.KeyMsg{Type: tea.KeyCtrlW})`, respectively `clickBar(m, zoneCol(t, m, tabZoneClose, 0))`):
  exactly 1 tab, a new non-nil session ≠ old, no blocks, empty input history, `m.ctx.Err() == nil`
  (quit cancels that context), the returned command run in a goroutine yields no `tea.QuitMsg`
  within 200 ms (it blocks on the new session's events: do not wait for it),
  `sessionFiles(t, startDir)` is empty.
- `TestCloseLastTabBusy` (provider `providertest.Response{Text: "late", Delay: 30 * time.Second}`,
  Enter, `waitBusy`, `Ctrl+W`: the old session finishes within `waitSession`'s 10 s; 1 fresh tab).
- `TestCloseLastTabTwoTabs` (2 tabs: `Ctrl+W` leaves 1 tab, no quit, the closed tab was saved as before).
- `TestCloseLastTabNewSessionError` (`NewSession` returns an error: one error block, the tab and
  session unchanged, no quit).
- `TestCloseLastTabExitStillQuits` (`/exit` returns a command whose message is `tea.QuitMsg`).
