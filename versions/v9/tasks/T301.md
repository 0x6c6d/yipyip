# T301: resetTab helper

Phase 3 · Model: opus: turn and subagent cancellation, pending approvals/questions, Consequential A2/A3 (no save) · Depends-on: T000 · Covers: R73 and R74 (shared mechanism), A2, A3, A4, A5, A6

## Brief
In `internal/tui/tabs.go` add one shared helper that replaces the **current** tab in place by a
fresh, empty tab. It is used later by `/clear` (keeps the input history) and by closing the last
tab (keeps nothing); this task adds only the helper and its tests, no caller.

```go
// resetTab replaces the live current tab in place by a fresh tab with a new agent session
// (global model, effort and mode) and an empty transcript. ...
func (m *Model) resetTab(keepHistory bool) error
```

Existing pieces in `internal/tui`: `tab` (per-tab state; the Model embeds the current tab, so
`m.sess`, `m.blocks`, `m.hist`, `m.pastes`, `m.queue`, `m.saved`, `m.turnActive`, … are the current
tab's), `newTab(parent context.Context, sess *agent.Session) tab`, `m.newSession()` (builds a
session through `Options.NewSession`; `(nil, nil)` for a session-less model, `errNewTab` on
failure), `m.globals()`, `m.denyPending()` (`approval.go`), `m.cancelQuestions()` (`question.go`),
`m.stopPump`, `m.tabs` (copy-on-write slice: clone before writing), `m.cur`, `m.ctx`, `m.sel`,
`m.input`, `m.refreshTo(follow bool)`. `closeTab` shows how a tab is torn down today.

Order of work (A4: on error nothing changes):
1. `sess, err := m.newSession()`; on error return it and change nothing at all.
2. Read `model, effort, mode := m.globals()` **before** replacing anything and apply them to the
   new session with `RestoreModelEffortMode` (when it is not nil).
3. Tear down the old tab like a close: `m.denyPending()` (pending approvals answered Deny),
   `m.cancelQuestions()` (pending questions answered Cancelled), `old.Cancel()` on the old
   session if any (cancels the running turn and its subagents), `m.stopPump()` if set (the old
   event pump ends; late events of the old session find no tab via `tabOf` and are dropped, A6).
4. Build `nt := newTab(m.ctx, sess)`; with `keepHistory` set `nt.hist, nt.pastes = m.hist, m.pastes`.
   Everything else is fresh: blocks, queue, subagent blocks, turn state (`turnActive`, turn clock,
   `interrupted`, `retryStatus`), `turnStarts`, `rmPending`, and a new `saveState` (the fresh
   session gets a new id on its first save, A2).
5. Install it: `m.tab = nt`, then clone `m.tabs` and set `m.tabs[m.cur] = nt`; clear `m.sel`;
   without `keepHistory` also reset the input (`m.input.Reset()`, empty draft); with it the input
   draft stays as it is. Call `m.refreshTo(true)` so the viewport shows the empty transcript.

It never saves the old tab (no `saveTab`) and never deletes an existing session file (A2, A3).
It does not add any transcript line (the callers do). It does not start the new event pump: the
caller returns `m.waitEvent()`. The tab count and `m.cur` never change.

**Tests** in a new `internal/tui/reset_test.go`:
`TestResetTabKeepHistory` (after a turn, with 2 tabs and tab 0 current: `resetTab(true)` → still 2
tabs, `m.cur == 0`, new non-nil session ≠ old, `m.tabs[0].sess == m.sess`, no blocks, same `m.hist`
pointer, `tabOf(old) == -1`, the globals unchanged, the fresh session's `History()` has 1 entry,
no session file written), `TestResetTabFresh` (`resetTab(false)`: new empty history, input empty),
`TestResetTabBusy` (provider `providertest.Response{Text: "late", Delay: 30 * time.Second}`; submit
with Enter, `waitBusy`; `resetTab(true)`; the old session finishes within `waitSession`'s 10 s;
`m.turnActive` false; the queue is empty), `TestResetTabDeniesApproval` (manual mode, a scripted
tool call that needs approval; once it is pending, `resetTab(true)`: the old turn ends, the tool
did not run, `m.pending` is empty; follow the setup of the existing approval tests),
`TestResetTabNewSessionError` (`newSessionModelOpts` with `NewSession` returning an error:
`resetTab` returns an error and `m.sess`, `m.blocks`, `m.tabs` are unchanged),
`TestResetTabKeepsSavedFile` (call `m.saveTab()` first: after `resetTab(true)` exactly the same
one file with the same bytes exists).

## Verification
`scripts/verify/v9/T301.sh` exits 0. It runs the six named tests and probes of the in-place reset
(tab count, session, history pointer, globals, no file) and of a busy reset (the old turn ends); the

and `make check`.
