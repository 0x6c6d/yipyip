# Plan v9: /clear in place, last tab replaced, rendered markdown

_Source: `versions/v9/spec.md` (2026-10-27). Core plan: `Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R73 `/clear` resets the current tab in place; R74 closing the last
tab leaves one fresh empty tab, no quit, no save; R75 own stdlib renderer `internal/tui/markdown.go`
for assistant blocks (tables, headings, emphasis, inline code, strike, lists, quotes, rules, links);
R76 fences keep chroma, incomplete markdown renders as plain text; R77 copy = rendered, redacted view
text; changed: `/help`, `docs/usage.md`, README `## Usage` line, CLAUDE.md tui line, old tests.
**Explicitly deferred:** spec §7 (markdown in user/tool/subagent blocks, images, HTML, footnotes,
task lists, reference links, clickable links, raw-mode switch; `/new`, Ctrl+T, tab limit, exit save).

## Architecture changes
- **new `internal/tui/markdown.go`**: `renderMarkdown(src string, width int) string`, pure and
  stdlib-only (+ existing lipgloss, chroma via `Highlight`, `x/ansi` for widths/wrap); line-based block
  pass (fence, table, heading, list, quote, rule, paragraph), then an inline pass for non-code text.
- **changed `internal/tui/blocks.go`**: `blockAssistant` = redact → `renderMarkdown(text, width-2)`
  (the `● `/2-space indent) → secret guard → `indentContinuation`; other block kinds unchanged.
- **changed `internal/tui/highlight.go`**: `highlightFences` stays; the renderer reuses its fence
  rules (` ``` ` at any indent, first word = lang, closed fence → `Highlight`, unclosed → plain rest).
- **changed `internal/tui/tabs.go`**: new shared `resetTab(keepHistory bool)`: deny pending
  approvals, cancel questions, `sess.Cancel()`, stop the pump, fresh session via `newSession()` with
  the globals, fresh `tab` (new `saveState`); used by `/clear` (keeps `hist`+`pastes`) and by
  `closeTab` when one tab is left (keeps nothing, no `saveTab`).
- **changed `internal/tui/commands.go`/`help.go`**: `/clear` → own `cmdClear`; `/new` unchanged.
