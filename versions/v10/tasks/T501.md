- `autosave_test.go`: `TestAutosaveAfterTurn` (one turn, no exit: a session file exists in `<start>/.yipyip/sessions`), `TestAutosaveSpacing` (fake clock via `tui.Options.Now`: tool-call turn; checkpoint autosaves respect 1 minute), `TestAutosaveErrorOnce` (sessions dir made read-only: exactly one `could not autosave session` line across three failing saves; skip when running as root), `TestAutosaveInterruptedResume` (an autosave taken mid-turn is `interrupted`; reopening it through the resume path and submitting a message makes the fake provider receive a valid request without a dangling tool call), `TestAutosaveExitSingleFile` (turn, autosave, `/exit`: one file, same id).
- `retention_test.go`: `TestRetentionStartup` (build the binary without testPanic, 30 session files, run it headless so that startup prune runs and `--help`-free exit is reached; if the UI cannot start without a TTY, call the exported startup path through `cmd/yip`'s existing test seam instead and say so), `TestRetentionOpenTabProtected` (TUI env with 2 tabs, 30 old files: after saves the two open tab files remain even when the oldest).
