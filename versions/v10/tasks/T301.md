# T301: Store.Prune

Phase 3 · Model: opus: deletes user files; data-loss risk and path confinement · Depends-on: T000 · Covers: R85

## Brief
In `internal/session/store.go` add (exact signature; supervisor probes compile against it):

```go
// Prune deletes the oldest session files so that at most keep valid sessions remain ...
func (s *Store) Prune(keep int, protect ...string) error
```

Rules:
1. Order: `s.List()` order (newest first by `updated`, then `created`). Sessions are the files `List` returns (valid JSON, version 1). Keep the first `keep` of them; delete the rest, except ids in `protect` (and any id for which `data.ID` equals a protected id), which are never deleted even if that leaves more than `keep` files. Protected sessions still count toward `keep` (they use up places in the newest list: do not delete an unprotected newer file to make room).
2. Only files named exactly `<12 lowercase hex>.json` (the `idPattern`) are ever deleted. Other files (`notes.txt`, `abc.json`, temp files, directories) are never touched. A file that `List` skipped (invalid JSON or version ≠ 1) is neither counted nor deleted.
3. Every path goes through the store's `resolve` (PathGuard): a `.yipyip` or `sessions` symlink escaping the start directory makes `Prune` return an error and delete nothing. A missing sessions directory returns nil. `keep <= 0` returns an error and deletes nothing (it never means "delete all").
4. Deletes use `s.Delete(id)`; a delete failure is remembered, the rest still runs, and the first error is returned at the end.

Tests (names exact, `internal/session/store_test.go` or a new `prune_test.go`; write files with explicit `updated` stamps, one second apart): `TestPruneKeepsNewest` (30 files, keep 25: the 25 newest remain), `TestPruneProtect` (2 old protected ids survive: 27 left), `TestPruneStrayFilesUntouched` (`notes.txt`, `abc.json`, a subdirectory, a temp file remain), `TestPruneInvalidJSONNotCounted` (an invalid-JSON `<12hex>.json` stays and does not use a place), `TestPruneMissingDir`, `TestPruneKeepNotPositive`, `TestPruneSymlinkEscape` (sessions dir symlink to a directory outside the start dir: error, outside files intact), `TestPruneUnderKeepNoop`.
