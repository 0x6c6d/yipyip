# T101: internal/crashlog: records, redaction, cap, perms

Phase 1 · Model: opus: new security-relevant writer (confinement, redaction, secrets in a file) · Depends-on: T000 · Covers: R78 (record format), R79 (cap), R80

## Brief
Create the package `internal/crashlog` (files `crashlog.go`, `crashlog_test.go`). Standard library only: it must NOT import `yipyip/internal/...` (so `internal/tools` and `internal/agent` can import it without a cycle). Exact exported API (supervisor probes compile against it):

```go
package crashlog

const (
	MaxBytes  = 1 << 20   // the log is cut when it grows past this
	KeepBytes = 512 << 10 // ... down to at most this
)

// Options configures a Logger.
type Options struct {
	Version   string                           // the `yip --version` string
	Redact    func(string) string              // applied to the panic value and the stack; nil = identity
	Resolve   func(rel string) (string, error) // maps a path relative to the start dir to an absolute, confined path (main passes tools.PathGuard.Resolve); required
	SessionID func() string                    // optional: id of the active tab's saved session, "" = none known
}

type Logger struct{ /* unexported */ }

func New(o Options) *Logger
func (l *Logger) Path() (string, error)            // l.Resolve(".yipyip/crash.log")
func (l *Logger) Fatal(v any) (path string, err error)       // record kind "fatal"; stack of the calling goroutine
func (l *Logger) Recovered(where string, v any)              // record kind "recovered"; call it inside a deferred func right after recover(); never panics, never returns an error
func SetDefault(l *Logger)                                   // package default, safe for concurrent use; nil clears it
func Default() *Logger
func Recovered(where string, v any)                          // = Default().Recovered; no-op while no default is set
```

Record format (appended to the file; one record per call):

```
=== yip crash 2026-10-28T12:00:00Z fatal ===        (kind: fatal | recovered; RFC 3339 UTC)
version: <Options.Version>
where: <where>                                         (recovered records only)
session: <id>                                          (only when SessionID() returns non-empty)
panic: <fmt.Sprint(v), redacted>
stack:
<runtime/debug.Stack() text of the current goroutine, redacted>
=== end ===
```

Rules:
1. Redaction: `Redact` is applied to the panic text and to the stack text (each as one string) before anything is written. Nothing else is ever written: no history, prompts, tool arguments or outputs. Write the version with the same `Redact` too.
2. Writing: `path := Resolve(".yipyip/crash.log")`; create the directory with `os.MkdirAll(dir, 0o700)` (an existing directory keeps its mode), open with `O_APPEND|O_CREATE|O_WRONLY` and mode `0o600`; append the whole record with one `Write` under a package-level mutex. If `Resolve` fails (e.g. symlink escape) nothing is written to disk.
3. `Fatal`: on any write or resolve error, write the same record to `os.Stderr` and return the error; on success return the path. `Recovered`: on error write the record to `os.Stderr` as well, return nothing.
4. Cap: after an append, if the file is larger than `MaxBytes`, drop the oldest whole records (a record starts at a line beginning with `=== yip crash `) until it is at most `KeepBytes`. If the newest record alone exceeds `KeepBytes`, keep its head cut at a line boundary and end it with `=== end ===`. Rewrite atomically (temp file in the same dir with mode 0600, then `os.Rename`).
5. A `Logger` is safe for concurrent use; a nil `*Logger` is valid and does nothing (`Fatal` on nil returns `"", nil`).

Tests (names exact, in `crashlog_test.go`, using `t.TempDir()` and `Resolve: func(rel string)(string,error){return filepath.Join(dir, rel), nil}`): `TestCrashlogRecordFormat` (time, version, panic, stack containing the test function's name), `TestCrashlogRecoveredMarked` (kind `recovered` and the `where:` line, stack taken inside a deferred recover contains the panicking function), `TestCrashlogSessionID`, `TestCrashlogPerms` (dir 0700 when created, file 0600; an existing dir keeps its mode), `TestCrashlogCap` (several large records push past `MaxBytes`: file ≤ `KeepBytes`, newest record intact, starts with a record header), `TestCrashlogCapSingleHugeRecord`, `TestCrashlogRedacts` (`Redact` replacing `SECRET123` with `[redacted]`: neither value nor stack nor version contains it), `TestCrashlogResolveError` (Fatal returns the error, writes to stderr (redirect `os.Stderr` in the test), creates no file), `TestCrashlogNoDefaultNoop`, `TestCrashlogConcurrent` (20 goroutines, `-race` clean, every record intact).
