# Plan v10: Crash resistance

_Source: `versions/v10/spec.md` (commit `1ccbbc7`), 2026-10-28. Core plan: `Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R78-R85: crash log (`internal/crashlog`), fatal-panic path with exit code 2,
recovered-panic logging, main-agent history checkpoints, session autosave (turn end + after checkpoints, ≥1 min
apart), autosaved sessions resumable, subagent/render-block containment, session retention (newest 25).
**Explicitly deferred:** everything in spec §7 (upload, verbose log, restart, resuming a running turn, SIGKILL/OOM).

## Architecture changes
- **New `internal/crashlog`** (stdlib only): `New(Options{Version, Redact, Resolve, SessionID})`, `Logger.Fatal/Recovered/Path`,
  package default (`SetDefault`, `Default`, `Recovered`, nil-safe). Writes only `.yipyip/crash.log` through the injected `Resolve`
  (main passes `tools.PathGuard.Resolve`, so crashlog never imports `tools`: no import cycle, registry can call it).
- **cmd/yip**: builds the logger after `config.Load` (redactor = `cfg.Redactor.Redact`), `SetDefault`; recovers fatal panics of
  `main`/`runUI`/`launchUI` → `Fatal`, stderr line, exit 2; `ErrProgramPanic` from `p.Run` with no record yet → fallback record.
  Test seam: ldflags-set `main.testPanic` (`launch`, `main`, `leak`; no env var in the shipped binary). Startup `Store.Prune(25, resumedID)` after `applyResume`.
- **internal/tui**: panic guard model wrapping Init/Update/View (+ returned Cmds) that records then re-panics so Bubble Tea still
  restores the terminal; per-block render guard (`[render error]`); autosave (`saveState` gets a mutex, last-autosave time, in-flight
  flag, error-shown flag; `Options.Autosave` seam, default `Store.Save`); handles `agent.EvCheckpoint`; exit save waits for
  in-flight autosaves.
- **internal/agent**: `Session.checkpoint` (main agent only: replaces `s.history` with a copy of the working history after each
  complete round, if `gen` matches) + `EvCheckpoint`; recovered panics in `runTurn`, `safeRun`, provider stream goroutine
  (→ `ErrorEvent`) and tool `Registry.Run` call `crashlog.Recovered`.
- **internal/session**: `Store.Prune(keep int, protect ...string) error`.
- **internal/tools**: `registry.go` recover logs via `crashlog.Recovered` (output text unchanged).

## Build Phases
### Phase 0: Preflight
- **Checks:** `go version | grep -q go1.27`; `git cat-file -e 1ccbbc7`; `git status --porcelain -- cmd internal e2e go.mod go.sum` empty; `make check` exits 0.
### Phase 1: Crash log and fatal path (walking skeleton)
- **Goal:** a forced panic in the shipped binary's UI path leaves a redacted record in `crash.log`, exit 2.
- **Key deliverables:** `internal/crashlog`; `cmd/yip` recovery + exit 2 + test seam; tui panic guard.
- **Exit criterion:** `go test ./internal/crashlog ./cmd/yip ./internal/tui -run 'Crashlog|Crash' -count=1`
### Phase 2: Recovered panics and checkpoints
- **Goal:** recovered panics are logged; a recovered turn keeps its completed rounds.
- **Key deliverables:** `crashlog.Recovered` at the 4 recover sites; `checkpoint` + `EvCheckpoint`.
- **Exit criterion:** `go test ./internal/agent ./internal/tools ./internal/provider -run 'PanicRecovered|Checkpoint' -count=1`
### Phase 3: Autosave and retention
- **Goal:** sessions survive a crash; the directory stays at 25 files.
- **Key deliverables:** `Store.Prune`; TUI autosave + exit-save coordination; startup prune.
- **Exit criterion:** `go test ./internal/session ./internal/tui ./cmd/yip -run 'Prune|Autosave|StartupPrune' -count=1`
### Phase 4: Containment
- **Goal:** a subagent panic and a block render panic no longer take anything else down.
- **Key deliverables:** subagent panic test + log; per-block render guard.
- **Exit criterion:** `go test ./internal/agent ./internal/tui -run 'SubagentPanic|RenderGuard' -count=1`
### Phase 5: e2e, docs, Definition of Done
- **Goal:** the whole behavior proven end to end; documentation current.
- **Key deliverables:** `e2e/crash_test.go`, `e2e/autosave_test.go`, `e2e/retention_test.go`; `docs/usage.md` section; `CLAUDE.md` notes.
- **Exit criterion:** `go test ./e2e/... -run 'Crash|Autosave|Retention' -count=1`
