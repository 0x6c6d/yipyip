## Build Phases
### Phase 0: Preflight
- **Checks:** `go version | grep -q 'go1.27'`; `make --version`; `git --version`; `command -v gofmt`;
  `echo "$PATH" | tr ':' '\n' | grep -qx "$(go env GOPATH)/bin"`;
  `test "$(git rev-parse --show-toplevel)" = /home/sa/workspace/code/yipyip`;
  `test -z "$(git status --porcelain | grep -vE ' (Plan\.md|versions/|scripts/verify/)')"`;
  `go mod download -json github.com/charmbracelet/bubbles@v0.21.1 >/dev/null` (proxy reachable).
### Phase 1: Skeleton (walking skeleton)
- **Goal:** thinnest runnable slice: `go.mod` (`go 1.27`, pinned deps), `Makefile`, `cmd/yip`
  with `--version`/`--help`, stub config load, TUI with input + status line that quits on `/exit`.
- **Key deliverables:** `cmd/yip/main.go`, `internal/{config,tui}` stubs, `.gitignore` (`bin/`).
- **Exit criterion (machine-checkable):** `make check && go run ./cmd/yip --version | grep -q '^yip '`
### Phase 2: Config, provider, transport
- **Goal:** R1, R2, R3 (transport), redactor part of R16; `providertest` fake SSE server.
- **Key deliverables:** `internal/config` (+ `redact.go`), `internal/provider` (+ `transport.go`).
- **Exit criterion (machine-checkable):** `go test ./internal/config ./internal/provider`
### Phase 3: Tools
- **Goal:** R4, R5, tool registry without web tools (R3), pre-write hook for undo.
- **Key deliverables:** `pathguard.go`, `bash.go`, file tools, glob `**`, grep, registry.
- **Exit criterion (machine-checkable):** `go test ./internal/tools`
### Phase 4: Agent core
- **Goal:** R6 loop + cancellation, R7 approval gate, R8 subagents, token accounting.
- **Key deliverables:** `internal/agent` session, loop, `approval.go`, subagent manager, events.
- **Exit criterion (machine-checkable):** `go test ./internal/agent`
### Phase 5: TUI
- **Goal:** R7 (Shift+Tab, `/mode`), R9, R10, R11, R15: rendering, commands, picker, panel.
- **Key deliverables:** `internal/tui` model, views, command dispatcher, completion, highlight.
- **Exit criterion (machine-checkable):** `go test ./internal/tui`
### Phase 6: Session commands
- **Goal:** R12 `/init`, R13 `/compact` + auto-compact, R14 `/undo` incl. subagent writes.
- **Key deliverables:** agent compaction + undo journal + init prompt; `e2e/` tests.
- **Exit criterion (machine-checkable):** `go test ./e2e -run 'Init|Compact|Undo'`
### Phase 7: Hardening & delivery
- **Goal:** R16 end-to-end, R17 install, R18 audit, docs: `config.example.json`, README `## Usage`.
- **Key deliverables:** `TestSecret*` across packages, `make install`, Usage section.
- **Exit criterion (machine-checkable):** `make check && go test ./... -run Secret && make install && (cd / && yip --version | grep -q '^yip ')`
