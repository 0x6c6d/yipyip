# T503: Slash-command dispatcher, completion and Shift+Tab

Phase 5 · Model: sonnet: command dispatch and key handling · Depends-on: T502 · Covers: R7, R10, R11

## Brief
In `internal/tui` (new file `commands.go`) replace the temporary command handling with a
dispatcher table `map[string]func(m Model, args string) (Model, tea.Cmd)` used by both Enter and
`Model.Command(line)`. Existing: `Commands()`/`HelpText()` in `help.go`, `Model`, `Drain`,
`EventMsg`. Agent API: `Session.Reset()`, `SetEffort(e) error` (`agent.ErrInvalidEffort`),
`Effort()`, `SetMode(agent.Mode)`, `ToggleMode() agent.Mode`, `Mode()`.

Commands (output goes into the conversation view as a system/info block):
- `/help`: shows `HelpText()`.
- `/new` and `/clear`: `Session.Reset()`, clear the conversation view, show `new session`.
- `/exit` and `/quit`: `tea.Quit` (exit code 0 comes from main).
- `/effort`: no argument → `effort: <current>`; `low|medium|high` → set and show
  `effort: <value>`; anything else → `error: effort must be low, medium or high` (unchanged).
- `/mode`: no argument toggles; `auto`/`manual` set; other → error. Show `mode: <mode>`.
- `Shift+Tab` (`tea.KeyShiftTab`) toggles the mode anywhere (status line shows it).
- `/model`, `/agents`, `/init`, `/compact`, `/undo`: keep a table entry that shows
  `<name>: not available yet` (later tasks replace these entries).
- Unknown `/foo` → `unknown command: /foo`; never sent to the model.
- A line that starts with `/` is always a command.

Completion: while the input starts with `/` and contains no space, show one line above the
input with the matching command names (prefix match, from `Commands()`, e.g. `/mo` → `/model
/mode`); `Tab` completes to the single match or to the longest common prefix. Hide the line
otherwise.

Tests in `internal/tui/commands_test.go` (temp HOME + `providertest` fake + `agent.NewSession`):
`TestHelpCommand` (every command name in the view), `TestNewClearsSession` (`/new` and `/clear`:
history back to 1 message, tokens 0, view cleared), `TestExitQuit` (`/exit`, `/quit` →
`tea.QuitMsg`), `TestEffortCommand` (show, set, invalid), `TestModeCommand`,
`TestShiftTabTogglesMode`, `TestUnknownCommand` (error shown; the fake got 0 requests),
`TestCompletion` (`/mo` shows both; Tab on `/he` completes to `/help`).
