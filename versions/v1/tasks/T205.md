# T205: Streaming chat client and SSE parser

Phase 2 · Model: sonnet: streaming client built on the opus transport · Depends-on: T201, T203, T204 · Covers: R2

## Brief
Create `internal/provider/client.go` and `internal/provider/sse.go` (package `provider`).
`transport.go` exists: get HTTP clients only from it (callers pass one in); never use
`http.DefaultClient`/`http.Get`.

Exported API (contract; keep names and types exactly):
```go
type ToolCall struct{ ID, Name, Arguments string }
type Message struct {
	Role, Content string // "system" | "user" | "assistant" | "tool"
	ToolCalls     []ToolCall
	ToolCallID    string
}
type ToolDef struct {
	Name, Description string
	Parameters        json.RawMessage // JSON schema object
}
type Request struct {
	Model      string // model key sent as "model"
	Messages   []Message
	Tools      []ToolDef
	Effort     string // low|medium|high
	SendEffort bool   // false: omit reasoning_effort
}
type Usage struct{ PromptTokens, CompletionTokens, TotalTokens int }
type EventKind int
const (
	EventText EventKind = iota + 1
	EventToolCall
	EventUsage
	EventDone
	EventError
)
type Event struct {
	Kind     EventKind
	Text     string   // EventText
	ToolCall ToolCall // EventToolCall (complete call)
	Usage    Usage    // EventUsage
	Err      error    // EventError
}
type Client struct{ /* unexported */ }
func NewClient(baseURL, apiKey string, hc *http.Client, red *config.Redactor) *Client
func (c *Client) Stream(ctx context.Context, req Request) <-chan Event
```
Request: `POST <baseURL without trailing "/">/chat/completions`, headers
`Content-Type: application/json`, `Accept: text/event-stream`, `Authorization: Bearer <apiKey>`
only when apiKey is non-empty. Body: `model`, `messages` (OpenAI shape: assistant `tool_calls` as
`[{"id","type":"function","function":{"name","arguments"}}]`, tool messages with
`tool_call_id`; `content` always present as a string), `"stream": true`,
`"stream_options": {"include_usage": true}`, `tools` as
`[{"type":"function","function":{"name","description","parameters"}}]` (omitted when empty),
`reasoning_effort` only when `SendEffort && Effort != ""`.

Stream: read `data:` lines (optional space after the colon; ignore other SSE fields, comments
and blank lines; allow lines up to 1 MiB). `[DONE]` ends the stream. For each JSON chunk: every
non-empty `choices[0].delta.content` → `EventText`; `delta.tool_calls` accumulate by `index` (id
and name when present, arguments appended); a `usage` object in any chunk is remembered. At the
end emit the complete tool calls in index order (`EventToolCall`), then `EventUsage` if usage was
seen, then exactly one final `EventDone`, then close the channel. Never block forever on a send:
select on `ctx.Done()`.

Errors in this task only need to be non-crashing: a non-2xx status → one final `EventError`
(`HTTP <code>`) and close. A later task hardens error handling; keep it in one function
(e.g. `func (c *Client) fail(...)`) so it is easy to extend.

Tests in package `provider_test` (external test package, so it can import `providertest`), file
`client_test.go`: `TestRequestPathAndHeaders`, `TestRequestBodyFields` (stream, stream_options,
reasoning_effort present and absent, tools), `TestTextDeltas`, `TestToolCallArgsSplit`,
`TestUsageParsing`. Build the HTTP client with `provider.NewHTTPClient([]string{srv.URL})`.
