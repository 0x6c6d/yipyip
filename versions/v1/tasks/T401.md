# T401: Approval gate

Phase 4 · Model: opus: the only path from a gated tool call to execution (Consequential A6, Risk "Approvals") · Depends-on: T101 · Covers: R7, R8

## Brief
Create `internal/agent/approval.go` (package `agent`, standard library only). Later tasks route
every gated tool call of the main agent and of subagents through `Gate.Check`; nothing else may
decide approvals (shared-code rule).

Exported API (contract; keep names and types exactly):
```go
type Mode string
const (
	ModeManual Mode = "manual"
	ModeAuto   Mode = "auto"
)
type Decision int
const (
	Deny Decision = iota // "n"
	Allow                // "y"
	AllowAlways          // "a": always for this tool this session
)
const DeniedMessage = "denied by user"
const MainAgentID = "main"
type ApprovalRequest struct {
	AgentID string // MainAgentID or a subagent id like "a1"
	Tool    string
	Args    string // raw JSON arguments as sent by the model
	/* unexported: reply channel (buffered 1), once */
}
func (r *ApprovalRequest) Respond(d Decision) // non-blocking; first call wins, later calls ignored
func IsGated(tool string) bool // true for bash, write_file, edit_file, spawn_agent; false otherwise
type Gate struct{ /* unexported */ }
func NewGate(notify func(*ApprovalRequest)) *Gate
func (g *Gate) Check(ctx context.Context, mode Mode, agentID, tool, args string) (bool, error)
func (g *Gate) Reset()
```
Behaviour of `Check`:
- Not gated, or `mode == ModeAuto`, or the tool is in the "always" set → `(true, nil)` at once,
  `notify` is not called.
- Otherwise build a request, call `notify(req)` synchronously (notify must not block; it may
  call `Respond` itself, at once or later from another goroutine), then wait for the decision
  or `ctx.Done()`:
  `Allow` → `(true, nil)`; `AllowAlways` → add the tool to the always set, `(true, nil)`;
  `Deny` → `(false, nil)`; ctx done → `(false, ctx.Err())`.
- The always set is per tool, shared by all agents of the session (main and subagents use the
  same Gate); `Reset()` clears it (used by `/new`). Switching to manual mode re-enables prompts
  for every tool not in the set (mode is passed per call, nothing to store).
- Concurrent `Check` calls (several subagents) each get their own request; safe for concurrent
  use. A nil `notify` behaves like an immediate `Deny`.

Tests in `internal/agent/approval_test.go`: `TestGateManualPromptsGated` (bash, write_file,
edit_file, spawn_agent prompt), `TestGateReadsNeverPrompt` (read_file, glob, grep, wait_agent,
cancel_agent), `TestGateDeny`, `TestGateAlwaysPerTool`, `TestGateAutoNeverPrompts`,
`TestGateReset`, `TestGateCancel` (unanswered request + ctx timeout returns an error within 2 s),
`TestGateLabel` (AgentID/Tool/Args on the request; first Respond wins).
