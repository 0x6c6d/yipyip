# T502: Status line

Phase 5 · Model: sonnet: one view component with exact format · Depends-on: T501 · Covers: R15, R7, R10

## Brief
Implement the real status line in `internal/tui` (new file `status.go`; `StatusLine()` and the
layout in `model.go` already exist). Agent API: `Session.ModelID()`, `Effort()`, `Mode()`
(`agent.ModeManual`/`ModeAuto`), `ReasoningEnabled()`, `Tokens() agent.Tokens{In, Out, Total}`,
`ContextSize() (used, limit int)`, `StartDir()`.

`StatusLine()` returns one line, rendered directly under the input box in `View()`:
```
<cwd> · <provider/model> · <effort> · <mode> · in <In> / out <Out> / total <Total> · ctx <used>[/<limit>]
```
- Separator ` · ` (U+00B7 with spaces). `<cwd>` is the start directory; when the line is wider
  than the terminal, shorten the cwd from the left with a leading `…` (never drop the other
  fields). `no model` when the session has none.
- Numbers are plain integers (no k/M abbreviation, no thousands separators), so
  `in 100 / out 20 / total 120`. `/<limit>` is omitted when the limit is 0.
- Effort is rendered dimmed (lipgloss `Faint`) when `ReasoningEnabled()` is false, but still
  shown.
- The status line updates on every render (it reads the session each time, so token changes
  after `Drain()` show up).
- Nothing in `View()`, `StatusLine()` or `HelpText()` may contain `cost`, `price` (any case) or
  `$` (check the rendered strings including ANSI styling).

Tests in `internal/tui/status_test.go` (all names start with `TestStatus` so that
`go test ./internal/tui -run Status` selects them; temp HOME + `providertest` fake +
`agent.NewSession` as in the existing session tests): `TestStatusLineFields` (cwd, `fake/m1`,
`medium`, `manual`), `TestStatusTokensAfterUsage` (fake reply with usage prompt 100 / completion
20 → status contains `in 100 / out 20 / total 120`), `TestStatusContextSize` (`ctx 100/8000`),
`TestStatusModeShown` (after `SetMode(agent.ModeAuto)` → `auto`), `TestStatusNoCost` (view,
status line and help text contain none of `cost`, `price`, `$`), `TestStatusNarrow` (width 40:
still contains `in 0 / out 0 / total 0`).
