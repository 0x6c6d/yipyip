# T104: TUI skeleton and main wiring

Phase 1 · Model: sonnet: first Bubble Tea model, new pattern · Depends-on: T102, T103 · Covers: R15, R11, R17

## Brief
Add the Bubble Tea UI skeleton and start it from `cmd/yip`.

Dependencies: `go get github.com/charmbracelet/bubbletea@v1.3.10 github.com/charmbracelet/bubbles@v0.21.1 github.com/charmbracelet/lipgloss@v1.1.0`
(these exact versions; then `go mod tidy`). No other third-party module.

Create `internal/tui/model.go` (package `tui`; `help.go` already exists, keep it):
```go
type Options struct {
	StartDir string
	ModelID  string // "" = no model
	Effort   string // "" = "medium"
	Mode     string // "" = "manual"
}
type Model struct{ /* unexported */ }
func New(opts Options) Model
func (m Model) Init() tea.Cmd
func (m Model) Update(msg tea.Msg) (tea.Model, tea.Cmd) // returns a tui.Model value
func (m Model) View() string
func (m Model) StatusLine() string
```
Behaviour:
- Layout top to bottom: conversation (bubbles `viewport`), bordered multi-line input (bubbles
  `textarea` inside a lipgloss rounded border), one status line under the input.
- `Enter` submits the input; `Alt+Enter` inserts a newline (configure the textarea KeyMap so
  plain Enter does not insert a newline). Handle `tea.WindowSizeMsg` (resize all parts).
- Submitted text `/exit` or `/quit` → `Update` returns `tea.Quit`. Any other text is appended to
  the conversation as `> <text>`, followed by the line `no model configured` (there is no agent
  yet), and the input is cleared.
- `StatusLine()` returns exactly
  `<StartDir> · <ModelID or "no model"> · <Effort> · <Mode> · in 0 / out 0 / total 0 · ctx 0`
  (separator is ` · `, U+00B7 between spaces); `View()` contains it under the input.
- Never print the words cost/price or a `$`.

Change `cmd/yip/main.go`: keep `--version`/`--help` first and untouched (no config access). With
no arguments: start dir = `filepath.EvalSymlinks(os.Getwd())`; home = `os.UserHomeDir()`;
`config.Load(home, startDir, os.Getenv)`; any error → `yip: <error>` on stderr and return 1.
Then run `tea.NewProgram(tui.New(tui.Options{StartDir: startDir, ModelID: cfg.DefaultModel}), tea.WithAltScreen()).Run()`;
a program error → stderr, return 1; normal quit → return 0.

Tests (`internal/tui/model_test.go`; drive `Update` with messages, assert on `View()`; no
teatest): `TestSkeletonExit` (typing `/exit` then Enter returns a command whose message is
`tea.QuitMsg`; same for `/quit`), `TestSkeletonStatusLine` (start dir, `no model`, `medium`,
`manual`, `in 0 / out 0 / total 0`), `TestSkeletonEcho` (a typed line appears as `> line`).
`cmd/yip/main_test.go`: add `TestConfigErrorExitCode` (`t.Setenv("HOME", tmp)`, `t.Chdir(dir)`
with an invalid `yipyip.json`; `run(nil, ...)` returns 1 and stderr names `yipyip.json`).
