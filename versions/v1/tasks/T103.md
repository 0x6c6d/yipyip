# T103: Config loader: files, deep merge, defaults

Phase 1 · Model: sonnet: merge semantics need moderate judgment, no secrets yet · Depends-on: T101 · Covers: R1

## Brief
Create `internal/config/config.go` (package `config`, standard library only). A later task adds
`{env:NAME}` substitution, provider/model parsing and secrets; keep the code easy to extend.

Exported API (contract: later tasks and supervisor probes compile against it; keep names and
types exactly, parameter names may differ):
```go
const ProjectFile = "yipyip.json"
func GlobalPath(home string) string // filepath.Join(home, ".config", "yipyip", "config.json")
func Merge(base, override map[string]any) map[string]any
type Config struct {
	DefaultModel string         // "default_model", "" when absent
	MaxSubagents int            // "max_subagents", default 4 when absent or <= 0
	AutoCompact  bool           // "auto_compact", default true when absent
	Raw          map[string]any // the merged JSON object
}
func Load(home, startDir string, getenv func(string) string) (*Config, error)
```
Behaviour:
- `Load` reads `GlobalPath(home)` and `filepath.Join(startDir, ProjectFile)`. A missing file is an
  empty object (no error). The project file overrides the global one via `Merge`.
- `Merge` is recursive: when both values are JSON objects they are merged key by key; any other
  value (string, number, bool, array, null) from `override` replaces the base value. Neither
  input map is modified.
- Unreadable file, invalid JSON, or a top-level value that is not an object → error that names the
  file path (and the JSON error); never include file contents in the error.
- Wrong types for the three known keys (e.g. `"max_subagents": "x"`) → error naming the key.
- Unknown keys are kept in `Raw` and otherwise ignored. `getenv` is unused for now (may be nil);
  keep the parameter.
- `Load` never writes anything to disk.

Tests in `internal/config/config_test.go` (use `t.TempDir()` for home and start dir; never the
real HOME): `TestLoadGlobal`, `TestProjectOverride` (a nested `provider.<id>.models` map in the
project file adds/changes one key while the other global keys survive; a scalar is replaced),
`TestLoadMissingFiles` (defaults 4 / true / ""), `TestLoadInvalidJSON` (error names the file),
`TestMergeDoesNotMutate`.
