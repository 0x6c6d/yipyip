# T302: Bash runner

Phase 3 · Model: opus: shell execution, process-group kill and env stripping (Risks "bash", "Secrets") · Depends-on: T101 · Covers: R5, R16

## Brief
Create `internal/tools/bash.go` (package `tools`, standard library only). It is the ONLY place in
non-test code that uses `os/exec` (shared-code rule).

Exported API (contract; keep names and types exactly):
```go
const (
	DefaultTimeout = 120 * time.Second
	MaxTimeout     = 600 * time.Second
	MaxOutputChars = 30000
)
type BashResult struct {
	Output   string // combined stdout+stderr, already truncated with Truncate
	ExitCode int    // process exit code; -1 when killed (timeout/cancel) or not started
	TimedOut bool
	Canceled bool
}
type BashRunner struct {
	Dir      string   // working directory (the start directory)
	StripEnv []string // variable names removed from the child environment
}
func (b *BashRunner) Run(ctx context.Context, command string, timeout time.Duration) BashResult
func ClampTimeout(d time.Duration) time.Duration // <= 0 → DefaultTimeout; > MaxTimeout → MaxTimeout
func Truncate(s string) string
```
Behaviour:
- Runs `bash -c <command>` in `Dir`, stdin from `/dev/null`, stdout and stderr into one buffer
  (combined, in arrival order). The command string is passed as one argument, never
  interpolated into another shell string.
- Own process group (`SysProcAttr.Setpgid = true`). On timeout (`ClampTimeout(timeout)`) or when
  `ctx` is done: kill the whole group (`syscall.Kill(-pgid, SIGKILL)`), set `TimedOut` or
  `Canceled`, `ExitCode = -1`, return within about 1 s (use `cmd.WaitDelay` so background
  children holding the pipes cannot block `Wait`). Background children of the command die too.
- Environment: `os.Environ()` minus every variable whose name is in `StripEnv` (exact names);
  everything else (PATH, HOME, ...) is kept.
- Output memory stays bounded (do not keep more than about 1 MiB), but the omitted-character count
  in the marker must be exact.
- `Truncate(s)`: if `s` has more than 30,000 characters (runes), keep the first 30,000 and append
  `"\n[output truncated: N characters omitted]"` (N = omitted runes); otherwise return `s`.
- A command that cannot be started → `ExitCode -1` and the error text in `Output`.

Tests in `internal/tools/bash_test.go`: `TestBashExitCode`, `TestBashCombinedOutput`,
`TestBashDir`, `TestBashTimeout` (1 s timeout on `sleep 30` returns in < 5 s, `TimedOut`),
`TestBashTimeoutKillsGroup` (a background child that would create a marker after 2 s never
does), `TestBashCancel`, `TestBashTruncation` (35,000 chars → marker with 5000; multi-byte
counted as runes), `TestClampTimeout`, `TestSecretBashEnv` (a variable holding `SECRET123` listed
in `StripEnv` is not visible to the command; `PATH` still is).
