# T603: Compaction (manual and automatic)

Phase 6 · Model: sonnet: model-written summary and history surgery, no security impact · Depends-on: T601 · Covers: R13, R15

## Brief
Create `internal/agent/compact.go` (+ small edits in `loop.go`). Existing: `Session` with history
(`[0]` = system prompt), `Submit`, the reusable model-call code in `loop.go`, token counters
(`Tokens()`, `ContextSize() (used, limit)`), the undo journal in `undo.go` (turn records holding
the history length at the start of each turn), `Config.AutoCompact`.

Add (contract):
```go
var ErrNothingToCompact = errors.New("nothing to compact")
func (s *Session) Compact(ctx context.Context) error // synchronous
```
Definitions: a turn = a `user` message and all messages after it up to the next `user` message.
`Compact`:
- `ErrBusy` while a turn runs; `ErrNothingToCompact` when the history has at most 2 turns.
- Sends one model request WITHOUT tools: the current history followed by a `user` message asking
  for a concise summary of the conversation so far (decisions, files touched, open tasks). The
  reply text is the summary. Its usage (or estimate) is ADDED to the session token totals (the
  total is never reduced by compaction).
- New history = `[system prompt, {role: user, content: "[Summary of the earlier conversation]\n" +
  summary}, <last 2 turns verbatim>]`.
- Undo journal: turn records of the dropped turns are removed; the kept records are re-indexed
  to the new history positions (undo after compaction undoes at most the 2 kept turns).
- Context used after compaction = characters/4 estimate of the new history.
- Emits `EvInfo` `compacted: <old> messages -> <new>`.

Automatic: at the start of `Submit`'s turn (before the first model call), if `Config.AutoCompact`
is true, the model's context limit is known (> 0) and the last prompt size (`ContextSize().used`)
is at least 80% of the limit, run the compaction first (emit `EvInfo` `auto-compacted`). When it
fails (or there is nothing to compact), emit `EvError`/ignore and continue the turn normally.

Tests in `internal/agent/compact_test.go` (`providertest.NewFunc`; detect the summary request by
its last user message): `TestCompactKeepsLastTwoTurns`, `TestCompactTokensNotReduced`,
`TestCompactNothing`, `TestAutoCompactAt80` (limit 1000 via `ConfigJSON(..., 1000)`, usage prompt
800 → the next Submit first sends the summary request), `TestAutoCompactBelowThreshold` (prompt
799 → no summary request), `TestAutoCompactDisabled` (`{"auto_compact": false}` in the project
`yipyip.json` → no summary request at 800).
