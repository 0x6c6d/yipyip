# T303: Tool registry and the `bash` tool

Phase 3 · Model: opus: every tool result passes the redactor here (Consequential A4) and no web tool may exist (R3) · Depends-on: T201, T301, T302 · Covers: R3, R5, R16

## Brief
Create `internal/tools/registry.go` (package `tools`). `pathguard.go` (`NewPathGuard`,
`Resolve`, `ErrOutsideStartDir`) and `bash.go` (`BashRunner`, `ClampTimeout`, `Truncate`) exist:
use them, do not re-implement them. `config.Redactor` (`internal/config/redact.go`,
`Redact(string) string`, nil-safe) exists.

Exported API (contract; keep names and types exactly):
```go
type Result struct {
	Output  string
	IsError bool
}
type Tool struct {
	Name, Description string
	Parameters        json.RawMessage // JSON schema, {"type":"object",...}
	Gated             bool            // needs approval in manual mode
}
type Options struct {
	StartDir    string
	Redactor    *config.Redactor
	StripEnv    []string             // passed to BashRunner
	BeforeWrite func(absPath string) // called by write tools before modifying a file (may be nil)
}
type Registry struct{ /* unexported */ }
func NewRegistry(opts Options) (*Registry, error) // error if the start dir is invalid
func (r *Registry) Tools() []Tool                  // sorted by Name
func (r *Registry) Has(name string) bool
func (r *Registry) Run(ctx context.Context, name string, args json.RawMessage) Result
func (r *Registry) Guard() *PathGuard
```
Design: keep an internal table of built-in tools (`name → {Tool, run func(ctx, json.RawMessage)
Result}`) so later tasks add `read_file`, `write_file`, `edit_file`, `glob` and `grep` by adding
entries (and their own files). This task registers only `bash`.

`bash` tool: schema `{"type":"object","properties":{"command":{"type":"string"},
"timeout_seconds":{"type":"integer","minimum":1,"maximum":600}},"required":["command"]}`,
`Gated: true`. Runs `BashRunner{Dir: Guard().Root(), StripEnv: opts.StripEnv}` with
`timeout_seconds` (default 120, clamped to 600). Output = runner output, then a line
`[exit code: N]`, plus ` [timed out after Ns]` or ` [cancelled]` when applicable. `IsError` when
the exit code is not 0. Missing or non-string `command` → `IsError` result.

`Run` rules: unknown tool → `Result{IsError: true, Output: "unknown tool: <name>"}`; arguments
that are not a JSON object → `IsError` (`invalid arguments: ...`); a panic inside a tool is
recovered into an `IsError` result; EVERY `Output` (errors included) passes
`opts.Redactor.Redact` before it is returned.

Never register a tool for web access: no tool name may contain `web`, `fetch`, `search`,
`browse`, `http`, `url`, `download` or `curl`.

Tests in `internal/tools/registry_test.go`: `TestRegistryNoWebTools`, `TestRegistryUnknownTool`,
`TestRegistryInvalidArgs`, `TestBashToolOutput`, `TestToolSchemasValidJSON` (every tool's
Parameters is a JSON object schema), `TestSecretToolResult` (bash `echo SECRET123` with a
Redactor holding it → Output contains `[redacted]`, not `SECRET123`).
