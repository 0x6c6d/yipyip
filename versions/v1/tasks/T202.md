# T202: `{env:NAME}` substitution, providers and models

Phase 2 · Model: opus: env-variable errors and secret registration (Consequential A4, Risk "Secrets") · Depends-on: T103, T201 · Covers: R1, R16

## Brief
Extend `internal/config` (files `config.go`, new `env.go`, tests). `Load`, `Merge`, `GlobalPath`,
`ProjectFile` and the existing `Config` fields stay as they are; `redact.go` exists (use it, do
not change its behaviour).

Add (contract; keep names and types exactly):
```go
type Config struct {
	DefaultModel string; MaxSubagents int; AutoCompact bool; Raw map[string]any // existing
	Providers map[string]Provider // keyed by provider id
	EnvNames  []string            // sorted unique NAMEs referenced via {env:NAME}
	Redactor  *Redactor           // never nil after Load; holds every resolved {env:} value
}
type Provider struct {
	ID, Name, BaseURL, APIKey string // options.baseURL without trailing "/", options.apiKey
	Models                    map[string]Model // keyed by model key
}
type Model struct {
	ID           string // "<provider id>/<model key>"
	Provider     string // provider id
	Key          string // model key, sent to the API as "model"
	Name         string // "name" or ""
	Reasoning    bool   // "reasoning", default true
	ContextLimit int    // "limit.context", 0 = unknown
}
type MissingEnvError struct{ Name string }
func (e *MissingEnvError) Error() string // "environment variable NAME is not set or empty"
func (c *Config) ModelIDs() []string                         // all model ids, sorted
func (c *Config) Lookup(id string) (Provider, Model, bool)
func (c *Config) DefaultModelID() string // default_model if Lookup succeeds, else first ModelIDs(), else ""
func (c *Config) BaseURLs() []string     // sorted unique non-empty provider base URLs
```
Behaviour:
- After merging, replace `{env:NAME}` (NAME = `[A-Za-z_][A-Za-z0-9_]*`) in every string value at
  any depth (inside objects and arrays; several references per string allowed) with
  `getenv(NAME)` (`getenv == nil` → `os.Getenv`).
- An unset or empty variable → `Load` returns `*MissingEnvError{Name}` (deterministic: the first
  missing name in sorted key order). The error text names the variable only: never a value, never
  config content. `cmd/yip` already prints `yip: <error>` and exits 1.
- Every resolved value is registered with `Config.Redactor` (also for keys other than apiKey).
- Parse `provider.<id>`: `name`, `options.baseURL`, `options.apiKey`, `models.<key>.{name,
  reasoning, limit.context}`. Ignore `npm`, `cost`, `options` keys other than those two, and any
  unknown key. A wrong type for a parsed field → error naming the JSON path (no values).
- `default_model` naming an unknown model is not an error (fall back as described).

Tests (`t.TempDir()` homes, an injected `getenv`; never the real environment):
`TestEnvSubstitution`, `TestMissingEnvNamesVariable` (errors.As to `*MissingEnvError`; message
contains the name, not the value `SECRET123` of another resolved variable), `TestEmptyEnvIsMissing`,
`TestCostIgnored`, `TestModelParsing`, `TestDefaultModelID`, `TestSecretConfig` (the resolved key
`SECRET123` is masked by `Config.Redactor` and absent from every error returned by `Load`).
