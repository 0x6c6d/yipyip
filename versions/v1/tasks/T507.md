# T507: Subagent panel and `/agents`

Phase 5 · Model: sonnet: TUI views and commands over an existing API · Depends-on: T503, T405 · Covers: R9

## Brief
Implement the subagent panel and the `/agents` command in `internal/tui` (new file `agents.go`;
replace the `/agents` placeholder entry in the command table of `commands.go`). Agent API:
`Session.Subagents() []agent.SubInfo` (`ID, Task, Model, Status, Tokens, Final, Err`; status
`agent.SubRunning`, `SubDone`, `SubFailed`, `SubCancelled`), `SubagentTranscript(id)
([]string, bool)`, `CancelSubagent(id) error`; `agent.EvSubagent` events on status changes.

- Panel: rendered between the conversation and the input, one line per RUNNING subagent:
  `<id> running <task shortened to 40 chars> <tokens> tokens`; hidden when none is running.
  It refreshes on every render (reads `Subagents()`), so `EvSubagent` events only trigger a
  re-render.
- `/agents`: a table of all subagents of the session: id, status
  (`running`/`done`/`failed`/`cancelled`), task (shortened), tokens; none → `no subagents`.
- `/agents <id>`: the transcript lines of that subagent; unknown id →
  `error: unknown subagent: <id>`.
- `/agents kill <id>`: `CancelSubagent(id)`; shows `cancelled <id>`; unknown id → error.
- All shown text passes `Session.Redact`.

Tests in `internal/tui/agents_test.go` (temp HOME + `providertest.NewFunc` fake that makes the main
agent call `spawn_agent {"task":"TASK-SUB ..."}` and answers subagent requests (first user message
= task) slowly or quickly as needed; auto mode): `TestAgentsList` (id `a1`, status, tokens),
`TestAgentsTranscript`, `TestAgentsKill` (running subagent → `cancelled`), `TestAgentsUnknown`
(`/agents a9` and `/agents kill a9` → error), `TestAgentsNone`, `TestSubagentPanel` (panel line
while running, gone after it finished).
