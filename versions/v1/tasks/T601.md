# T601: Undo journal

Phase 6 · Model: opus: restores user files incl. subagent writes (Consequential A7, Risk "Undo") · Depends-on: T405 · Covers: R14

## Brief
Create `internal/agent/undo.go` (+ edits in `session.go`/`loop.go`). Existing: the registry calls
`Options.BeforeWrite(absPath)` exactly once right before `write_file`/`edit_file` modify a file
(after validation; the path is already symlink-resolved and inside the start dir); `NewSession`
wires that hook to an internal no-op method `s.beforeWrite(path)`; the loop (`runLoop`) runs tool
calls for the main agent and for subagents; `Submit` starts turns; `Reset` clears the session.

Add (contract):
```go
var ErrNothingToUndo = errors.New("nothing to undo")
type UndoResult struct {
	Restored        []string // paths relative to the start dir ("/"-separated), sorted
	Deleted         []string // files created in the turn and now removed, sorted
	BashNotReverted []string // bash commands of the undone turn, in execution order
}
func (s *Session) Undo() (UndoResult, error)
```
Journal (memory only, never written to disk):
- Each `Submit` opens a turn record: the history length before the user message, a map
  `absPath → snapshot{existed bool, data []byte, mode fs.FileMode}`, and the list of bash
  commands.
- `beforeWrite(path)`: if the current turn has no snapshot for `path` yet, record one (file
  bytes and permission bits, or `existed=false` when missing). Writes by subagents count for the
  current turn (the most recently started turn of the session); guard with a mutex (subagents
  write concurrently).
- Every `bash` tool call that actually ran (main agent or subagent; denied calls are not listed)
  appends its `command` to the current turn.

`Undo()`:
- `ErrBusy` while a turn runs; `ErrNothingToUndo` when no turn record is left.
- Pops the last turn: for each snapshot, `existed` → write the bytes back and restore the mode;
  not existed → remove the file (only the file; leave created directories). These restore writes
  bypass the tools and are not journaled. Truncates the history to the recorded length (removes
  the turn's user message and everything after it). Returns the sorted relative paths and the bash
  commands.
- Repeatable back to the session start (each call undoes one more turn).
- `Reset` clears the journal. Token totals are not changed by undo.

Tests in `internal/agent/undo_test.go` (temp dirs + `providertest`; auto mode):
`TestUndoRestoresModified`, `TestUndoDeletesCreated`, `TestUndoRemovesTurn` (history length back
to before the turn), `TestUndoTwice` (two turns writing the same file → two undos restore the
original), `TestUndoListsBash`, `TestUndoSubagentWrites` (a subagent's `write_file` during the
turn is restored), `TestUndoNothing`, `TestUndoBusy`, `TestUndoRestoresMode`.
