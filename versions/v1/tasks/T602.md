# T602: `/undo` command and e2e Undo tests

Phase 6 · Model: sonnet: command wiring and end-to-end tests over the opus journal · Depends-on: T601, T503 · Covers: R14

## Brief
Wire `/undo` into the TUI and add the end-to-end tests of README §8 for undo.

Existing: `internal/tui` command table in `commands.go` (placeholder entry `/undo: not available
yet`), `Model.Command(line) (Model, tea.Cmd)`, `Drain()`, `View()`; agent
`Session.Undo() (agent.UndoResult{Restored, Deleted, BashNotReverted []string}, error)` with
`agent.ErrNothingToUndo` / `agent.ErrBusy`.

TUI (`internal/tui/undo.go`, replace the placeholder):
- `/undo` calls `Session.Undo()`. Success → remove from the conversation view everything that
  was rendered since the start of the undone turn (track the view position where each submitted
  user message started), then show `undone:` with `restored <path>` / `deleted <path>` lines and,
  if any, `not reverted (bash): <command>` lines. `ErrNothingToUndo` → `nothing to undo`;
  `ErrBusy` → `busy: press Esc to cancel the running turn`.

End-to-end tests, new package `e2e` (directory `e2e/`, test files only plus a tiny `doc.go`):
- `e2e/helpers_test.go`: a helper that creates a temp HOME and a temp start dir, starts a
  `providertest` fake with given responses, writes `providertest.ConfigJSON(srv.URL,
  "{env:FAKE_KEY}", 8000)` as the global config, loads it with `config.Load(home, dir, getenv)`
  where getenv maps `FAKE_KEY` to `SECRET123`, creates `agent.NewSession`, sets
  `agent.ModeAuto`, and builds `tui.New(tui.Options{StartDir: dir, Session: s})` with a
  `tea.WindowSizeMsg{Width: 160, Height: 50}`. Plus `submit(t, m, text)` = `Command` + wait for
  the turn + `Drain`. Other e2e tasks reuse it; keep it generic.
- `e2e/undo_test.go` (all through `Model.Command("/undo")`): `TestUndoRestoresModified`,
  `TestUndoDeletesCreated`, `TestUndoRemovesTurn` (the next request to the fake no longer contains
  the undone user message; the view no longer shows it), `TestUndoTwice`, `TestUndoListsBash`
  (view shows `not reverted (bash): echo hi > c.txt`).
