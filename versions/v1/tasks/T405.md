# T405: Subagent tools in the session

Phase 4 · Model: opus: concurrent agents sharing the approval gate (A6) and turn cancellation · Depends-on: T403, T404 · Covers: R8, R7, R6, R15

## Brief
Connect the subagent manager (`internal/agent/subagent.go`: `NewManager(max, run, onChange)`,
`Spawn(parent, task, model)`, `Wait`, `Cancel`, `CancelAll`, `List`, `Get`, `Transcript`,
`Subagent.AddTokens/Log`) to the session and its loop (`loop.go`: reusable `runLoop` taking an
agent id, a history and a tool set; `Gate.Check` for gated tools; `Submit`, `Cancel`, `Reset`).
New file `internal/agent/agenttools.go` (+ edits in `session.go`/`loop.go`).

Add (contract):
```go
func (s *Session) Subagents() []SubInfo
func (s *Session) SubagentTranscript(id string) ([]string, bool)
func (s *Session) CancelSubagent(id string) error
```
Agent tools (provider tool definitions with JSON schemas), offered to the main agent in addition
to the registry tools:
- `spawn_agent` `{task (required), model (optional "provider/model")}`, gated (manual mode asks).
  Starts a subagent via `Manager.Spawn(turnCtx, task, model)` and returns at once with the
  result `subagent <id> started` (the first spawn of a session gets id `a1`). Errors (limit
  reached, unknown model id) → error result to the model (`IsError` true in `EvToolResult`).
- `wait_agent` `{id}`: blocks until that subagent ends (or the turn is cancelled) and returns its
  final text; failures as error results.
- `cancel_agent` `{id}`: cancels it; result `cancelled <id>`.

Subagent run: fresh history `[system prompt + a line "You are subagent <id>; finish with a short
summary.", user: <task verbatim>]`; tool set = registry tools + `wait_agent` + `cancel_agent`
(NO `spawn_agent`: no nesting); model = the given id or the session's current model; runs
`runLoop` with agent id = subagent id, so approvals in manual mode go through the same Gate and
appear as `EvApproval` with `AgentID` = the subagent id, and its text/tool events carry that id.
Each response's tokens are added to the session totals AND to the subagent
(`Subagent.AddTokens`); transcript lines (`Log`) record its tool calls, results (shortened) and
final text. Status changes emit `EvSubagent` (Text = `<id> <status>`).

Manager limit = `Config.MaxSubagents` (default 4). The subagent context derives from the turn
context of the turn that spawned it, so `Cancel` (Esc) also cancels running subagents of that
turn. `Reset` cancels all subagents and starts a new empty manager (ids restart at `a1`).

Tests in `internal/agent/agenttools_test.go` (providertest `NewFunc`: identify subagent requests by
their first user message = the task): `TestSpawnToolReturnsImmediately` (spawn result arrives while
the subagent is still running), `TestSpawnLimitError` (max_subagents 1 via project yipyip.json,
two spawns in one response → second is an error result), `TestSubagentNoSpawnTool`,
`TestWaitAgentReturnsFinal`, `TestCancelAgentTool`, `TestSubagentTokensAdded`,
`TestSubagentApprovalLabelled` (manual mode: an `EvApproval` with AgentID `a1` for its bash),
`TestEscCancelsSubagents`.
