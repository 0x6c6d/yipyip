# T305: `glob` (with `**`) and `grep`

Phase 3 · Model: sonnet: search tools that call the opus PathGuard · Depends-on: T303 · Covers: R4

## Brief
Add two built-in tools to `internal/tools` (new file `search.go`, plus entries in the built-in
table of `registry.go`). Existing API you use, unchanged: `Registry.Guard().Resolve(p)`,
`Guard().Root()`, `Truncate`, `Result{Output, IsError}`; `Run` already redacts outputs. Standard
library only (own `**` matcher, Go `regexp`).

Exported helper (contract):
```go
func MatchGlob(pattern, path string) bool // slash-separated relative paths
```
`MatchGlob` supports `*` and `?` and `[...]` within one path segment (as `path.Match`) and `**`
as a whole segment matching zero or more segments: `**/*.go` matches `a.go` and `x/y/c.go`;
`x/**/c.go` matches `x/c.go` and `x/y/c.go`; `x/*.go` does not match `x/y/c.go`; `*.go` does not
match `x/b.go`.

Tools (both `Gated: false`):
- `glob` `{pattern (required), path (optional, default ".")}`: walks `path` (resolved by the
  guard; outside → `IsError`) with `filepath.WalkDir` (does not follow symlinks), skips `.git`
  directories, matches each file's path relative to `path` against the pattern. Output: matching
  paths relative to the START directory, `/`-separated, sorted, one per line; at most 1,000
  then `[results truncated: N more]`; none → `no matches`.
- `grep` `{pattern (required), path (optional), glob (optional)}`: Go RE2 regular expression;
  invalid → `IsError` with the regexp error. Walks like `glob`, skips `.git` and binary files
  (a NUL byte in the first 8,000 bytes). `glob` filter: a pattern containing `/` is matched with
  `MatchGlob` against the path relative to the start dir, otherwise against the base name.
  Output lines `relpath:line:text` (1-based line numbers, path relative to the start dir with
  `/`), sorted by path then line; at most 1,000 matches then
  `[results truncated: N more matches]`; none → `no matches`. The whole output also goes through
  `Truncate`.

Tests in `internal/tools/search_test.go`: `TestGlobDoubleStar`, `TestMatchGlob` (the cases above),
`TestGlobSkipsGit`, `TestGrepFormat` (exact line `x/b.go:2:func B() {}`), `TestGrepGlobFilter`,
`TestGrepSkipsBinary`, `TestGrepInvalidRegex`, `TestSearchPathEscape` (`path: "../"` and an
absolute outside path → `IsError` for both tools).
