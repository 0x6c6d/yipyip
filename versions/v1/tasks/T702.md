# T702: `config.example.json`

Phase 7 · Model: haiku: one fixed file plus a load test · Depends-on: T202 · Covers: R1

## Brief
Create `config.example.json` in the repository root with exactly this content (2-space
indentation, trailing newline):
```json
{
  "max_subagents": 4,
  "auto_compact": true,
  "provider": {
    "openrouter": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "OpenRouter",
      "options": {
        "baseURL": "https://openrouter.ai/api/v1",
        "apiKey": "{env:OPENROUTER_API_KEY}"
      },
      "models": {}
    }
  }
}
```
Add `TestExampleConfigLoads` to `internal/config/example_test.go`: copy `../../config.example.json`
into a temp HOME as `.config/yipyip/config.json`, call `config.Load(home, t.TempDir(), getenv)`
with an injected getenv returning `dummy-value` for `OPENROUTER_API_KEY`, and assert: no error,
`MaxSubagents == 4`, `AutoCompact == true`, provider `openrouter` with the base URL above and
the resolved key, no models, `DefaultModelID() == ""`. Also assert that with the variable unset
the error is a `*config.MissingEnvError` naming `OPENROUTER_API_KEY`.

Do not put the provider host string into any `.go` file other than `_test.go` files (read it from
the JSON file in the test instead of hard-coding it).

`scripts/verify/v1/T702.sh` exits 0. It checks that the file is valid JSON equal to the content
above, runs `TestExampleConfigLoads` and `make check`. Negative: no non-test `.go` file contains
