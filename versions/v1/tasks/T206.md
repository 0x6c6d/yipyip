# T206: Provider errors, dropped streams, redacted error text

Phase 2 · Model: opus: HTTP error bodies may echo the API key (Consequential A4, Risk "Secrets") · Depends-on: T205 · Covers: R2, R16

## Brief
Harden `internal/provider/client.go` / `sse.go`. The exported API stays exactly as it is:
`NewClient(baseURL, apiKey string, hc *http.Client, red *config.Redactor) *Client`,
`(*Client).Stream(ctx, Request) <-chan Event`, `Event{Kind, Text, ToolCall, Usage, Err}` with
kinds `EventText, EventToolCall, EventUsage, EventDone, EventError`. Every stream ends with
exactly one final `EventDone` or `EventError`, then the channel is closed.

Required behaviour:
- Non-2xx response → final `EventError` whose `Err.Error()` is
  `HTTP <status>: <excerpt>`; excerpt = first 500 characters of the body with whitespace
  collapsed, then redacted.
- Redaction: every error text the client produces (HTTP excerpts, transport and connection
  errors, URL errors that might contain credentials) passes through `red.Redact` AND the client
  always masks its own `apiKey` as `[redacted]`, even when `red` is nil.
- Dropped stream: the body ends (EOF or read error) before `[DONE]` and without a
  `finish_reason` having been seen → final `EventError` (`stream interrupted: ...`). Text events
  already emitted stay emitted. EOF after a `finish_reason` without `[DONE]` counts as done.
- A malformed JSON chunk → final `EventError` (`invalid stream chunk`), no panic.
- A refused host (`ErrHostNotAllowed` from the transport) or any connection error → final
  `EventError` that still satisfies `errors.Is(err, ErrHostNotAllowed)` (wrap, redact only the
  message via a custom error type that keeps `Unwrap`).
- Context cancelled → final `EventError` with `errors.Is(err, context.Canceled)`; the channel
  closes within 1 s of the cancel, also while the server keeps the connection open.
- Never panics; no goroutine is left blocked after the channel closed.

Tests in `internal/provider/errors_test.go` (package `provider_test`, `providertest` and local
`httptest` servers): `TestHTTP500`, `TestHTTP401`, `TestDroppedStream`, `TestMalformedChunk`,
`TestCancelStream`, `TestRefusedHostError`, `TestSecretProviderError` (a 401 body echoing
`Bearer SECRET123`: error text contains `401` and `[redacted]`, not `SECRET123`, with and without
a Redactor).

## Verification
`scripts/verify/v1/T206.sh` exits 0. It runs the named tests and `make check` and the probe
`scripts/verify/v1/probes/T206.go`. Negative: a 401 body echoing the key (nil Redactor), a
dropped stream, a malformed chunk, a refused foreign host (never reached) and a cancelled
stream must each end in `EventError` without the key and within the time limits.
