# T799: Global Definition of Done

Phase 7 · Model: supervisor: the supervisor runs the version's Definition of Done itself · Depends-on: T704 · Covers: R1, R2, R3, R4, R5, R6, R7, R8, R9, R10, R11, R12, R13, R14, R15, R16, R17, R18 (all acceptance criteria of README §8, via D1–D15)

## Brief
When no other row is selectable, the supervisor runs `scripts/verify/v1/T799.sh`, which executes
the Global Definition of Done of `versions/v1/plan.md` (D1–D15) one line per check. A failing
line becomes a new fix row (`todo`, tier by the usual rules, with its own task file and a
verification script equal to that failing check), and the loop continues; after 2 such repair
passes, stop and report.

Note: D11 runs `make install` into the real `$(go env GOPATH)/bin` (allowed by README R17) and
needs `$(go env GOPATH)/bin` on `PATH` (checked in T000). D14 compares README.md with the commit
that added `versions/v1/plan.md` (the only allowed change is the appended `## Usage` section).

## Verification
`scripts/verify/v1/T799.sh` exits 0: D1–D15 all pass. Negative: D13 (no real provider host in
non-test Go code or the Makefile) and D14 (no deleted README lines) are failure-sensitive checks
in the script.
