## Brief
Create `internal/agent/session.go`, `events.go`, `prompt.go`. Existing APIs: `config.Config`
(`Lookup`, `ModelIDs`, `DefaultModelID`, `BaseURLs`, `EnvNames`, `Redactor`, `MaxSubagents`,
`AutoCompact`), `provider.NewHTTPClient`, `provider.NewClient`, `provider.Message`,
`tools.NewRegistry(tools.Options{StartDir, Redactor, StripEnv, BeforeWrite})`, and
`approval.go` (`Mode`, `Gate`, `NewGate`, `ApprovalRequest`, `MainAgentID`). No turn loop yet:
the next task adds `Submit`.

Exported API (contract; keep names and types exactly):
```go
var (
	ErrNoModel = errors.New("no model configured"); ErrBusy = errors.New("a turn is already running")
	ErrUnknownModel = errors.New("unknown model");   ErrInvalidEffort = errors.New("invalid effort")
)
type Options struct {
	Config     *config.Config
	StartDir   string
	HTTPClient *http.Client // nil → provider.NewHTTPClient(Config.BaseURLs())
}
type Tokens struct{ In, Out, Total int }
type EventKind int
const ( EvText EventKind = iota + 1; EvToolCall; EvToolResult; EvApproval; EvError; EvInfo; EvTurnDone; EvSubagent )
type Event struct {
	Kind    EventKind
	AgentID string // MainAgentID or subagent id
	Text    string // text delta, tool result output, error or info message
	Tool    string // EvToolCall / EvToolResult / EvApproval
	Args    string // EvToolCall: raw JSON arguments
	IsError bool   // EvToolResult
	Approval *ApprovalRequest // EvApproval
}
func NewSession(opts Options) (*Session, error)
func (s *Session) NextEvent(ctx context.Context) (Event, error) // blocks until an event or ctx done
func (s *Session) PollEvents() []Event                          // takes all queued events, never blocks
func (s *Session) ModelID() string; func (s *Session) Models() []string
func (s *Session) SetModel(id string) error // unknown → error wrapping ErrUnknownModel, model unchanged
func (s *Session) Effort() string; func (s *Session) SetEffort(e string) error // low|medium|high, else ErrInvalidEffort
func (s *Session) ReasoningEnabled() bool // current model's Reasoning (false when no model)
func (s *Session) Mode() Mode; func (s *Session) SetMode(m Mode); func (s *Session) ToggleMode() Mode
func (s *Session) Tokens() Tokens
func (s *Session) ContextSize() (used, limit int) // used = last prompt tokens; limit = model ContextLimit
func (s *Session) History() []provider.Message    // copy; [0] is the system prompt
func (s *Session) SystemPrompt() string
func (s *Session) StartDir() string               // symlink-resolved
func (s *Session) Redact(text string) string
func (s *Session) Reset()
```
Behaviour:
- Defaults: model `Config.DefaultModelID()` ("" allowed), effort `medium`, mode `ModeManual`,
  tokens zero, history `[system]`. `NewSession` builds the registry with
  `StripEnv: Config.EnvNames`, `Redactor: Config.Redactor`, and a `BeforeWrite` hook calling an
  internal no-op method (`s.beforeWrite(path)`) that the undo task fills in later.
- Event queue: unbounded, mutex-protected; emitting never blocks, even with no reader (an
  internal `emit(Event)` redacts `Text` and `Args` with the config Redactor before queueing).
  `NextEvent` and `PollEvents` both consume from it.
- One `*Gate` per session whose notify emits an `EvApproval` event (AgentID/Tool from the
  request, `Approval` set). Keep it in a field for the loop.
- System prompt (`prompt.go`): a built-in text (you are yip, a coding assistant working in
  `<StartDir>`; tools available; paths are relative to the start directory; be concise) plus, if
  `<StartDir>/AGENTS.md` exists, `"\n\n# AGENTS.md\n" + content` (truncated to 30,000 chars).
  Re-read on `Reset`.
- `Reset()` (for `/new`): cancels a running turn if any (keep a hook for the loop task),
  clears history back to `[system]`, zeroes tokens and context usage, calls `Gate.Reset()`,
  drops queued events; model, effort and mode are kept.
- Thread-safe getters/setters (one mutex). No files are written.
