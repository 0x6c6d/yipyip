# T304: `read_file`, `write_file`, `edit_file`

Phase 3 · Model: sonnet: file tools that only call the opus PathGuard; supervisor runs the escape checks · Depends-on: T303 · Covers: R4, R14

## Brief
Add three built-in tools to `internal/tools` (new file `files.go`, plus an entry for each in the
built-in table of `registry.go`). Existing API you use, unchanged:
`Registry.Guard().Resolve(p) (string, error)` (symlink-safe, errors wrap `ErrOutsideStartDir`),
`Truncate(s string) string`, `Options.BeforeWrite func(absPath string)`, `Result{Output, IsError}`.
`Run` already redacts outputs and recovers panics.

Tools (JSON-schema objects; all paths go through `Resolve`; relative paths are relative to the
start dir; results show paths relative to the start dir with `/` separators):
- `read_file` `{path}` (required), `Gated: false`: returns the file content passed through
  `Truncate`. Directory or missing file → `IsError`.
- `write_file` `{path, content}` (both required), `Gated: true`: creates missing parent
  directories (the guard has already resolved them inside the root), calls
  `BeforeWrite(absPath)` exactly once right before writing, writes the content; an existing
  file keeps its permission bits, a new file gets `0644`. Output `wrote N bytes to <rel>`.
- `edit_file` `{path, old_string, new_string}` (all required), `Gated: true`: the file must
  exist; `old_string` must be non-empty and occur exactly once. 0 occurrences →
  `IsError` `old_string not found in <rel>`; more than one → `IsError`
  `old_string is ambiguous: N occurrences in <rel>`; exactly one → `BeforeWrite(absPath)`, then
  replace and write (mode kept). Output `edited <rel>`.
- Any path rejected by the guard → `IsError` with a message containing
  `outside the start directory`; nothing is read, written or created, `BeforeWrite` is not called.
- `BeforeWrite` is never called when validation fails.

Tests in `internal/tools/files_test.go` (`t.TempDir()` roots with an outside sibling directory and
symlinks): `TestReadFile`, `TestReadFileOutside` (`..` and symlink), `TestWriteFileCreatesDirs`,
`TestWriteFileOutsideRejected` (through a symlinked directory; no file appears outside),
`TestEditFileMissing`, `TestEditFileAmbiguous`, `TestEditFileOK`, `TestBeforeWriteHook`.
