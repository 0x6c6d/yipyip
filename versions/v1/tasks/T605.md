# T605: `/init` and e2e Init test

Phase 6 · Model: sonnet: a prompt, a command and an end-to-end test · Depends-on: T602 · Covers: R12

## Brief
Implement `/init`: the agent inspects the repository and writes or updates `AGENTS.md` in the
start directory.

Existing: `agent.Session` with `Submit(text) error`, `StartDir()`, the loop and tools (the model
writes files through `write_file`/`edit_file`; manual mode asks for approval as usual); the TUI
command table in `internal/tui/commands.go` (placeholder entry for `/init`); e2e helpers in
`e2e/helpers_test.go` (temp HOME and start dir, `providertest` fake, session in auto mode, TUI
model, `submit` helper).

Add (contract), new file `internal/agent/init.go`:
```go
func InitPrompt(existing string) string // existing = current AGENTS.md content, "" if none
func (s *Session) Init() error          // Submit(InitPrompt(<AGENTS.md of StartDir() or "">))
```
The prompt tells the model to inspect the repository with `glob`, `grep` and `read_file`, then
write `AGENTS.md` in the start directory with build/test/lint commands and architecture notes
using `write_file` (or `edit_file`). When `existing` is non-empty, the prompt includes it verbatim
between clear markers and says to update it and keep everything that is still valid instead of
discarding it. `Init` returns the `Submit` errors (`ErrNoModel`, `ErrBusy`).

TUI (`internal/tui/init.go`, replace the placeholder): `/init` calls `Session.Init()` and shows
`initializing AGENTS.md ...`; errors shown as `error: ...`.

Tests:
- `internal/agent/init_test.go`: `TestInitPromptNew` (mentions `AGENTS.md`, build/test commands),
  `TestInitPromptKeepsExisting` (contains the existing text and an instruction to update, not
  discard).
- `e2e/init_test.go`: `TestInitCreatesAgentsMD` (the fake answers the init request with a
  `write_file` of `AGENTS.md`, then a text reply; after `/init` and the turn, `AGENTS.md` exists in
  the temp start dir with that content), `TestInitUpdatesExisting` (existing `AGENTS.md` with
  `KEEP-ME`: the request sent to the fake contains `KEEP-ME` and `AGENTS.md`).
