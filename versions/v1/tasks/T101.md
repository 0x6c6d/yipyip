# T101: Go module, Makefile, .gitignore and `--version`

Phase 1 · Model: haiku: mechanical scaffolding with a clear boundary · Depends-on: T000 · Covers: R17, R18

## Brief
Create the walking skeleton of the Go program `yip` (module `yipyip`) in the repository root.

Files to create:
- `go.mod`: exactly `module yipyip` and `go 1.27`. No `require` lines yet (dependencies are
  added later by the tasks that import them). Do not run `go get`.
- `.gitignore`: contains the line `bin/`.
- `cmd/yip/main.go` (package `main`):
  - `var version = "dev"` (overridden at build time with `-ldflags "-X main.version=..."`).
  - `func run(args []string, stdout, stderr io.Writer) int`; `main` only calls
    `os.Exit(run(os.Args[1:], os.Stdout, os.Stderr))`.
  - `--version` (also `-version`) prints exactly `yip <version>` and a newline to stdout and
    returns 0. It must not read any config file or environment variable.
  - Unknown flags print a short error plus `usage: yip [--version] [--help]` to stderr and
    return 2.
  - No arguments: for now print `yip: interactive UI not built yet` to stderr and return 0
    (a later task replaces this).
- `cmd/yip/main_test.go`: `TestVersionFlag` (run with `--version` returns 0, output matches
  `^yip `) and `TestUnknownFlag` (returns 2, stderr mentions usage).
- `Makefile` (GNU Make, `.PHONY` targets, recipe lines indented with tabs):
  - `VERSION ?= $(shell git describe --tags --always --dirty 2>/dev/null || echo dev)` and
    `LDFLAGS := -X main.version=$(VERSION)`.
  - `build`: `go build ./...` and `go build -ldflags "$(LDFLAGS)" -o bin/yip ./cmd/yip`.
  - `check`: fails if `gofmt -l .` prints anything (print the offending files), then
    `go vet ./...`, `go test ./...`, `go build ./...`; exits non-zero on the first failure.
  - `install`: installs the binary as `yip` into `$(go env GOBIN)`, or into
    `$(go env GOPATH)/bin` when GOBIN is empty (evaluate both at recipe run time inside the
    recipe, create the directory if needed, build with the same `-ldflags`).
  - The Makefile must never mention `proxy.golang.org` or `openrouter` and must not download
    anything (`go get`, `curl`, ...).

Notes:
- `gofmt -l .` also scans `scripts/verify/` (supervisor probes, already formatted); leave them.
- Keep everything gofmt-formatted; `go vet ./...` must be clean.
