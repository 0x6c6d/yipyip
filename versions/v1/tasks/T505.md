# T505: Approval prompt in the TUI

Phase 5 · Model: sonnet: UI for the opus gate; the supervisor runs the unprompted-bash checks · Depends-on: T503 · Covers: R7, R8

## Brief
Render and answer approval requests in `internal/tui` (new file `approval.go` in package `tui`).
Agent API: events `agent.Event{Kind: agent.EvApproval, AgentID, Tool, Approval *agent.ApprovalRequest}`
where `ApprovalRequest{AgentID, Tool, Args}` has `Respond(agent.Decision)` with decisions
`agent.Allow` (y), `agent.Deny` (n), `agent.AllowAlways` (a). The gate in the agent decides
when to ask (manual mode, gated tools, "always" set); the TUI only shows and answers. Never
call `Respond` on the user's behalf.

- On an `EvApproval` event (via the event pump or `Drain`), queue the request (FIFO). While a
  request is pending show a prompt block above the input:
  `[<AgentID>] <Tool>: <args summary>` (for bash the `command`, for file tools the `path`,
  otherwise the raw JSON shortened to 200 chars; all text through `Session.Redact`) and the line
  `y / n / a (always for this tool this session)`.
- While pending, the keys `y`, `n`, `a` answer the first request (Allow/Deny/AllowAlways) and
  show the next one; other printable keys are ignored (they do not go into the input); `Esc`
  answers Deny for all pending requests and cancels the turn (`Session.Cancel()`).
- In auto mode no prompt appears (the gate does not ask); nothing to do in the TUI.

Tests in `internal/tui/approval_test.go` (temp HOME + `providertest` + `agent.NewSession`; manual
mode is the default; poll `Drain()` until the prompt is visible): `TestApprovalPromptShown`
(bash `echo hi` → view contains `[main] bash`, `echo hi` and `y / n / a`),
`TestApprovalDeny` (bash `touch marker`, key `n` → no marker; the next request to the fake
carries a tool message `denied by user`), `TestApprovalYes` (`y` → marker created),
`TestApprovalAlways` (`a` → a second bash call in the same session runs without a prompt),
`TestApprovalAutoMode` (auto: no prompt, marker created), `TestApprovalIgnoresOtherKeys`.
