# T506: Tool blocks, collapsible results and syntax highlighting

Phase 5 · Model: sonnet: TUI views and chroma integration · Depends-on: T501 · Covers: R15

## Brief
Improve the conversation rendering in `internal/tui` (new files `blocks.go`, `highlight.go`).
Events: `agent.EvToolCall` (AgentID, Tool, Args = raw JSON) and `agent.EvToolResult` (Tool,
Text = output, IsError); assistant text arrives as `agent.EvText` deltas. Everything shown goes
through `Session.Redact` (already done in the event handling; keep it).

Dependency: `go get github.com/alecthomas/chroma/v2@v2.27.0` (exactly this version), then
`go mod tidy`. No other new module.

- Tool call block: a bordered block with a header `<tool> <args>` (args compacted to one line,
  max 200 chars; for subagents prefix `[<AgentID>]`). The matching result renders inside the
  block below the header: collapsed by default to the first 3 lines plus
  `… (N more lines, ctrl+o to expand)`; error results styled red. `Ctrl+O` toggles
  expanding all results (collapsed again on the next toggle).
- Fenced code blocks in assistant text (```` ```lang ```` ... ```` ``` ````) are highlighted with
  chroma (formatter `terminal256`, style `monokai`) once the closing fence has arrived; unknown
  or missing language → plain text. Text outside fences is unchanged.
- Exported helper (contract): `func Highlight(code, lang string) string` returns the highlighted
  code (ANSI escape sequences) or the code unchanged for an unknown language.
- The viewport keeps following the bottom while new content arrives; `PgUp`/`PgDn` scroll.

Tests in `internal/tui/blocks_test.go`: `TestToolBlockRendered` (feed `EventMsg` values via
`Update`: header shows `read_file` and the path), `TestToolResultCollapsed` (10-line result →
first 3 lines + `7 more lines`), `TestToolResultExpand` (Ctrl+O shows line 10),
`TestHighlightGo` (`Highlight("func main() {}", "go")` contains `\x1b[` and `main`),
`TestHighlightUnknownLang` (returned unchanged), `TestFenceHighlightedInView`.
