# T301: PathGuard (start-directory confinement)

Phase 3 · Model: opus: symlink-safe confinement (Consequential A5, Risk "PathGuard") · Depends-on: T101 · Covers: R4

## Brief
Create `internal/tools/pathguard.go` (package `tools`, standard library only). It is the only
place that decides whether a path is inside the start directory; all file tools, `glob` and
`grep` call it (shared-code rule).

Exported API (contract; keep names and types exactly):
```go
var ErrOutsideStartDir = errors.New("path is outside the start directory")
type PathGuard struct{ /* unexported */ }
func NewPathGuard(startDir string) (*PathGuard, error)
func (g *PathGuard) Root() string
func (g *PathGuard) Resolve(p string) (string, error)
```
Behaviour:
- `NewPathGuard`: makes `startDir` absolute and resolves symlinks (`filepath.EvalSymlinks`); it
  must exist and be a directory, else an error. `Root()` returns that resolved path.
- `Resolve(p)`: `""` → error. Relative paths are joined to the root, absolute paths are used
  as given; then `filepath.Clean`. Find the deepest existing ancestor (walk up with
  `os.Lstat`), resolve it with `filepath.EvalSymlinks`, append the remaining (non-existent)
  components. The final path must equal the root or lie inside it (`filepath.Rel`, no `..`
  prefix); otherwise return an error wrapping `ErrOutsideStartDir`
  (`fmt.Errorf("%w: %s", ErrOutsideStartDir, p)`, showing the path as given).
- Absolute paths through a symlinked alias of the root (e.g. `/tmp/rootlink/a.txt` where
  `rootlink → root`) resolve inside and are allowed. A symlink inside the root pointing to
  another place inside the root is allowed.
- A symlink inside the root pointing outside (file or directory) is rejected, also for new files
  below a symlinked directory (`link-out/new.txt`).
- A dangling symlink (exists per Lstat, EvalSymlinks fails) → error (never follow it to create a
  file elsewhere).
- Never panics, never touches the file system except reads (`Lstat`, `EvalSymlinks`).

Tests in `internal/tools/pathguard_test.go` (all in `t.TempDir()`): `TestGuardRelative`,
`TestGuardAbsoluteInside`, `TestGuardDotDotEscape`, `TestGuardAbsoluteOutside`,
`TestGuardSymlinkEscape`, `TestGuardSymlinkInside`, `TestGuardNewFile`,
`TestGuardDanglingSymlink`, `TestGuardRootSymlinked`.
