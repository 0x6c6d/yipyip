# T204: `providertest` fake SSE provider

Phase 2 · Model: sonnet: test helper with moderate protocol detail · Depends-on: T101 · Covers: R18, R2

## Brief
Create `internal/provider/providertest/providertest.go` (package `providertest`; standard
library only; it must NOT import any `yipyip/...` package, so `provider` tests can use it without
import cycles). Every later test and the supervisor probes use it as the offline fake
OpenAI-compatible provider.

Exported API (contract; keep names and types exactly):
```go
type ToolCall struct{ ID, Name, Arguments string }
type Usage struct{ Prompt, Completion int } // total = Prompt + Completion
type Response struct {
	Status    int           // 0 or 200 = SSE stream; anything else = plain error response
	Body      string        // body for an error response
	Text      string        // streamed as content deltas
	ToolCalls []ToolCall    // streamed as tool_calls deltas
	Usage     *Usage        // final usage chunk when non-nil
	Raw       []string      // if non-nil: sent verbatim as "data: <p>\n\n" lines instead of the above
	Drop      bool          // abort the connection after the content (no finish chunk, no [DONE])
	Delay     time.Duration // wait before the first byte (ends early if the request is cancelled)
}
type Message struct {
	Role, Content, ToolCallID string
	ToolCalls                 []ToolCall
}
type Request struct {
	Method, Path           string
	Header                 http.Header
	Body                   []byte
	JSON                   map[string]any // decoded body (nil if not JSON)
	Model, ReasoningEffort string         // "model", "reasoning_effort" ("" when absent)
	Messages               []Message      // decoded "messages" (tool_calls/tool_call_id included)
	ToolNames              []string       // tools[].function.name in order
}
type Server struct {
	URL string // base URL to configure: "http://127.0.0.1:<port>/v1"
	/* unexported */
}
func New(responses ...Response) *Server // request i gets responses[i]; afterwards Response{Text: "ok"}
func NewFunc(fn func(n int, req Request) Response) *Server // n = 0-based request index
func (s *Server) Requests() []Request // copy, in arrival order
func (s *Server) Close()
func ConfigJSON(baseURL, apiKey string, contextLimit int) string
```
Behaviour:
- Built on `httptest.NewServer`; accepts any method/path, records the request (thread-safe)
  before responding. Undecodable bodies are recorded with nil JSON.
- SSE (status 200, `Content-Type: text/event-stream`, flush after every event, each event is
  `data: <json>\n\n`): content deltas of at most 4 runes each as
  `{"choices":[{"index":0,"delta":{"content":"..."}}]}` (the first delta also has
  `"role":"assistant"`); per tool call i: one chunk with
  `{"index":i,"id":..,"type":"function","function":{"name":..,"arguments":""}}`, then its
  arguments split into at least 2 non-empty pieces (when length ≥ 2), each
  `{"index":i,"function":{"arguments":"<piece>"}}` inside `delta.tool_calls`; then a finish chunk
  with `"finish_reason":"tool_calls"` (if any tool calls) or `"stop"`; then, if Usage is set,
  `{"choices":[],"usage":{"prompt_tokens":p,"completion_tokens":c,"total_tokens":p+c}}`;
  then `data: [DONE]`.
- `Drop`: after the content/tool deltas, abort with `panic(http.ErrAbortHandler)`.
- `ConfigJSON` returns a yipyip config: `default_model` `fake/m1`; provider `fake` with
  `name`, `options.baseURL` = baseURL, `options.apiKey` = apiKey (e.g. `"{env:FAKE_KEY}"`);
  models `m1` (`limit.context` = contextLimit) and `m2` (`"reasoning": false`).

Tests in `providertest_test.go` (raw `net/http` client against the fake): `TestFakeTextStream`,
`TestFakeToolCallSplit`, `TestFakeRecordsRequests`, `TestFakeErrorStatus`, `TestFakeDrop`,
`TestFakeDefaultAfterScript`, `TestConfigJSON`.
