# T404: Subagent manager

Phase 4 · Model: opus: goroutines, limits and cancellation (concurrency) · Depends-on: T101 · Covers: R8, R9

## Brief
Create `internal/agent/subagent.go` (package `agent`, standard library only). It is a
self-contained manager; the next task connects it to the session's tools.

Exported API (contract; keep names and types exactly):
```go
type SubStatus string
const (
	SubRunning   SubStatus = "running"
	SubDone      SubStatus = "done"
	SubFailed    SubStatus = "failed"
	SubCancelled SubStatus = "cancelled"
)
type SubInfo struct {
	ID, Task, Model string
	Status          SubStatus
	Tokens          int
	Final, Err      string // final text (done) or error text (failed/cancelled)
}
type Subagent struct{ /* unexported */ } // handle passed to the run function
func (a *Subagent) ID() string
func (a *Subagent) AddTokens(n int)
func (a *Subagent) Log(line string) // appends one transcript line
type RunFunc func(ctx context.Context, a *Subagent, task, model string) (string, error)
type Manager struct{ /* unexported */ }
func NewManager(max int, run RunFunc, onChange func(SubInfo)) *Manager // max <= 0 → 4; onChange may be nil
func (m *Manager) Spawn(parent context.Context, task, model string) (string, error)
func (m *Manager) Wait(ctx context.Context, id string) (string, error)
func (m *Manager) Cancel(id string) error
func (m *Manager) CancelAll()
func (m *Manager) List() []SubInfo // in spawn order
func (m *Manager) Get(id string) (SubInfo, bool)
func (m *Manager) Transcript(id string) ([]string, bool) // copy of the logged lines, in order
func (m *Manager) Running() int
```
Behaviour:
- `Spawn` returns immediately with ids `a1`, `a2`, ... (monotonic per manager). If `Running()`
  already equals max → error (`subagent limit reached (max N)`), nothing is started. The run
  function executes in its own goroutine with a context derived from `parent` (cancelling the
  parent, e.g. the turn context, cancels the subagent) and cancellable per id.
- Status: `running` until the run function returns; then `done` (Final = returned text),
  `cancelled` if its context was cancelled (Err = "cancelled"), else `failed` (Err = error
  text). The slot is freed when the run function returns.
- `Wait` blocks until the subagent finished or `ctx` is done; returns Final for `done`, an error
  for failed/cancelled, an error for an unknown id (immediately, not a timeout), `ctx.Err()` on
  ctx done.
- `Cancel` unknown id → error; finished subagent → nil (no-op). `CancelAll` cancels every running
  one.
- `onChange` is called (outside the manager's lock) on spawn and on every status change with the
  current `SubInfo`.
- Safe for concurrent use; no goroutine leaks after the run functions return.

Tests in `internal/agent/subagent_test.go`: `TestSpawnReturnsImmediately`, `TestSpawnLimit`
(5th concurrent spawn with max 4 errors), `TestWaitReturnsFinal`, `TestCancelSubagent`,
`TestParentCancel`, `TestWaitUnknown`, `TestSubagentTokensAndTranscript`, `TestSubagentFailed`.
