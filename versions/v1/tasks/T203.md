# T203: Host-allowlist HTTP transport

Phase 2 · Model: opus: network restriction (Consequential A3, Risk "Transport allowlist") · Depends-on: T101 · Covers: R3, R18

## Brief
Create `internal/provider/transport.go` (package `provider`, standard library only). It is the
single `http.RoundTripper` used by all of yipyip's outgoing HTTP.

Exported API (contract; keep names and types exactly):
```go
var ErrHostNotAllowed = errors.New("host not allowed")
type Transport struct{ /* unexported */ }
func NewTransport(baseURLs []string) (*Transport, error)
func (t *Transport) RoundTrip(req *http.Request) (*http.Response, error)
func NewHTTPClient(baseURLs []string) (*http.Client, error)
```
Behaviour:
- The allowlist is the set of canonical `host:port` of the given base URLs: lowercase host,
  explicit port or the scheme default (http 80, https 443). Only `http`/`https` URLs with a host
  are valid; anything else (`::not a url`, `ftp://x`, `http://`) → `NewTransport` error.
  An empty list is valid and allows nothing.
- `RoundTrip` compares the canonical `host:port` of `req.URL` with the allowlist as strings (no
  DNS: `localhost:P` does not match `127.0.0.1:P`). Not allowed → close the request body and
  return an error wrapping `ErrHostNotAllowed` (`fmt.Errorf("%w: %s", ...)`) without dialing.
- Allowed requests go to an inner `*http.Transport` built from scratch (not a clone of
  `http.DefaultTransport`) with `Proxy: nil` (HTTP_PROXY/HTTPS_PROXY are ignored), sensible dial
  and TLS-handshake timeouts, `ForceAttemptHTTP2: true`; no overall timeout (responses stream).
- `NewHTTPClient` returns `&http.Client{Transport: t, CheckRedirect: ...}` where every redirect
  target is checked against the allowlist (refuse with an error wrapping `ErrHostNotAllowed`),
  max 10 redirects, no `Timeout`.
- Nowhere in non-test code may anything use `http.DefaultClient`, `http.DefaultTransport`,
  `http.Get/Post/Head`, or `ProxyFromEnvironment`; later code gets clients only from
  `NewHTTPClient`.

Tests in `internal/provider/transport_test.go` (httptest servers on 127.0.0.1 only):
`TestTransportAllowsConfiguredHost`, `TestTransportRejectsForeignHost` (the foreign server
receives 0 requests; `errors.Is(err, ErrHostNotAllowed)`), `TestTransportRejectsOtherPort`,
`TestTransportRejectsRedirectToForeignHost`, `TestTransportEmptyAllowlist`,
`TestTransportInvalidBaseURL`.
