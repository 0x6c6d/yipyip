# T403: Agent loop, token accounting and cancellation

Phase 4 · Model: opus: per-turn cancellation and concurrency (Risk "bash" kill on Esc), gate on every gated call (A6) · Depends-on: T206, T304, T305, T402 · Covers: R6, R2, R7, R15

## Brief
Create `internal/agent/loop.go` (+ tests). Existing in package `agent`: `Session` with its
event queue (`emit`, `NextEvent`, `PollEvents`), `Gate.Check(ctx, mode, agentID, tool, args)`,
`DeniedMessage`, `Tokens`, `ErrNoModel`, `ErrBusy`, model/effort/mode getters, registry, HTTP
client. Provider API: `provider.NewClient(baseURL, apiKey, hc, red).Stream(ctx, provider.Request{
Model, Messages, Tools, Effort, SendEffort}) <-chan provider.Event` with kinds `EventText`,
`EventToolCall`, `EventUsage`, `EventDone`, `EventError`. Tools: `Registry.Tools()` (Name,
Description, Parameters, Gated) and `Registry.Run(ctx, name, args) tools.Result{Output, IsError}`.

Add (contract):
```go
const MaxIterations = 50
func (s *Session) Submit(text string) error // returns at once; the turn runs in a goroutine
func (s *Session) Cancel()                  // cancels the running turn (Esc); no-op when idle
func (s *Session) Wait()                    // blocks until no turn is running
func (s *Session) Busy() bool
```
`Submit`: `ErrNoModel` when `ModelID() == ""`; `ErrBusy` while a turn runs. Otherwise append the
user message and start the turn with its own `context.WithCancel`.

Turn loop, implemented as a reusable function the subagent task will call with another history,
agent id and tool set, e.g.
`func (s *Session) runLoop(ctx context.Context, agentID string, hist []provider.Message, ts toolSet) ([]provider.Message, string, error)`
(final text, error): up to `MaxIterations` model calls; each call sends `Model` = model key,
the history, the tool definitions, `Effort`, `SendEffort = ReasoningEnabled()`. Emit `EvText`
per text delta (AgentID = agent id). Append the assistant message (text + tool calls). For each
tool call in order: emit `EvToolCall` (Tool, Args); if the tool is gated,
`Gate.Check(ctx, Mode(), agentID, name, args)`: denied → result `DeniedMessage`; ctx error → stop;
allowed → `Registry.Run(ctx, ...)`; emit `EvToolResult` (Tool, Text = output, IsError); append a
`tool` message with `ToolCallID`. No tool calls → done. After 50 calls that still request tools →
emit `EvError` `iteration limit (50) reached` and stop. Unknown tool names produce an error result
for the model (the registry already does), never a crash.

Tokens: per response with usage, `In += prompt`, `Out += completion`, `Total += total` (or
prompt+completion), context used = last prompt tokens; without usage estimate characters/4
(In from the request messages, Out from the reply text + tool arguments, Total = In+Out
increment; context used = the In estimate).

Errors: provider `EventError` → emit `EvError` (Text = redacted error) and end the turn; the
user message stays in history and the session stays usable.

Cancellation: `Cancel` cancels the turn context: the stream, a running `bash` (the runner kills
its process group on ctx done) and pending approval waits end; the loop then appends a
`cancelled` tool result for every tool call of the last assistant message that has no result (the
history stays valid for the next request), emits `EvInfo` `cancelled`, and the turn ends within
2 s.

Every turn (also failed or cancelled ones) emits `EvTurnDone` as its last event; all events of a
turn are queued before `Wait` returns and before `Busy` turns false. `Reset` cancels a running turn
and waits for it.

Tests in `internal/agent/loop_test.go` (use `providertest`; `SetMode(ModeAuto)` where no approval
is wanted; manual-mode tests answer `EvApproval` from a goroutine reading `NextEvent`):
`TestLoopToolCallThenAnswer`, `TestIterationLimit` (exactly 50 requests), `TestCancelStopsTurn`
(bash `sleep 30`, Cancel, turn ends < 2 s), `TestSubmitNoModel`, `TestSubmitBusy`,
`TestTokenAccounting` (usage 100/20 → 100/20/120, context 100), `TestTokenEstimate`,
`TestProviderErrorShown` (HTTP 500 then a normal reply on the next Submit), `TestEffortSent`,
`TestManualDenyRunsNothing` (denied bash `touch marker` → no marker, model gets `denied by user`).
