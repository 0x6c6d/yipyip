# T102: `--help` usage text and the slash-command list

Phase 1 · Model: haiku: fixed text and a small flag, mechanically checkable · Depends-on: T101 · Covers: R17, R10, R11, R15

## Brief
Add the help text used by `yip --help` and (later) by the `/help` command.

Create `internal/tui/help.go` (package `tui`, standard library only, no Bubble Tea yet):
```go
type CommandInfo struct{ Name, Args, Help string }
func Commands() []CommandInfo // fixed order, see below
func HelpText() string        // commands and keys, one per line
```
`Commands()` returns exactly these 12 entries in this order (Args may be empty):
`/model [provider/model]` (pick or set the model), `/effort [low|medium|high]` (show or set the
reasoning effort), `/mode [auto|manual]` (switch approval mode), `/agents [id | kill id]`
(list, show or cancel subagents), `/init` (write or update AGENTS.md), `/compact` (summarize the
conversation), `/undo` (undo the last turn's file changes), `/new` (start a fresh session),
`/clear` (alias of /new), `/exit` (quit), `/quit` (alias of /exit), `/help` (show this help).

`HelpText()` renders one line per command (`  /model [provider/model]  pick or set the model`)
followed by a `Keys:` block: `Enter` send, `Alt+Enter` new line, `Esc` cancel the running turn,
`Shift+Tab` toggle manual/auto mode, `Ctrl+C` twice quit, `Tab` complete a command, `Ctrl+O`
expand tool results, `PgUp/PgDn` scroll. The text must not contain the words `cost` or `price`
(any case) or the character `$`.

Change `cmd/yip/main.go`: `--help`, `-help` and `-h` print to stdout
`Usage: yip [--version] [--help]`, one sentence saying yip is a terminal coding assistant that
works in the current directory, a blank line, `Commands:` and `tui.HelpText()`; return 0. Like
`--version`, this happens before any config or environment access.

Tests:
- `internal/tui/help_test.go`: `TestHelpTextListsCommands` (all 12 names appear, `Commands()`
  has 12 entries in the order above), `TestHelpTextNoCost` (no `cost`/`price` in any case, no `$`).
- `cmd/yip/main_test.go`: add `TestHelpFlag` (returns 0; output contains every command name).

`scripts/verify/v1/T102.sh` exits 0. It runs the three tests and `make check`, and runs the built
binary with `--help` from an empty temporary directory with an empty HOME and no API key, checking
the 10 command names of the acceptance criterion. Negative: the help output must not contain
