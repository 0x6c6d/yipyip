# T402: HTML-to-text converter (stdlib)

Phase 4 · Model: opus: parser for untrusted input (web pages) · Depends-on: T000 · Covers: R70 (HTML becomes plain text), plan assumption #5

## Brief
v8 adds a tool `web_fetch` that returns a web page as plain text. This task writes only the converter it will use;
the tool comes in another task. Standard library only (`golang.org/x/net/html` is not a dependency and must not be
added; `go.mod`/`go.sum` stay unchanged).

Create `internal/tools/htmltext.go` (package `tools`) with

```go
// htmlToText converts an HTML document to plain text.
func htmlToText(s string) string
```

Rules:
- An own single-pass, linear-time tag scanner (no regexp backtracking over the whole document, no recursion).
  A `<` starts markup only when followed by an ASCII letter, `/`, `!` or `?`; any other `<` is text.
- Comments `<!-- … -->` are dropped; an unterminated comment drops the rest of the input. `<!DOCTYPE …>`,
  `<? … >` and every other tag are dropped. Quoted attribute values may contain `>` (`<a title="a>b">`).
- The content of `script`, `style`, `noscript` and `template` elements is dropped up to the matching closing tag
  (tag names case-insensitive, `</SCRIPT >` with whitespace counts); an unclosed one drops the rest of the input.
- Block-level tags (opening or closing) become a newline: `p`, `div`, `br`, `hr`, `li`, `ul`, `ol`, `dl`, `dt`,
  `dd`, `h1`–`h6`, `tr`, `table`, `thead`, `tbody`, `section`, `article`, `header`, `footer`, `nav`, `aside`, `main`,
  `blockquote`, `pre`, `form`, `title`, `head`, `body`, `html`.
- Entities are decoded with `html.UnescapeString` **after** markup removal, once (so `&lt;script&gt;` ends up as the
  literal text `<script>` and is not parsed again).
- Whitespace: within a line every run of spaces/tabs/other Unicode spaces becomes one space and lines are trimmed;
  runs of empty lines collapse to one newline; the result is trimmed (no leading or trailing whitespace).
- Invalid UTF-8 is replaced by U+FFFD (`strings.ToValidUTF8`).

Tests in a new file `internal/tools/htmltext_test.go`:
- `TestHTMLToText` (table): a page with `<title>`, `<style>.x{color:red}</style>`, `<script>alert("SCRIPTX")</script>`,
  `<p>Hello &amp; welcome</p><div>second   line</div><!-- COMMENTX -->` → contains `Hello & welcome` and `second line` on
  separate lines, and none of `SCRIPTX`, `color:red`, `COMMENTX`, `<`, `>`; upper-case `<SCRIPT>…</SCRIPT >`;
  `noscript` and `template` bodies; unclosed `<script>`; unterminated comment; attribute with `>` inside quotes;
  `a < b` stays `a < b`; `&lt;b&gt;` becomes `<b>` text; `&nbsp;`/numeric entities; whitespace collapse; invalid UTF-8.
- `TestHTMLToTextLarge`: 1 MiB of `<` characters, 1 MiB of `<a ` without `>`, and 100,000 nested `<div>` each convert
  in well under 1 s (assert < 2 s) without panicking.
