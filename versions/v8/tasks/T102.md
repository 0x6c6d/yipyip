# T102: Remove jev from internal/agent (main turn on the session model)

Phase 1 · Model: opus: cross-cutting change of the agent loop and of the provider allowlist source (Consequential assumption #3) · Depends-on: T101 · Covers: R47-R56 removed (agent part: routing, `jev.route`, `min_confidence`, fallback, stats, toggle), changed network rule (jev host leaves the allowlist)

## Brief
v8 removes jev (an external turn-routing service). The TUI no longer calls any jev API (done before this
task). This task removes all jev code from `internal/agent`; every main turn now runs on the session model.
`internal/provider` and `internal/config` still contain their jev code after this task (later tasks remove
it): stop using it from `internal/agent`, do not edit those packages.

Delete:
- `internal/agent/jev.go` (defines `ErrJevNotConfigured`, `ErrJevOff`, `JevTimeout`, `JevStateLimit`,
  `JevStats`, `Tier`/`TierNone`/…, `JevConfigured`, `SetJev`, `JevOn`, `JevStats()`, `SetJevTimeout`,
  `askJev`, `noteJevFallback`, `difficultyQuestion`, `scoreTier`, `tierModel`, `JevRoute`, `routeTurn`,
  `TurnModel`, `TurnTier`, `truncateRunes`, `accountJev`). None of these is used outside jev code.
- `internal/agent/jev_test.go`, `jev_noanswer_test.go`, `jev_norisk_test.go`, `jev_route_test.go`,
  `jev_session_test.go`.

Edit `internal/agent/session.go`:
- remove the fields `jev`, `jevOn`, `jevStats`, `jevTimeout`, `turnActive`, `turnModel`, `turnTier` and the
  `JevClient()` method; remove the block that creates the jev client from `cfg.Jev`;
- the provider HTTP client is built from `cfg.BaseURLs()` (the configured provider base URLs only) instead of
  `cfg.AllowedBaseURLs()`: `provider.NewHTTPClient(cfg.BaseURLs())`; update the `Options.HTTPClient` comment
  accordingly. No other host may enter that allowlist;
- remove jev wording from comments (e.g. "the provider/jev client" → "the provider client").

Edit `internal/agent/loop.go`:
- in `Submit` remove `s.turnModel, s.turnTier = "", TierNone` and `s.turnActive = true`; in `runTurn` remove
  `s.turnActive = false`, `ts.model = s.routeTurn(ctx, user)` and the `s.jevStats.Turns[...]++` block, so
  `ts.model` stays `""` (= the session model) for the main loop; subagents keep setting `ts.model`
  (`runSubagent`). Drop the then-unused `user` parameter of `runTurn` if nothing else uses it;
- in the token accounting remove the `s.accountJev(total)` call;
- remove the routing sentence from the `runTurn` doc comment.

Everything else stays as is: `const MaxIterations = 0`, `const MaxSubagentIterations = 500`, the
`question` tool (always asks the user), approvals. Do not edit `internal/agent/approval.go`. Remove any
remaining `jev`/`typesafe`/`systemone` mention (any case) under `internal/agent/`, comments included.
No new test is required; all existing agent tests must keep passing.
