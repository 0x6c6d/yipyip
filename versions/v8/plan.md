# Plan v8: jev_rate (jev rates a task on request) and web_fetch (read a web page)

_Source: `versions/v8/spec.md` (R68-R78), 2026-10-23; v8 start commit `75b78f2`. Core plan: `Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R68-R73 `jev_rate` tool (score question `taskDifficulty`, unsure → `medium`, not gated, own per-tab counters, `/jev stats tasks`, docs); R74-R78 `web_fetch` tool (always registered, approval-gated, `NewFetchHTTPClient` with a dial-time IP check, HTML → text, untrusted marker, docs); the changed README network rule and the changed v5 "jev only routes" rule (docs, `CLAUDE.md`, system prompt, old tests); rebase of the supervisor-owned v5 `T799.sh` guards to `75b78f2`.
**Explicitly deferred:** spec §7: JS rendering, cookies/login, domain allowlist, caching, PDF/images, POST, size/domain config keys, page summaries; automatic `jev_rate` use, other question types, several texts or file paths per call; changes to `/jev`, `/jev stats`, turn routing, `jev.route`; persisted counters, a toggle or per-session limit for `jev_rate`; README edits.

## Architecture changes
- **internal/agent `jevrate.go`** (new): `jev_rate` tool def + run, added to `turnTools` and `subTools` only while `JevConfigured()`; uses a new shared helper `jevRequest(ctx, state, qs) (answers, usage, cut, err)` (redact → cut to `JevStateLimit` → jev timeout); `askJev` becomes toggle check + `jevRequest` + routing `InputTokens`, same behavior.
- **internal/agent `jev.go`**: `JevStats` gains `Tasks [4]int` (by `Tier`), `TaskFallbacks`, `TaskInputTokens`; `taskQuestion` var (`taskDifficulty`, score, the R69 instructions, the 3 routing levels).
- **internal/tui `jev.go`**: `/jev stats tasks` case (5 lines); `/jev`, `/jev stats` and the usage error unchanged.
- **internal/provider `transport.go`** (additions only): `FetchOptions{Timeout, AllowAddr}`, `ErrAddressNotAllowed`, `NewFetchHTTPClient(FetchOptions) *http.Client` (own `http.Transport`, `Proxy: nil`, no jar, dialer `Control` on the resolved IP, ≤5 redirects re-checked as R74, header-scrubbing round tripper).
- **internal/tools `webfetch.go`, `htmltext.go`** (new): `web_fetch` (URL checks, GET, status/type checks, 1 MiB read, HTML → text with stdlib only, 20,000-rune cut); `registry.go`: `Options.Fetch *http.Client` (nil → default fetch client), `web_fetch` always registered, the web-like name guard exempts exactly `web_search` and `web_fetch`.
- **internal/agent**: `approval.go` + one `gatedTools` line; `Options.FetchClient` (test seam) passed to `tools.Options.Fetch`; `prompt.go` new web sentence. **internal/tui**: approval prompt shows `url` for `web_fetch`; `/help` lists `jev_rate`, `web_fetch`, `/jev stats tasks`.
- **docs/usage.md**, **CLAUDE.md** (not the Delegation workflow section): both tools; no "only routes"/"routing only".
