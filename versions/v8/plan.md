## Scope
**In scope for this version:** §4 removal of all jev code/tests/fake/docs (R47-R56), leftover `jev` key ignored, `/jev` unknown; R68-R71 escalation (`escalate_model`, `escalate_after`, main-loop trigger, info line, docs); R72-R76 `web_fetch` (always registered, gated, `NewFetchHTTPClient` with dial-time IP check, HTML → text, untrusted marker, docs); changed README network rule, R3, R7.

## Architecture changes
- **Removed:** `internal/config/jev.go`, `internal/provider/jev.go`, `providertest/jev.go`, `internal/agent/jev.go`, `internal/tui/jev.go` and every jev test (`*jev*_test.go`, e2e `jev*_test.go`); `Config.Jev` + `fillJev` call; `Config.AllowedBaseURLs` (callers use `BaseURLs()`: the jev host leaves the provider allowlist); Session `jev`, `jevOn`, `jevStats`, `jevTimeout`, `turnActive`, `turnModel`, `turnTier`, `SetJev`/`JevOn`/`JevStats`/`JevClient`/`TurnModel`, `routeTurn`/`accountJev` calls in `loop.go`; tui `jevOn`, `SetJev` in `tabs.go`, status `jev`/`route:` fields, `/jev` in `help.go`.
- **internal/provider `transport.go`:** jev wording only in comments (allowlist is fed by config); v8 adds `FetchOptions{Timeout, AllowAddr}`, `ErrAddressNotAllowed`, `NewFetchHTTPClient(FetchOptions) *http.Client` (own `http.Transport`, `Proxy: nil`, no jar, dialer `Control` on the resolved IP, ≤5 redirects re-checked as R72, header-scrubbing round tripper).
- **internal/config `escalate.go`** (new): `Config.EscalateModel string`, `Config.EscalateAfter int` (default 3), `fillEscalate` after `fillProviders`.
- **internal/agent `escalate.go`** (new): per-run `escalation` state {target, after, failures, done}; `runLoop` builds it only for `MainAgentID`, feeds each tool result, and before the next request swaps `client, m` via `clientFor(target)` and emits the info line.
- **internal/tools `webfetch.go`, `htmltext.go`** (new); `registry.go`: `Options.Fetch *http.Client` (nil → default fetch client), `web_fetch` always registered, the web-like name guard exempts exactly `web_search` and `web_fetch`.
- **internal/agent:** `approval.go` + one `gatedTools` line; `Options.FetchClient` (test seam) → `tools.Options.Fetch`; `prompt.go` web sentence. **internal/tui:** approval prompt shows `url` for `web_fetch`.
- **Docs:** README `## Usage` (jev block out, escalation in), `docs/usage.md`, `CLAUDE.md` (not the Delegation workflow section).
