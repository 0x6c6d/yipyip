# T101: Session Store (Save/Load/List/Delete)

Phase 1 · Model: opus: the Store persists tool results un-redacted (Consequential A13) and derives
the public session id from file content (Consequential A3) — parsing untrusted files + a public id
format · Depends-on: T000 · Covers: R29, R30 (write mechanics), R33 (confinement, no secrets), R16

## Brief
Create the new package `internal/session` (`package session`).

**Files:** `internal/session/session.go` (types), `internal/session/store.go` (Save/Load/List/Delete),
`internal/session/store_test.go`, plus append `.yipyip/` to the repo root `.gitignore`.

Import direction: `internal/session` may import `internal/agent` (for the history type) and
`internal/tools` (for the confinement); it must never be imported by `internal/agent`, and it never
touches `internal/provider` or `internal/config`.

**`SessionData`** (JSON, exported fields with `json` tags) with exactly the R29 fields:
`version` (int, constant `1`), `id` (string), `created`, `updated`, `startdir`, `model`, `effort`,
`mode` (strings — use the agent package's types if their existing types are trivially stringable,
otherwise string), `in_tokens`, `out_tokens`, `total_tokens` (int64), `last_context` (int),
`conversation` (the full agent history type — whatever `agent.Session` already exposes internally is
acceptable, but it must round-trip every field incl. tool calls and results), `history` ([]string,
input history oldest first), `pastes` (map-backed struct: `{n: int, entries: map[string]string}` —
define it as a plain JSON object `{"n": N, "entries": {...}}`), `queue` ([]string, queued messages in
order), `title` (string), `turn` (struct `{active string, started time-ish string/int, interrupted bool}`
— free to shape, but an interrupted turn is stored with `interrupted: true` and is never resumed).
Unknown fields are ignored when loading (`json.Decoder` default — no `DisallowUnknownFields`).

**`Store`** — construct with a start directory: dir = `<startdir>/.yipyip/sessions` (mode 0755,
created lazily). Methods:
- `Save(data *SessionData) error` — writes atomically: temp file in the **same directory**
  (`os.CreateTemp`), chmod 0600, full JSON write, `Sync`/`Close`, then `os.Rename` over the target.
  Id derivation (A3): if `data.ID` is empty, first save to a temp name, SHA-256 the temp file's
  content, set `data.ID` = 12 hex chars of the first 3 bytes (`fmt.Sprintf("%x")`), and write the
  final `<id>.json`; if `data.ID` is already set, save directly to `<id>.json`; set `updated`.
- `Load(id string) (*SessionData, error)` — read `<id>.json`; missing file, `"version": 0`,
  `"version": 2`+ (anything ≠ 1 present), or invalid JSON → error whose text names the file path
  (never a crash, never a panic).
- `List() ([]SessionData, error)` — every valid file, newest first by `updated` (fall back to
  `created`); unreadable/invalid files are skipped without failing the list.
- `Delete(id string) error` — removes `<id>.json`; missing → a normal error naming the file.

All path handling goes through the confinement already used for the start dir: resolve `startdir`
with symlink resolution as `internal/tools`' PathGuard does; if `<startdir>/.yipyip` (or any
ancestor) is a symlink pointing outside the resolved start dir, every method refuses with an error.
The save path never runs a shell command and never reads config or env for secrets.

Title helper (fold here): `Title(users' first message string) string` — first 60 runes of the first
user message, newlines collapsed to one line (spaces), empty input → empty title. Export it so the
TUI can reuse it.

Tests in `internal/session/store_test.go` (names exact; temp `t.TempDir()` start dirs):
- `TestSaveLoadRoundTrip`: fill every field (incl. a history entry, a paste, a queue message, a
  multi-run weakly-typed conversation entry), Save then Load, compare every field; `id` is 12 hex
  lowercase; two saves of the same content keep the id; a changed second save keeps the same id too
  (id derives only when empty).
- `TestSaveAtomicNoTempLeftovers`: after Save, the sessions dir contains exactly one `.json` file
  and no temp/`.`-prefixed leftover (also run Save twice).
- `TestListNewestFirst` / `TestDelete`: three saves with different `updated` (set `updated`
  explicitly through a small time injection — do not sleep; e.g. Save calls a package-level
  `var now = time.Now` the test can stub), List order + Delete removes + Delete of missing id errors.
- `TestLoadVersionMismatch` (negative): write `{"version":0,...}` and `{"version":2,...}` to
  `<id>.json`; both Loads error and the error text contains the file path.
- `TestLoadInvalidJSON` (negative): `not json` → error naming the file; missing file → error.
- `TestLoadUnknownFieldsIgnored` (positive): a valid version-1 file with extra top-level fields
  loads fine.
- `TestSymlinkedRefused` (negative): real start dir `a/`, `a/.yipyip` → symlink to `b` outside →
  Save/Load/List/Delete all return an error (never create anything under `b`).
- `TestNoSecretInFile` (negative): a conversation/tool-result containing `SECRET123` **is** stored
  (R33: un-redacted, as sent to the model) — assert it is present in the raw file bytes — but no api
  key or config material is: Save receives no key field and the struct has none (assert the JSON
  keys are exactly the R29 set).
