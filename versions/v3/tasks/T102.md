# T102: Agent export accessors and restore setters

Phase 1 · Model: opus: touches the Consequential assumptions A5 (interrupted turn stored as
finished) and A3/A13 (id derivation feeds Save; tool results un-redacted by construction) ·
Depends-on: T101 · Covers: R29 (agent side), R34 precondition (fidelity data available)

## Brief
`internal/agent/session.go` (the Session struct file; keep all changes inside `internal/agent`):
add the export/restore seam the TUI will use to assemble `session.SessionData`. Import direction is
`internal/session` → `agent`, so agent gains **no** new import and defines plain accessors with
agent-native types.

Export accessors (method names as below; keep them minimal, nothing else public):
- `History() ` — the full conversation (the same internal slice/structure the provider request is
  built from, incl. every tool call and every tool **result** as sent to the model, i.e.
  un-redacted: do not run the redactor here).
- `TokenCounts() (in, out, total int64)` and `LastContextTokens() int`.
- `ModelName()`, `Effort()`, `Mode()` and their current values as strings.
- `TurnState() (active bool, started string, interrupted bool)` — `interrupted` true when the turn
  was cut by Esc/double Ctrl+C; per A5 an interrupted turn **is** exported as finished
  (`active=false, interrupted=true`), never resumable.

Restore setters, inverse and complete (used by T103/resume later; grouped so one call restores one
session without touching the constructor):
- `RestoreHistory(...)` taking the same type `History()` returns;
- `RestoreTokens(in, out, total int64, lastContext int)`;
- `RestoreModelEffortMode(model, effort string, mode Mode)`.
A restored session keeps its existing context (undo journal, approvals do not need restoring) and
keeps its `Session.Reset`-orthogonal fields intact. Do not change any existing public method's
signature; if the internal history type is unexported, export a thin immutable copy type here and
have `internal/session` convert it — do **not** make `internal/session` mirror agent internals by
duplication; use the agent type (T101 already allows that import direction).

Tests in `internal/agent/export_test.go` (names exact; the package already has test helpers for a
model with a scripted session — reuse them; if you need a scripted provider turn use the existing
fake-provider helper from the tui/agent tests' pattern in that package):
- `TestExportAfterTurn`: run one scripted turn containing a tool call; `History()` length and last
  entries contain the tool call and the tool result text un-redacted: the result containing
  `SECRET123` appears literally in the exported history (`strings.Contains`) — the redaction applies
  to the **view**, never to export (negative-side check that export ≠ Redact()).
- `TestExportTokenCountsAndModel`: after the turn, tokens and model/effort/mode strings match what
  the session reports internally.
- `TestInterruptedTurnExportedAsFinished`: submit, then cancel the turn (the same code path a
  double `Ctrl+C` uses in tests); `TurnState()` returns `active=false, interrupted=true`, and
  `History()` still holds the messages produced until the cancel (A5: stored as finished, files it
  wrote stay).
- `TestRestoreRoundTrip`: capture Export data from a used session, build a fresh `Session` (same
  constructor the other tests use), call the Restore setters, and assert History/counts/model/
  effort/mode equal the original — then Restore must be callable on a used session too (restore
  over existing state works, no panic).
