## Architecture changes
- **new `internal/session`**: `Store` (`<startdir>/.yipyip/sessions`), `SessionData` (R29 fields),
  `Save`/`Load`/`List`/`Delete`; atomic temp+`os.Rename`; all paths through the `tools` PathGuard.
- **changed `internal/agent`**: question gate (waiting pattern of `approval.go`); export accessors +
  restore setters; no import of `internal/session` (import direction session → agent).
- **changed `internal/tools`: none** — `question` lives in `internal/agent` (A1), so `git diff
  --stat 9519824..HEAD -- internal/provider/transport.go internal/tools` stays empty.
- **changed `internal/provider`**: retry loop in `client.go` only (R37); `providertest` scripts
  connect-reset/429/5xx before the first byte; `transport.go` untouched.
- **changed `internal/config`**: settings-write path for exactly `model`/`effort`/`mode`; the load
  and merge path is unchanged.
- **changed `internal/tui`**: tabs (≤8), tab bar, `/sessions`, exit-save, resume picker, question
  overlay, settings persist, shift+enter; per-tab state, global model/effort/mode.
- **changed `cmd/yip`**: `--resume [id]` (alias `-c`) + picker launch; `--help` update. **also**:
  `docs/usage.md` (Sessions/Tabs/Questions/Retry), `.gitignore` (`.yipyip/`), `CLAUDE.md`
  (architecture lines outside its Delegation section). Same delta applied to `Plan.md`.

## Build Phases
### Phase 0: Preflight
- **Checks:** `make check` exits 0 on the v2 baseline; `git diff --stat 9519824..HEAD -- internal/provider/transport.go internal/tools` prints nothing; `git status --porcelain` is empty before the first task.
### Phase 1: session store + save on exit (walking skeleton)
- **Goal:** `internal/session` (Store, SessionData, Save/Load/List/Delete; atomic, confined) + agent export/restore accessors; `/exit`, `/quit`, double `Ctrl+C` save every non-empty tab; `.gitignore` gains `.yipyip/`.
- **Key deliverables:** `internal/session` + tests (round-trip, `version` 0/2 + invalid JSON rejected, unknown fields, List, Delete, symlink refusal, `SECRET123`); exit-path wiring in `cmd/yip`/`internal/tui`.
- **Exit criterion:** `go test ./internal/session && go test ./internal/tui -run ExitSave` exits 0.
### Phase 2: resume, picker, `/sessions`, round-trip fidelity
- **Goal:** R31 `--resume` + picker (R35, R35a); R32 `/sessions` (list/load/rm); R34 fidelity; changed R11 help mentions.
- **Key deliverables:** cmd flag + picker overlay (model-picker pattern); `/sessions` dispatch; e2e `Session` diffing recorded provider requests.
- **Exit criterion:** `go test ./internal/tui -run 'Sessions|Resume' && go test ./e2e -run Session` exits 0.
### Phase 3: connection retries
- **Goal:** R37 retry loop in `internal/provider/client.go`; `providertest` scripts pre-first-byte failures; changed R12 failure behaviour.
- **Key deliverables:** retry loop + `retrying (n/10) in <wait>` status event; negatives: 400 no retry, post-first-byte no retry, no other host ever contacted.
- **Exit criterion:** `go test ./internal/provider -run Retry && go test ./e2e -run Retry` exits 0.
### Phase 4: tabs
- **Goal:** R38 up-to-8 tabs, per-tab state, global model/effort/mode; changed R11 `/new` opens a fresh session in a new tab.
- **Key deliverables:** tab model + bar + keys (`Ctrl+T/W/Tab/Shift+Tab`, `Alt+1`–`Alt+8`); save-on-close; negative: old `Tab`/`Shift+Tab` keys unchanged.
- **Exit criterion:** `go test ./internal/tui -run Tabs` exits 0.
### Phase 5: question tool
- **Goal:** R39 `question` gate in `internal/agent` + overlay in the TUI; turn not finished while the overlay waits.
- **Key deliverables:** gate + overlay (radio/checkbox/free-text rows, `↑`/`↓`/`Space`/`Enter`/`Esc`); e2e `Question` (answer becomes the tool result in the follow-up request).
- **Exit criterion:** `go test ./internal/tui -run Question && go test ./e2e -run Question` exits 0.
### Phase 6: settings persistence, shift+enter, help + docs
- **Goal:** R40 settings write in `internal/config` + TUI trigger; R36 shift+enter; changed R11 help; `docs/usage.md` sections; `CLAUDE.md` lines.
