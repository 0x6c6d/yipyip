# Plan v5: jev routing only, click-to-cursor fix, longer subagent runs

_Source: `versions/v5/spec.md` (2026-10-22). Core plan: `Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** three-tier jev routing `easy`/`medium`/`hard` (R53, R50); `/jev` shows
the route (R55) and `/jev stats` reports routing only, per tier (R56, R48); routing-only fallback
(R52); subagent limit 500 model calls, main agent 50 (R54, R6); click-to-cursor that really moves the
textarea cursor (R41); deletion of jev question answering (R49) and of the jev risk screen (R51);
docs (README `## Usage` jev example, `docs/usage.md`, `/help`, CLAUDE.md architecture).
**Explicitly deferred:** per-tier descriptions in config, jev for chat/code generation, changing the
main agent's 50, new jev question types, any real network call in tests (spec section 7).

## Architecture changes
- **config/jev.go** (changed): `JevRoute{Easy, Medium, Hard}`; only `hard` required; `easy`/`medium`
  optional (absent = ""), each present key checked against configured models, error names the key.
- **agent/jev.go** (changed): `routeTurn` rounds+clamps the score to 0..2 → tier → model (absent tier →
  `hard`); per-turn tier stored on the Session; `JevStats` = per-tier turns and main tokens
  (none/easy/medium/hard), `Fallbacks`, `InputTokens`; `accountJev` adds every main/subagent model
  call's total to the current turn's tier. Removed: `jevRisk`, `riskQuestion`, `noteJev(answered)`,
  `Answered`, `QuestionTokens`/`RoutingTokens`/`OtherTokens`.
- **agent/question.go** (changed): `jevAnswer`, `jevQuestionState`, `withTurnHistory`/`turnHistory`
  and the context key removed; every `question` call goes to the TUI reply channel.
- **agent/approval.go** (changed, security): `SetRiskScreen`, the `risk` hook, `risky()` and the
  "AllowAlways not stored" branch removed; `Check` is the pre-v4 logic; `session.go` wiring removed.
- **agent/loop.go** (changed): `MaxIterations` 50 (main) + `MaxSubagentIterations` 500; `runLoop` takes
  the limit from the agent kind; error `iteration limit (<n>) reached` with the limit used.
- **tui/jev.go** (changed): `/jev` toggles and prints `jev on · easy=<id> medium=<id> hard=<id>` /
  `jev on · no route configured` / `jev off`; `/jev stats` prints the 11 R56 lines.
- **tui/inputmouse.go + mouse.go** (changed): input geometry taken from the rendered layout (the same
  row/column offsets `View()` uses); click sets the textarea's own cursor row/column.
- No new packages, files outside the listed ones only for tests; Commands unchanged.
