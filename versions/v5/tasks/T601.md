## Brief
Update the user documentation to v5. Behaviour to document (already implemented):
- `jev.route` has three keys `easy`, `medium`, `hard`, each a `<provider>/<model>` id of a configured
  provider; only `hard` is required, an absent `easy` or `medium` uses the `hard` model; unknown
  models are rejected at load naming the key (e.g. `jev.route.medium`). Jev rates each user turn
  0/1/2 → easy/medium/hard; the choice holds for the whole turn; the status line shows
  `route: <id>`. Errors, a 10 s timeout or low confidence fall back to the session's model.
- Jev only routes: it no longer answers questions (every `question` goes to the user) and no longer
  screens tool calls in auto mode (approvals are as without jev).
- `/jev` toggles jev and prints `jev on · easy=<id> medium=<id> hard=<id>`,
  `jev on · no route configured` or `jev off`; `/jev stats` prints the 11 routing lines
  (`turns routed easy|medium|hard: N`, `turns not routed: N`, `jev fallbacks: N`,
  `jev input tokens: N`, `main tokens easy|medium|hard|not routed: N`,
  `avg main tokens per turn: easy N, medium N, hard N, not routed N`), per tab, in memory.
- A subagent run stops after 500 model calls, the main agent after 50 per turn.
- A click in the input moves the cursor to the clicked cell.
