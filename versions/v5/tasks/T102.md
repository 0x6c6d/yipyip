# T102: Three-tier turn routing (round, clamp, effective tier)

Phase 1 · Model: opus: decides which paid model runs a whole turn and keeps the routing state sent to jev minimal (Consequential assumptions 1 and 18) · Depends-on: T101 · Covers: R53 (score 0/1/2 → easy/medium/hard for the whole turn, absent `medium`/`easy` → `hard`, status line shows the choice), R50 (changed), R52 (changed: only routing falls back; error, timeout, low confidence → session model, one fallback each; a turn never waits longer than the timeout)

## Brief
State before this task (`internal/agent`): `jev.go` has `routeTurn(ctx, user) string`, called in
`runTurn` (`loop.go`) after `autoCompact`: when `s.JevOn()` and `s.cfg.Jev.Route != nil` it asks jev
one score question (`difficultyQuestion`, state `"request: " + user`, via `s.askJev`, which redacts,
truncates to 2000 runes and applies the 10 s `JevTimeout`, test seam `SetJevTimeout`). Score `< 1` →
`Route.Easy`, else `Route.Hard`; error, wrong answer count or `Confidence < MinConfidence` →
`noteJev(false)` (a fallback) and `""` (the session model). On success it sets `s.turnRouted`,
`s.turnModel` (reset in `Submit`), emits `EvInfo` `jev route: <id>` and returns the id; `ts.model`
then runs every request of the main loop. `TurnModel()` returns the routed id or `""`. The TUI
status line already shows `route: <id>` from `TurnModel()` (keep that). `config.JevRoute` now is
`{Easy, Medium, Hard string}`; `Hard` is always set, `Easy`/`Medium` may be `""`.

Change `internal/agent/jev.go` (and `session.go`/`loop.go` only as needed):
- New exported type and constants, exactly:
  `type Tier int` with `const ( TierNone Tier = iota; TierEasy; TierMedium; TierHard )`
  (TierNone = not routed) and `func (t Tier) String() string` returning `"not routed"`, `"easy"`,
  `"medium"`, `"hard"`.
- Score → tier: `math.Round(score)`, then clamp to 0..2 (0 → easy, 1 → medium, 2 → hard; so 0.49 →
  easy, 0.5 → medium, 1.5 → hard, -3 → easy, 9 → hard); a NaN or infinite score is a fallback.
- Tier → model: the tier's route key; an absent (`""`) `Easy` or `Medium` uses `Hard`, and the
  **effective** tier is then `TierHard` (the tier whose model actually runs).
- Store the effective tier of the current turn on the Session (reset to `TierNone` in `Submit`
  next to `turnModel`); add `func (s *Session) TurnTier() Tier` (running or last turn; `TierNone`
  when not routed). `TurnModel()` keeps its meaning.
- Add `func (s *Session) JevRoute() (easy, medium, hard string)`: the effective model id of each
  tier (absent tier → the `hard` id); all `""` when jev or its route is not configured. (The TUI's
  `/jev` uses it later.)
- Fallback stays exactly R52: jev error, timeout, missing/malformed answer or confidence below
  `min_confidence` → the session's model for the whole turn, `Fallbacks` +1, no `jev route` info.
  The session model (`ModelID()`) is never changed by routing. Esc during routing is not a fallback.
- The jev request stays as in v4: state `request: <redacted user text>`, only the `difficulty`
  score question (its three level texts may stay). Do not change `approval.go`, `question.go` or
  the `JevStats` struct in this task.
