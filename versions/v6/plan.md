# Plan v6: web search (Brave) and reads outside the start directory

_Source: `versions/v6/spec.md`, 2026-10-22. Core plan: `Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** optional `search` config block (R57); search-only allowlist in the
transport (R58, changed R3); gated, redacted `web_search` tool against Brave (R59-R61, changed R7);
`read_file`/`glob`/`grep` read anywhere (R62, changed R4) while `write_file`/`edit_file`/undo stay
confined (R63); `/help`, system prompt, `docs/usage.md`; supervisor update of README sections 1-9.
**Explicitly deferred:** `web_fetch`, other backends, caching, ranking, pagination, search limits,
approval or allow-list for outside reads (spec §7).

## Architecture changes
- **internal/config** (changed): `search.go` parses `search` → `Config.Search *Search{BaseURL, APIKey}`
  (nil when absent); `AllowedBaseURLs()` never contains `search.baseURL`.
- **internal/provider/transport.go** (changed, security): `NewSearchHTTPClient(baseURL)`: own
  `Transport` whose allowlist is exactly the search `host:port`, redirects checked against it,
  `Proxy: nil`, `Timeout` 20 s; provider and jev clients keep `NewHTTPClient(AllowedBaseURLs())`.
- **internal/provider/search.go** (new): Brave client `Search(ctx, query, count)` → `[]Result`/error
  (`GET /res/v1/web/search`, headers, ≤1 MiB body); `providertest/brave.go` (new): fake Brave.
- **internal/tools/websearch.go** (new): `web_search` tool (validation, redaction, formatting);
  registered only when `Options.Search` is set; `registry.go` forbidden-word check allows exactly
  the name `web_search`.
- **internal/tools/pathguard.go** (changed, security): `Resolve` keeps today's write-mode
  semantics (confined); new `ResolveRead` (read mode: absolute/`..`/symlinks anywhere, dangling
  symlink still an error). `files.go` `read_file` and `search.go` `glob`/`grep` call `ResolveRead`.
- **internal/agent/approval.go** (changed, security): `web_search` added to the gated set.
  `prompt.go`: read/write rule, `web_search` mentioned only when registered.
- **internal/tui** (changed): approval summary shows `query` for `web_search`; `/help` line.

changed by exactly one named opus task with negative tests; `redact.go` is changed by no task (if it
must, only the Phase 1 config task, opus, with `SECRET123` negatives). The supervisor checks the diff.
