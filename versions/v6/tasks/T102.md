# T102: Search transport: search-only HTTP client (transport.go)

Phase 1 · Model: opus: changes the security-critical host allowlist `transport.go` (Consequential assumption 2, Risk "Transport allowlist") · Depends-on: T101 · Covers: R58, R3

## Brief
State before this task: `internal/provider/transport.go` is the only place that builds HTTP
clients. `Transport` is an `http.RoundTripper` with a per-instance allowlist of canonical
`host:port` strings (`canonicalHostPort`, no DNS), `Proxy: nil` in the inner `*http.Transport`
(`newInnerTransport`), and requests to other hosts fail with an error wrapping
`ErrHostNotAllowed` without dialing. `NewHTTPClient(baseURLs)` returns an `*http.Client` on such a
Transport whose `CheckRedirect` refuses redirects to hosts outside the same allowlist (at most 10
redirects) and has no overall timeout (responses stream). Provider and jev clients are built with
`NewHTTPClient(cfg.AllowedBaseURLs())`; `config.Config.Search` (`*config.Search{BaseURL, APIKey}`,
nil when absent; T101) never enters `AllowedBaseURLs()`.

Change only `internal/provider/transport.go` (this is the one task allowed to change it) and add
tests:
- `const SearchTimeout = 20 * time.Second`.
- `func NewSearchHTTPClient(baseURL string) (*http.Client, error)`: a new `*Transport` whose
  allowlist is exactly the canonical `host:port` of `baseURL` (built with `NewTransport`), the
  same redirect check as `NewHTTPClient` (redirects to another `host:port` refused with an error
  wrapping `ErrHostNotAllowed`, at most 10), and `Timeout: SearchTimeout`. An empty or invalid
  `baseURL` (no scheme/host, scheme other than http/https) returns `nil` and an error that does
  not contain the URL. Share code with `NewHTTPClient` instead of duplicating the redirect logic.
- `NewHTTPClient`, `NewTransport`, `canonicalHostPort` and their behaviour stay unchanged: the
  search host is never added to the provider/jev client, and the search client reaches only its
  host (no fallback, no proxy, no extra hosts).
- Update the package doc comment if needed; no other file in `internal/provider` changes except
  the new test file.

Tests (exact names) in a new `internal/provider/search_transport_test.go` (package `provider_test`;
plain `httptest.Server`s on 127.0.0.1, each counting its requests; a real config loaded with
`config.Load` from temp files where a test needs `AllowedBaseURLs()`):
- `TestSearchTransportReachesSearchHost`: a client from `NewSearchHTTPClient(s.URL)` GETs
  `s.URL+"/res/v1/web/search?q=x"` (200) and follows a same-host redirect; `Timeout == SearchTimeout`
  and `Transport` is a `*provider.Transport`.
- `TestSearchTransportRefusesProviderHost`: the search client to the provider server and to the
  jev server → error wrapping `ErrHostNotAllowed`, those servers got 0 requests.
- `TestSearchHostRefusedForProviderClient`: with `provider`, `jev` and `search` configured, the client
  from `NewHTTPClient(cfg.AllowedBaseURLs())` to the search server → `ErrHostNotAllowed`, 0 requests.
- `TestSearchHostRefusedForJevClient`: a `provider.NewJevClient` on that client with the search
  server as its base URL → `Ask` fails with `ErrHostNotAllowed`; the search server got 0 requests.
- `TestSearchRedirectRefused`: the search server answers `302` to another server → error wrapping
  `ErrHostNotAllowed`; the other server got 0 requests.
- `TestSearchTransportInvalidBaseURL`: `""`, `"ftp://127.0.0.1"`, `"http://"`, `"127.0.0.1:80"`
  → `nil` client and an error.

## Verification
`scripts/verify/v6/T102.sh` exits 0. It runs the named tests and the whole provider package plus a
supervisor probe (overlay test): positively the search client reaches its host, follows a same-host
redirect and has a 20 s timeout; negatively the provider/jev client is refused for the search host,
the search client is refused for the provider, jev, a foreign host, a different host spelling and a
cross-host redirect (refused hosts get no request), and invalid base URLs build no client. It also
checks that `transport.go` changed while no other security-critical file did and that nothing
outside `internal/provider` changed.
