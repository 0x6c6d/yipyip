Phase 2 · Model: opus: changes the security-critical approval gate `approval.go` (Risk "Approvals") · Depends-on: T000 · Covers: R60 (gate part), R7

## Brief
State before this task: `internal/agent/approval.go` holds the approval gate shared by the main
agent and all subagents. `gatedTools` is a map of tool names (`bash`, `write_file`, `edit_file`,
`spawn_agent`); `IsGated(tool)` looks a name up in it (exact, case-sensitive);
`(*Gate).Check(ctx, mode, agentID, tool, args)` returns true at once for ungated tools and in
`ModeAuto`, returns true for a tool answered "always" (`AllowAlways`) earlier in the session, and
otherwise sends an `*ApprovalRequest{AgentID, Tool, Args}` to the notify callback and waits for
`Allow`/`AllowAlways`/`Deny`; it fails closed (nil gate, nil notify, cancelled context, unknown
decision → false). `Reset` forgets the "always" answers. Existing tests live in
`internal/agent/approval_test.go` (helpers `answering(d)` and `mustCheck`).

Change `internal/agent/approval.go` (this is the one task allowed to change it): add
`"web_search": true` to `gatedTools` (with a short comment). Nothing else in the file changes: no
new logic, no removed lines. Do not change any other production file.

Tests (exact names) in a new `internal/agent/approval_websearch_test.go` (package `agent`; Gate
level, no session needed):
- `TestWebSearchIsGated`: `IsGated("web_search")` is true; `IsGated("Web_Search")`,
  `IsGated("web_search ")`, `IsGated("websearch")` are false; the four v1 gated tools stay gated
  and `read_file`, `glob`, `grep`, `wait_agent`, `cancel_agent`, `question` stay ungated.
- `TestWebSearchGateManualPrompt`: manual mode → notify receives one request with
  `Tool == "web_search"`, the given `AgentID` and `Args` containing the query; `Allow` → true.
- `TestWebSearchGateDeny`: `Deny` → false; a nil-notify gate in manual mode → false; a nil `*Gate`
  → false; a cancelled context → false.
- `TestWebSearchGateAlways`: `AllowAlways` for `web_search` → later `web_search` checks pass
  without a prompt, while `bash` still prompts; `AllowAlways` for `bash` does not let
  `web_search` pass without a prompt; after `Reset` `web_search` prompts again.
- `TestWebSearchGateAuto`: auto mode → true without a prompt.
- `TestWebSearchGateSubagent`: a request from agent id `a1` is labelled `a1`, and an "always"
  given to the main agent's `web_search` also covers `a1` (one gate per session).
