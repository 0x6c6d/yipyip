# T103: Brave search client and fake Brave endpoint

Phase 1 · Model: sonnet: HTTP client and test fake on top of the opus-built search transport, moderate parsing logic · Depends-on: T102 · Covers: R59 (request shape, status and JSON handling), R57 (key only in the Brave request header)

## Brief
State before this task: `internal/provider/transport.go` provides
`NewSearchHTTPClient(baseURL string) (*http.Client, error)` (allowlist = exactly the search
host:port, cross-host redirects refused with `ErrHostNotAllowed`, 20 s timeout). Package
`providertest` holds the httptest fakes; `providertest/jev.go` (`NewJev(fn)`, `JevRequest`,
`JevResponse`, `JevServer{URL}`, `Requests()`, `Close()`) is the pattern to copy.

Create `internal/provider/search.go` (do not change `transport.go` or any other existing file):
- `type SearchResult struct{ Title, URL, Description string }` (raw strings as Brave sends them).
- `type SearchClient struct{ ... }` and
  `func NewSearchClient(hc *http.Client, baseURL, apiKey string) *SearchClient` (`hc` must come
  from `NewSearchHTTPClient`; `baseURL` without trailing `/`).
- `func (c *SearchClient) Search(ctx context.Context, query string, count int) ([]SearchResult, error)`:
  `GET <baseURL>/res/v1/web/search?` + `url.Values{"q": {query}, "count": {strconv.Itoa(count)}}.Encode()`
  built with `http.NewRequestWithContext`, headers `X-Subscription-Token: <apiKey>` and
  `Accept: application/json` (no `Authorization` header). It does not validate or change
  `query`/`count` (the tool does). Response handling:
  - status other than 200 → `*SearchStatusError{Code: <status>}` (body discarded, never echoed);
  - body read through `io.LimitReader` of `MaxSearchBody+1` bytes (`const MaxSearchBody = 1 << 20`);
    longer than `MaxSearchBody` or not valid JSON → error wrapping `ErrSearchInvalidResponse`;
  - JSON `{"web":{"results":[{"title":..,"url":..,"description":..}, ...]}}` → one
    `SearchResult` per element in order; a missing `web` or `results` → zero results, nil error;
  - transport errors are returned wrapped (`fmt.Errorf("search: %w", err)`); no error text ever
    contains the API key or the response body.
- `type SearchStatusError struct{ Code int }` with `func (e *SearchStatusError) Error() string`
  returning `HTTP <code>`; `var ErrSearchInvalidResponse = errors.New("invalid response")`.

Create `internal/provider/providertest/brave.go`, a fake Brave endpoint:
- `type BraveResult struct{ Title, URL, Description string }`
- `type BraveRequest struct{ Method, Path, RawQuery string; Query url.Values; Header http.Header }`
- `type BraveResponse struct{ Status int; Body string; Results []BraveResult; Delay time.Duration }`:
  `Status` 0 or 200 = success; a non-empty `Body` is sent verbatim with `Status` (or 200);
  otherwise the body is `{"type":"search","web":{"results":[...]}}` built from `Results`
  (`title`, `url`, `description`; an empty list for nil). `Delay` waits before replying and ends
  early when the request is cancelled.
- `type BraveServer struct{ URL string; ... }` (`URL` = `http://127.0.0.1:<port>`, no path),
  `func NewBrave(fn func(n int, req BraveRequest) BraveResponse) *BraveServer` (reply to the n-th,
  0-based request), `Requests() []BraveRequest` (copy, arrival order), `Close()`. It records every
  request on any path.

Tests (exact names) in a new `internal/provider/search_test.go` (package `provider_test`, using
`NewBrave` and a client from `NewSearchHTTPClient(brave.URL)`):
- `TestSearchClientRequest`: one call with query `go generics & more?` and count 3 → one request,
  `GET`, path `/res/v1/web/search`, `Query.Get("q")` equals the query exactly, `count` is `3`,
  `X-Subscription-Token` is the key, `Accept` is `application/json`, no `Authorization` header.
- `TestSearchClientResults`: two scripted results come back in order with the raw strings; a
  response without results → empty slice, nil error.
- `TestSearchClientNon200`: status 500 and 401 with a body containing the key and `upstream detail`
  → `*SearchStatusError` with that code (`errors.As`); the error text contains neither.
- `TestSearchClientBadJSON`: body `{nope` → `errors.Is(err, ErrSearchInvalidResponse)`.
- `TestSearchClientBodyLimit`: a valid JSON body larger than 1 MiB → `ErrSearchInvalidResponse`.
- `TestSearchClientCancel`: with `Delay` 5 s, cancelling the context returns an error within 2 s.
