# Plan v4: skills, jev decisions, mouse-friendly input and tabs

_Source: `versions/v4/spec.md`, 2026-10-22. Core plan: `Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R41–R52 (input click/select-to-copy, tab `×`/`+` buttons, 1-row tab
bar, skills + `/skills`, jev client/config, `/jev` + stats, jev question answers, turn routing,
auto-mode risk screen, fallback); changed R36 (Shift+Enter removed), R38 (only `Ctrl+T`/`Ctrl+W`),
R39 (question inline in the transcript), R3 (jev host allowed while configured).
**Explicitly deferred:** spec §7 (image/`box` questions, jev for chat/code, token disk logs, skill
install/remote skills, skill permissions, per-tab model, real network in tests).

## Architecture changes
- New `internal/skills`: `Load(home, startdir)` → `[]Skill{Name, Description, Body, Source}` + warnings;
  hand-written `key: value` frontmatter; project files read through `tools` PathGuard; read-only.
- New `internal/provider/jev.go`: `JevClient.Ask(ctx, state, []Question) ([]Answer, Usage, error)`,
  built with `NewHTTPClient` (no own transport); `providertest` gains a fake System One endpoint.
- Changed `internal/config`: `jev` block (defaults, `{env:}` key into the Redactor, `route` validated
  against configured `provider/model`s at load); jev `baseURL` joins the transport allowlist only if `jev` is set.
- New `internal/agent/jev.go`: decider (question answer, turn routing, risk screen, 10 s timeout,
  fallback, in-memory stats). Changed `approval.go`: one optional `RiskScreen` hook consulted only
  where auto mode would auto-approve; a true result routes into the existing prompt path.
- Changed `internal/tui`: input mouse hit-testing (`mouse.go`/`input.go`), tab bar layout with `×`/`+`
  hit zones (`tabbar.go`), tab keys trimmed (`tabkeys.go`), question as transcript block
  (`question.go`/`blocks.go`), `/skills`, `/jev`, `/<skill>` (`commands.go`), status `jev` + routed model.
- Removed: modifyOtherKeys request (`cmd/yip/main.go`) and Shift+Enter CSI mapping (`internal/tui/keyseq.go`).
