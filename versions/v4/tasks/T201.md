# T201: Skills loader: global dir, project override, skips

Phase 2 · Model: opus: merges untrusted files from two roots and keeps project paths confined (Consequential assumption 6) · Depends-on: T101 · Covers: R45 (global + project, project wins, missing folder fine, bad name/frontmatter skipped with one warning)

## Brief
Extend `internal/skills` (`skills.go`, `skills_test.go`). It already exports
`Source` (`Global`/`Project`), `Skill{Name, Description, Body, Source}`, `GlobalDir(home)`
(= `home/.config/yipyip/skills`), `ProjectDir(startDir)` (= `startDir/.yipyip/skills`),
`Parse(folder, data)` and `Load(home, startDir) ([]Skill, []string)`, which today reads only the
project directory (through `tools.PathGuard`, symlink escapes and files > 256 KiB skipped, one
warning line `skill <folder>: <reason>` per skipped entry). Keep all of that and the API unchanged.

Add:
- `Load` also reads `GlobalDir(home)` when `home != ""`; a missing global directory is fine (no
  warning). The global directory is the user's own and is read directly (no PathGuard), but with
  the same 256 KiB limit, the same parse rules and one warning per skipped entry; warnings of
  global entries name the folder and say `global`, e.g. `skill global/<folder>: <reason>`;
  project warnings may say `project/<folder>`. Every warning is a single line.
- Merge: a project skill with the same `Name` as a global skill replaces it (no warning); the
  result is sorted by `Name`; `Source` tells where each came from.
- Within one source, a duplicate `Name` keeps the first folder in name order, the other is
  skipped with a warning.
- An unreadable directory or file is skipped with a warning, never a panic or error return.
- Still read-only: no writes, renames, removes or mkdirs; no `os/exec`, no `net/http`.

Tests in `internal/skills/skills_test.go` (temp home and start dir; keep the existing tests):
`TestSkillGlobalOnly`, `TestSkillProjectOnly`, `TestSkillProjectOverrides` (same name in both →
project body and `Source == Project`, other global skills still present), `TestSkillBadSkipped`
(invalid `name`, missing frontmatter, unclosed frontmatter in either source → skipped, exactly one
warning line each naming the folder, valid siblings loaded), `TestSkillMissingDirs` (both missing,
`home == ""`).

## Verification
`scripts/verify/v4/T201.sh` exits 0. It runs the named tests and a supervisor probe (overlay test)
for global only, override and skip warnings; negatively it checks that a global skill never beats
the project one, that a project symlink escape stays refused with a global dir present, that the
package has no write/exec/http calls and that protected files are untouched.
