# T406: `/jev` command, `/jev stats` and status line

Phase 4 · Model: sonnet: UI wiring over the finished agent API, no decision or security logic · Depends-on: T402, T403 · Covers: R48 (`/jev` toggles, `jev on`/`jev off`, `jev is not configured`, status shows `jev`, `/jev stats` counters), R50 (status line shows the routed model)

## Brief
State before this task: `agent.Session` has `JevConfigured() bool`, `SetJev(on bool) error`
(`agent.ErrJevNotConfigured` when not configured; stays off), `JevOn() bool`, `JevStats() agent.JevStats`
(`Answered, Fallbacks, InputTokens, QuestionTokens, RoutingTokens, OtherTokens int`) and
`TurnModel() string` (routed model id of the running/last turn, "" when not routed). A jev-answered
question emits an `EvInfo` `jev answered: …`, routing emits `jev route: <id>`; both already render
as info blocks. In `internal/tui`, `commands.go` has the `slashCommands` map (built-ins; a skill
of the same name is shadowed), `help.go` the `/help` text, `status.go` the status line; mode,
model and effort are global across tabs (`globals`/`setGlobals`).

Changes (`commands.go`, `status.go`, `help.go`, a new `jev.go` if useful; no agent changes):
- `/jev` (no args): unconfigured → info line `jev is not configured` (stays off); else toggle and
  print `jev on` or `jev off`. The on/off state is global like mode: apply it to every open tab's
  session and to sessions of tabs opened later. Not saved to settings; off at startup.
- `/jev stats`: info block with exactly these lines for the current tab's session:
  `jev answered: N`, `jev fallbacks: N`, `jev input tokens: N`, `main tokens question: N`,
  `main tokens routing: N`, `main tokens other: N`. Works also when jev is off or unconfigured.
- `/jev <other>`: error line `error: usage: /jev [stats]`.
- Status line: contains the word `jev` while jev is on (absent when off) and `route: <id>` while
  `TurnModel()` is non-empty.
- `/help` lists `/jev` and `/jev stats` with a one-line description each.

Tests (exact names) in `internal/tui/jev_test.go` (drive `Model.Command`/`Update` and `View()`;
build a session whose config has `jev` pointing at `providertest.NewJev` — add a local helper that
writes `<start>/yipyip.json` with `{"jev":{"baseURL":<fake URL>,"apiKey":"{env:TYPESAFE_API_KEY}"}}`
before `config.Load`, fake getenv): `TestJevToggle` (on/off lines, status shows/hides `jev`, a
second tab follows), `TestJevUnconfigured` (no `jev` key and `jev` without key → message, stays
off, no `jev` in status), `TestJevStats` (after one question answered by the fake jev the stats
show `jev answered: 1` and every line), `TestJevHelp` (`/help` lists `/jev`).
