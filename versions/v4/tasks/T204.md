## Brief
Add an end-to-end test of skills against the fake provider. Production code is finished; this
task only touches `e2e/helpers_test.go` and a new `e2e/skills_test.go` (fix production code only
if the test exposes a real bug, and say so).

Existing pieces: `e2e/helpers_test.go` builds an `env` (`Model tui.Model`, `Session`, `Server`
(`*providertest.Server`), `Dir` = start dir, `Home` = temp home) with `newEnv(t, resps...)` /
`newEnvServer`; the config's API key resolves to `SECRET123`; the session is in auto mode;
`e.submit(t, text)` runs `Model.Command`, waits for the turn and drains events. `tui.Options` has
`Home string` (the home whose `.config/yipyip/skills/` holds global skills) and skills are loaded in
`tui.New` and re-read by `/skills`; project skills live in `<Dir>/.yipyip/skills/<name>/SKILL.md`.
On `/exit` the TUI saves the session under `<Dir>/.yipyip/sessions/`.

Changes:
1. `e2e/helpers_test.go`: pass `Home: home` in the `tui.Options` built by `newEnvServer` (no
   other behaviour change for existing tests).
2. `e2e/skills_test.go`, `TestSkillE2E`:
   - After `newEnv`, write a global skill `review` (body `GLOBAL REVIEW`), a project skill
     `review` (body `Review the code. Key: SECRET123`) and a global skill `note` whose body asks
     to write a file; then `e.submit(t, "/skills")` and check the view lists `/review` once as
     `(project)` and `/note` as `(global)`.
   - Script the fake provider so that `/review focus on tests` gets a plain text reply and
     `/note` gets a `write_file` tool call for `notes.txt` and then a text reply.
   - `/review focus on tests`: the user message the provider received is the project body with
     `[redacted]` in place of the key, a blank line, then `focus on tests`; no request message
     contains `SECRET123`; `GLOBAL REVIEW` was never sent.
   - `/note`: `notes.txt` is written in auto mode exactly as a typed request would be (skills
     change nothing about tools or approval).
   - Every `SKILL.md` is byte-for-byte unchanged afterwards.
   - `/exit`: no file under `<Dir>/.yipyip/sessions/` contains `SECRET123`.
   Use only temp dirs; the test must finish in under 10 s.
