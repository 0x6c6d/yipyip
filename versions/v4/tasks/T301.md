# T301: Jev config block (defaults, route validation)

Phase 3 · Model: opus: the jev key is a new secret and the block decides which host becomes reachable (Consequential assumption 2) · Depends-on: T000 · Covers: R47 (config key `jev`, defaults, `{env:TYPESAFE_API_KEY}` key), R50 (unknown `route` models rejected at load, message naming the key)

## Brief
Add the `jev` block to `internal/config` (new file `internal/config/jev.go`, called from
`Config.fill` in `config.go`; tests in new `internal/config/jev_test.go`, package `config`).
Do not change `redact.go` or `env.go`: `{env:NAME}` values are already resolved and registered
with the Redactor by `Load` before `fill` runs.

Exported API (exact names):
```go
const (
	DefaultJevBaseURL       = "https://api.typesafe.ai"
	DefaultJevModel         = "jev-latest"
	DefaultJevMinConfidence = 0.7
)
// Jev is the "jev" object. Config.Jev is nil when the key "jev" is absent.
type Jev struct {
	BaseURL       string    // "baseURL" without trailing "/", default DefaultJevBaseURL
	APIKey        string    // "apiKey", "" when absent (normally "{env:TYPESAFE_API_KEY}")
	Model         string    // "model", default DefaultJevModel
	MinConfidence float64   // "min_confidence", default DefaultJevMinConfidence
	Route         *JevRoute // nil when "route" is absent
}
// JevRoute is "jev.route": model ids "<provider>/<model>" for easy and hard turns.
type JevRoute struct{ Easy, Hard string }
```
and a new field `Jev *Jev` on `Config`.

Rules (each error is returned by `Load`, starts with `config: ` and names the JSON path; an error
never contains a configured or resolved value, only paths):
- `jev` must be an object (`"jev"` named); unknown keys inside it are ignored.
- `baseURL`, `apiKey`, `model` must be strings (path e.g. `jev.model`). `baseURL` must parse as an
  absolute `http` or `https` URL with a host, else an error naming `jev.baseURL`.
- `min_confidence` must be a number in `[0, 1]`, else an error naming `jev.min_confidence`.
- `route` must be an object with string keys `easy` and `hard`, both required; each must name a
  configured model (`Config.Lookup`), else an error naming `jev.route.easy` / `jev.route.hard`
  (e.g. `config: "jev.route.easy" names an unknown model`). Validate after the providers are filled.
- An empty `{}` gives all defaults; `jev` absent leaves `Config.Jev == nil` and changes nothing else.

Tests (exact names) in `internal/config/jev_test.go`, temp HOME/start dir, a fake `getenv` that
maps `TYPESAFE_API_KEY` to `SECRET123`: `TestJevConfigDefaults` (empty block and only apiKey →
defaults; apiKey resolved and redacted by `Config.Redactor`), `TestJevConfigUnset` (no key →
nil), `TestJevConfigValues` (all keys set, trailing `/` trimmed, project file overrides global
key by key), `TestJevRouteUnknownModel` (unknown easy or hard model, missing hard → error naming
the key, never quoting the value), `TestJevConfigInvalid` (non-object, bad baseURL, out-of-range
or non-number min_confidence).
