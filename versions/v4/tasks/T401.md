# T401: Jev decider core (toggle, ask with redaction and timeout, stats)

Phase 4 · Model: opus: every jev request leaves the machine; state must be redacted and bounded, and no turn may wait longer than the timeout (Consequential assumption 3) · Depends-on: T304 · Covers: R48 (on/off state, in-memory counters, main-model tokens split question/routing/other), R52 (10 s timeout), R47 (`state` redacted, at most what the question needs)

## Brief
State before this task: `agent.Session` (fields `cfg *config.Config`, `hc`, `mu`, ...) has
`JevClient() *provider.JevClient` (nil unless `cfg.Jev` is set with a non-empty `APIKey`) and
`Redact(text) string` (uses `config.Redactor`). `provider.JevClient.Ask(ctx, state string,
qs []provider.JevQuestion) ([]provider.JevAnswer, provider.JevUsage, error)`; `JevUsage{Input, Output}`.
`cfg.Jev.MinConfidence` holds the confidence threshold. `Session.account(...)` in `loop.go` adds
the main model's token usage of every request.

Create `internal/agent/jev.go` (+ `internal/agent/jev_test.go`, package `agent`) with exactly:
```go
var (
	ErrJevNotConfigured = errors.New("jev is not configured")
	ErrJevOff           = errors.New("jev is off")
)
const (
	JevTimeout    = 10 * time.Second
	JevStateLimit = 2000 // runes of state sent per question
)
type JevStats struct {
	Answered, Fallbacks, InputTokens            int // jev decisions used / fallbacks / jev input tokens
	QuestionTokens, RoutingTokens, OtherTokens int // main-model tokens by category
}
func (s *Session) JevConfigured() bool        // JevClient() != nil
func (s *Session) SetJev(on bool) error       // on && !configured -> ErrJevNotConfigured, stays off
func (s *Session) JevOn() bool                // off at start, never persisted
func (s *Session) JevStats() JevStats         // copy
func (s *Session) SetJevTimeout(d time.Duration) // test seam; d <= 0 restores JevTimeout
// unexported, used by the later question/routing/risk tasks:
func (s *Session) askJev(ctx context.Context, state string, qs []provider.JevQuestion) ([]provider.JevAnswer, error)
func (s *Session) noteJev(answered bool) // Answered++ when true, else Fallbacks++
```
`askJev`: error wrapping `ErrJevOff` (no request) when off or unconfigured; otherwise
`state = s.Redact(state)` **first**, then cut to at most `JevStateLimit` runes (keep the start),
then `Ask` under `context.WithTimeout(ctx, timeout)`; adds `usage.Input` to `InputTokens`; any
error is returned as is (callers fall back). It never panics and never blocks past the timeout.
`Reset` (`/new`) keeps the on/off state and the counters (process-wide per session).

Token split: in `account` (only when the generation matches, like the existing counters), add
the request's total to `QuestionTokens` when the main agent's reply contains a `question` tool
call, else to `RoutingTokens` when a new unexported field `turnRouted bool` is true (always false
until the routing task sets it), else to `OtherTokens`. Stats are memory only (no file writes).

Tests (exact names): `TestJevSessionToggle` (configured/unconfigured/no key, default off,
`ErrJevNotConfigured`), `TestJevAskRedacts` (state with `SECRET123` and > 2000 runes → fake sees
`[redacted]`, no secret, ≤ 2000 runes; InputTokens counted), `TestJevAskOff`, `TestJevAskTimeout`
(timeout seam 150 ms, fake `Delay` 5 s → error in well under 2 s), `TestJevStatsTokens` (one plain
turn with usage → `OtherTokens`). Build configs like the existing tests (temp HOME, provider fake
`providertest.ConfigJSON`, project `yipyip.json` with `{"jev":{"baseURL": <fake jev URL>,
"apiKey":"{env:TYPESAFE_API_KEY}"}}`, fake `getenv`).
