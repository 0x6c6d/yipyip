# T304: Jev host in the transport allowlist; session jev client

Phase 3 · Model: opus: changes which hosts the single R3 transport lets through (Consequential assumption 2) · Depends-on: T301, T303 · Covers: R3 (changed: also the host of a configured `jev.baseURL`), R47 (jev host allowed only while `jev` is configured)

## Brief
State before this task: `config.Config` has `Jev *config.Jev` (nil when the key `jev` is absent;
fields `BaseURL`, `APIKey`, `Model`, `MinConfidence`, `Route`) and `BaseURLs()` (provider base
URLs). `internal/provider` has `NewHTTPClient(baseURLs)` (the only host-restricted client) and
`NewJevClient(hc *http.Client, baseURL, apiKey, model string) *JevClient` with
`Ask(ctx, state, []JevQuestion) ([]JevAnswer, JevUsage, error)`. `agent.NewSession` builds its
client with `provider.NewHTTPClient(cfg.BaseURLs())` when `Options.HTTPClient` is nil.

Changes (do not touch `transport.go`; the host check stays there):
1. `internal/config/config.go` (or `jev.go`): `func (c *Config) AllowedBaseURLs() []string`
   = `BaseURLs()` plus `Jev.BaseURL` when `Jev != nil` (sorted, unique). Without `jev` it equals
   `BaseURLs()` exactly. `BaseURLs()` itself is unchanged.
2. `internal/agent/session.go`: `NewSession` uses `cfg.AllowedBaseURLs()` instead of
   `cfg.BaseURLs()` (update the `Options.HTTPClient` comment). New method
   `func (s *Session) JevClient() *provider.JevClient`: nil when `cfg.Jev == nil` or its `APIKey`
   is empty; otherwise one client built once in `NewSession` with the session's `hc`,
   `Jev.BaseURL`, `Jev.APIKey`, `Jev.Model`. No second transport or client is built anywhere.
3. Tests (exact names):
   - `internal/provider/jev_allow_test.go` (package `provider_test`, loads a real config with
     `config.Load` from temp files, fake `getenv` mapping `TYPESAFE_API_KEY` to `SECRET123`; fake
     endpoint `providertest.NewJev`): `TestJevHostRefusedUnset` (config without `jev`: a
     `JevClient` on `NewHTTPClient(cfg.AllowedBaseURLs())` aimed at the fake jev URL fails with
     `ErrHostNotAllowed`, 0 requests recorded), `TestJevHostAllowedSet` (with `jev.baseURL` = fake:
     the same call succeeds), `TestTransportJevOnlyItsHost` (with `jev` set, a third 127.0.0.1
     port is still refused).
   - `internal/config/jev_test.go`: `TestJevAllowedBaseURLs` (with/without jev, dedup with a
     provider URL on the same host string).
   - `internal/agent/jev_session_test.go`: `TestJevSessionClient` (jev configured with key →
     `JevClient()` non-nil and `Ask` reaches the fake; without `jev` or without key → nil; the
     session's provider chat still works).

## Verification
`scripts/verify/v4/T304.sh` exits 0. It runs the named tests and a supervisor probe (in package
`agent`) checking the allowlist with and without `jev`; negatively it checks that the session's
client refuses the jev host when `jev` is unset and a foreign host when it is set, that no other
code builds a transport, and that `transport.go`, `approval.go` and protected files are untouched.
