# T302: Fake System One endpoint in providertest

Phase 3 · Model: sonnet: offline test fake with a fixed shape, no security logic · Depends-on: T000 · Covers: R47 (tests run against a fake System One endpoint, never the real host)

## Brief
Add a fake jev ("System One") server to `internal/provider/providertest` in a new file
`internal/provider/providertest/jev.go` with tests in new `jev_test.go` (package `providertest`).
The package keeps importing no yipyip package; standard library only (`net/http/httptest` on
127.0.0.1). Do not change the existing chat fake.

Exported API (exact names):
```go
// JevUsage is the "usage" object of a reply.
type JevUsage struct{ Input, Output int } // "input_tokens", "output_tokens"

// JevRequest is one recorded request.
type JevRequest struct {
	Method, Path string
	Header       http.Header
	Body         []byte
	JSON         map[string]any // decoded body (nil if not JSON)
	Model        string         // "model"
	State        string         // "state"
	Questions    map[string]any // "questions" (name -> question object)
}

// JevResponse scripts one reply.
type JevResponse struct {
	Status  int            // 0 or 200 = success
	Body    string         // non-empty: sent verbatim with Status (or 200)
	Answers map[string]any // success body "answers" (name -> answer object)
	Usage   *JevUsage      // success body "usage" when non-nil, omitted otherwise
	Delay   time.Duration  // wait before replying; ends early when the request is cancelled
}

type JevServer struct{ URL string /* "http://127.0.0.1:<port>", no path */ ; ... }
func NewJev(fn func(n int, req JevRequest) JevResponse) *JevServer // n is 0-based
func (s *JevServer) Requests() []JevRequest // copy, arrival order
func (s *JevServer) Close()

// Answer helpers for JevResponse.Answers.
func JevChoiceAnswer(choice string, confidence float64) map[string]any // {"type":"choice","choice":..,"confidence":..}
func JevScoreAnswer(score, confidence float64) map[string]any         // {"type":"score","score":..,"confidence":..}
func JevNoulAnswer(p float64) map[string]any                          // {"type":"noul","noul":p}
```
Behaviour:
- Only `POST /v1/systemone` is served and recorded (on arrival, before any `Delay`); any other
  method/path → 404 (not recorded, `fn` not called).
- Success (Status 0/200, Body ""): `Content-Type: application/json`, body
  `{"model": <request model>, "answers": Answers, "usage": {"input_tokens": .., "output_tokens": ..}}`.
- Status 422 with Body "": a FastAPI-style body `{"detail":[{"loc":["body","questions"],"msg":"invalid question","type":"value_error"}]}`.
- Any other status with Body "": a short plain text body.
- `Delay` waits, but returns at once (without a reply) when the request context is done; `Close`
  never hangs on a delayed request.

Tests (exact name) `TestJevFakeEndpoint`: success body and recorded fields (method, path,
`Authorization` header, model, state, questions, raw body), the three helpers, 422 detail body,
verbatim body, 404 on another path, a delayed reply cut by a client timeout finishes quickly.
