# T405: Jev risk screen wired into the session (auto mode)

Phase 4 · Model: opus: sends tool arguments to jev and decides whether an auto-mode call gets a prompt; must never remove a prompt or leak a secret (Consequential assumptions 3 and 4) · Depends-on: T401, T404 · Covers: R51 (noul risk question before `bash`/`write_file`/`edit_file` in auto mode, probability ≥ 0.5 → manual approval prompt, manual mode unchanged), R52 (error or timeout → auto mode as is)

## Brief
State before this task (`internal/agent`): `Gate.SetRiskScreen(fn func(ctx, tool, args string) bool)`
in `approval.go` — consulted only in auto mode for `bash`/`write_file`/`edit_file`; `true` routes
that call into the normal approval prompt (`EvApproval`), `false` auto-approves; it can only add a
prompt. `jev.go` provides `s.JevOn()`, `s.askJev(ctx, state, qs)` (redacts, ≤ 2000 runes, 10 s
timeout), `s.noteJev(answered bool)`. `provider.JevQuestion{Name, Type: provider.JevNoul,
Instructions}`, `JevAnswer{Noul}`. The session's gate is `s.gate`, shared with subagents.
Do **not** change `approval.go`.

Changes (`jev.go`, one line in `session.go`'s `NewSession`):
- `NewSession` installs `s.gate.SetRiskScreen(s.jevRisk)`.
- `func (s *Session) jevRisk(ctx context.Context, tool, args string) bool`: returns `false` at
  once without a request when jev is off. Otherwise one noul question (`Name: "risk"`, instructions
  like "Is this tool call risky: destructive, irreversible, leaking secrets or acting outside the
  project?"), state = `tool: <tool>\nargs: <args>` (askJev redacts and bounds it). Error or timeout
  → `noteJev(false)`, `false`. `Noul >= 0.5` → `noteJev(true)`, emit one `EvInfo`
  `jev: risky <tool> call, asking for approval`, `true`. Else `noteJev(true)`, `false`.
- `jevRisk` never approves anything itself and never touches mode, "always" or `Gate` state.

Tests (exact names) in `internal/agent/jev_risk_test.go` (fake provider scripts one `bash` call
`{"command":"echo hi SECRET123"}` then a text reply; config like the other jev tests):
`TestJevRisk` (auto, jev on, noul 0.9 → `EvApproval` for the bash call; Deny → tool result
`denied by user`; Allow → it runs), `TestJevRiskSafeUnchanged` (noul 0.1 → no `EvApproval`, bash runs),
`TestJevRiskManualUnchanged` (manual mode, jev on → `EvApproval` exactly as before and zero jev
requests), `TestJevRiskFallback` (jev 500 and timeout via `SetJevTimeout` → no prompt, bash runs,
`Fallbacks` counted, turn finishes), `TestJevRiskState` (state names the tool and contains no
`SECRET123`; `read_file` in auto mode → no jev request).

## Verification
`scripts/verify/v4/T405.sh` exits 0. It runs the named tests and a supervisor probe of risky,
safe, manual, off, failure and scope cases; negatively it checks that manual mode always still
