# T303: Jev client (internal/provider/jev.go)

Phase 3 · Model: opus: new outbound client to a live system carrying a secret key; must go through the host-restricted transport (Consequential assumption 2) · Depends-on: T302 · Covers: R47 (`POST <baseURL>/v1/systemone`, Bearer auth, body `{model, state, questions}`, types `choice`/`score`/`noul`, answers parsed, 422 or any failure is an error value)

## Brief
Create `internal/provider/jev.go` and tests `internal/provider/jev_test.go` (package
`provider_test`, using `providertest.NewJev` from `internal/provider/providertest/jev.go`, which
records `JevRequest{Method, Path, Header, Body, JSON, Model, State, Questions}` and replies with
`JevResponse{Status, Body, Answers, Usage *JevUsage{Input, Output}, Delay}`; answer helpers
`JevChoiceAnswer(choice, conf)`, `JevScoreAnswer(score, conf)`, `JevNoulAnswer(p)`; `URL` has no path).
Do not change `transport.go`; the client receives an `*http.Client` from `NewHTTPClient` and never
builds a client or transport itself (no `http.Client{}`, `http.Transport{}`, `DefaultClient`).

Exported API (exact names):
```go
const (
	JevChoice = "choice"
	JevScore  = "score"
	JevNoul   = "noul"
)
var ErrJev = errors.New("jev request failed") // wrapped by every error of Ask

type JevQuestion struct {
	Name         string            // key in "questions"
	Type         string            // JevChoice, JevScore or JevNoul
	Instructions string
	Choices      map[string]string // choice: label -> description, 1..255 entries
	Levels       []string          // score: ordered criteria, 1..10 entries
}
type JevAnswer struct {
	Name, Type string
	Choice     string  // choice
	Score      float64 // score
	Confidence float64 // choice, score
	Noul       float64 // noul: probability 0..1
}
type JevUsage struct{ Input, Output int }
type JevClient struct{ /* unexported */ }
func NewJevClient(hc *http.Client, baseURL, apiKey, model string) *JevClient
func (c *JevClient) Ask(ctx context.Context, state string, qs []JevQuestion) ([]JevAnswer, JevUsage, error)
```
Wire format (docs.typesafe.ai/api):
- Request `POST <baseURL without trailing "/">/v1/systemone`, headers `Authorization: Bearer <apiKey>`
  and `Content-Type: application/json`, body
  `{"model": m, "state": s, "questions": {name: {"type": t, "instructions": i, "criteria": c}}}`
  where `criteria` is an object label→description for choice, a JSON array of strings for score,
  and omitted for noul.
- Response 200: `{"model", "answers": {name: {"type","choice","confidence",...} | {"type","score","confidence",...} | {"type","noul"}}, "usage": {"input_tokens","output_tokens"}}`; unknown fields
  (`legend`, `probabilities`) are ignored. Missing usage → estimate both as chars/4 of request and
  response body (at least 1).
- `Ask` returns the answers in the order of `qs`, each with its `Name` and `Type`.

Errors (always wrapping `ErrJev`; also wrap the cause with a second `%w`, e.g.
`provider.ErrHostNotAllowed` or the context error; never a panic; never containing the API key):
invalid questions before any request (none, empty/duplicate name, unknown type, choice count not
1..255, score levels not 1..10); transport error (foreign host → also `errors.Is(err, ErrHostNotAllowed)`);
ctx done; status 422 → message with `422` and the `detail[].msg` texts; any other non-200;
body not JSON; an answer missing or of the wrong type; body larger than 1 MiB.

Tests (exact names): `TestJevRequestShape` (method, path, auth header, content type, model,
state, questions incl. choice object, score array, no noul criteria), `TestJevAnswerTypes` (three
types parsed, order, usage; missing usage estimated), `TestJev422`, `TestJevForeignHostRefused`
(client from `NewHTTPClient` whose allowlist lacks the fake → error wrapping `ErrHostNotAllowed`,
fake records 0 requests), `TestJevBadResponse` (500, non-JSON, missing answer, wrong type),
`TestJevInvalidQuestions`, `TestJevContextTimeout` (Delay 5 s, ctx 200 ms → error well under 2 s).

## Verification
`scripts/verify/v4/T303.sh` exits 0. It runs the named tests and a supervisor probe of request
shape, answers, 422, failures, timeout and invalid questions; negatively it checks that a host not in
the allowlist is never contacted, that the key never shows in an error, that `jev.go` builds no
client/transport of its own, and that `transport.go` and protected files are untouched.
