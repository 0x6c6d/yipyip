# T102: Headless runner skeleton and e2e harness

Phase 1 · Model: opus: the headless runner owns crash handling, redaction and turn lifetime (Plan routing: headless runner) · Depends-on: T101 · Covers: R86, R88, R98

## Brief
Replace the stub `runHeadless` in `cmd/yip/headless.go` with a working one-turn runner, and add the
e2e harness `e2e/headless_test.go`. No Bubble Tea, no tty.

`runHeadless(f flags, d deps, stdin io.Reader, stdout, stderr io.Writer, cs *crashState) int`:
1. Prompt: `f.h.prompt == "-"` → read all of `stdin` (cap 10 MiB); after `strings.TrimSpace` an empty
   prompt is a usage error (`yip: empty prompt`, exit 2).
2. Start dir like `runUI`: `os.Getwd` + `filepath.EvalSymlinks` (a later task adds `--dir`). Home via
   `os.UserHomeDir`, `config.Load(home, startDir, os.Getenv)`; errors → `yip: <err>` on stderr, exit 1
   (pass the message through `cfg.Redactor.Redact` when cfg exists).
3. Crash log exactly like `runUI`: `tools.NewPathGuard(startDir)`, `crashlog.New(...)` with
   `cfg.Redactor.Redact` and `guard.Resolve`, `crashlog.SetDefault`, `cs.logger = ...`, `go cs.logger.Watch(ctx, crashlog.WatchInterval)`
   with a cancelled ctx on return. A panic keeps going through the existing `crashExit` (exit 2).
4. `agent.NewSession(agent.Options{Config: cfg, StartDir: startDir})`; apply the stored model and effort
   the way `applyStoredSettings` does (factor a helper if needed) but never the stored mode;
   `sess.SetMode(agent.ModeAuto)`. Never call `config.SaveSettings`.
5. A prompt starting with `/` → for now `yip: <first word> is not available with -p`, exit 2 (a later task
   adds skills).
6. `sess.Submit(prompt)`; consume `sess.NextEvent(ctx)` until `EvTurnDone`. Collect the final text =
   the main agent's (`AgentID == agent.MainAgentID`) `EvText` deltas of the last assistant message (reset
   the buffer when a main-agent `EvToolCall` follows text). Remember whether an `EvError` occurred.
   On `EvApproval` respond `agent.Deny` and on `EvQuestion` call `Cancel()` for now (later tasks
   replace both). Progress on stderr, one line each, redacted: `tool <name>` on main and subagent
   `EvToolCall`, `subagent <id> <state>` on `EvSubagent`, `retry <text>` on `EvRetry`, `error: <text>` on `EvError`.
7. End: print `sess.Redact(final)` + `"\n"` on stdout; exit 0, or 1 when an `EvError` occurred.
   Nothing else on stdout. Call `sess.Cancel()`/`sess.Wait()` before returning so no goroutine
   outlives the run. No session saving yet.

`e2e/headless_test.go` (package e2e; reuse `cliBinary`, `cliDirs`, `writeCLIGlobalConfig`, `cliResult`):
- helper `runYip(t, home, dir, stdin string, extra []string, args ...string) cliResult` like `runCLI`
  but with `cmd.Stdin = strings.NewReader(stdin)` (never a tty);
- helper `headlessDirs(t, srv *providertest.Server) (home, dir string)` writing
  `providertest.ConfigJSON(srv.URL, "{env:FAKE_KEY}", 100000)` as global config; tests pass
  `FAKE_KEY=SECRET123` in `extra`.
- `TestHeadlessPrompt`: fake replies `Text: "hello world"`; `yip -p hi` → exit 0, stdout exactly `hello world\n`.
- `TestHeadlessStdin`: `yip -p -` with stdin `from stdin`; the fake's last user message is `from stdin`; stdout `hello world\n`.
- `TestHeadlessUsage`: `yip --json` (no `-p`) → 2; `yip -p -` with empty stdin → 2; `yip -p /model` → 2 with exactly one stderr line.
- `TestHeadlessToolProgress`: fake returns a `glob` tool call then text; stderr contains `tool glob`, stdout only the final text.
