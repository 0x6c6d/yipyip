# T302: JSON output and stderr progress wiring

Phase 3 · Model: opus: runner output path where redaction and "nothing else on stdout" must hold (Risk: secrets) · Depends-on: T102, T202, T301 · Covers: R88, R89, R98

## Brief
Wire the records of `cmd/yip/headless_events.go` into `runHeadless` (`cmd/yip/headless.go`).
1. With `--json` (`f.h.json`): every event goes through `mapper{redact: sess.Redact, truncate: 2000}`
   and each record is written with `encodeLine` to stdout. Consecutive `text` deltas of the same agent
   may be merged into one record per assistant message (flush on any other event). `approval`
   records: one per `EvApproval` with the decision taken (for now always `denied` in manual mode;
   auto mode emits none since the gate does not ask). The very last line is exactly one `result`
   record. Nothing else is written to stdout (progress lines go to stderr only without `--json`;
   with `--json` stderr stays empty except fatal errors).
2. Without `--json`: unchanged from the skeleton (final text + newline on stdout, progress on stderr).
3. Result fields: `session_id` "" (saving comes later), `exit_code`, `reason` (`done` or `error` for now),
   `final_text` (redacted), `model_calls` = `sess.ModelCalls()`, `subagents` = number of distinct
   subagent ids seen, `tokens` from `sess.TokenCounts()` (in/out), `duration_ms` since start,
   `tools` = count of `tool_call` events per tool name (all agents), `files_changed` = sorted unique
   start-dir-relative paths from successful (`!IsError`) `write_file`/`edit_file` results of any
   agent (path taken from the matching call's JSON `path` argument; absolute paths made relative with
   `filepath.Rel(startDir, …)`; bash not tracked).
4. Keep the runner readable: put the event loop in a small `runner` struct (state: final text,
   counts, files, error flag) in `headless.go`; later tasks add answers, approvals, limits, saving.

E2E tests in new `e2e/headless_json_test.go` (helpers `runYip`, `headlessDirs` from `e2e/headless_test.go`):
- `TestHeadlessJSON`: fake: `write_file` call `{"path":"a.txt","content":"x"}`, then text `done`.
  `yip -p go --json`: exit 0; every stdout line `json.Unmarshal`s; each line's first key is `type`
  (check with `strings.HasPrefix(line, "{\"type\":")`); `tool_call` and `tool_result` present; last line
  is `result` with all keys listed above, `reason` `done`, `final_text` `done`, `files_changed` `["a.txt"]`,
  `tools` `{"write_file":1}`, `model_calls` 2.
- `TestHeadlessSubagent`: main calls `spawn_agent` `{"task":"sub"}` then `wait_agent` with the returned id
  (use `providertest.NewFunc` and inspect the request messages to answer the subagent with text `sub done`
  and the main agent with text `main done`); `--json` trace contains `subagent` records (with that id) and
  `result.subagents == 1`. Without `--json`, stderr contains a `subagent ` line.
