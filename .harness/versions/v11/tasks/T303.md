# T303: Transcript file and secret redaction

Phase 3 · Model: opus: file write confined by PathGuard and secret redaction (Consequential A14, Risk: secrets) · Depends-on: T302 · Covers: R97, R98

## Brief
Add `--transcript <file>` to `runHeadless` (`cmd/yip/headless.go`).
- Resolve the path with the existing `tools.NewPathGuard(startDir)` + `guard.Resolve(path)` (write mode;
  relative paths are relative to the start dir). An error (outside the start dir, symlink escape) →
  `yip: transcript path outside the start directory` on stderr, exit 2, **before** any model call and
  before creating any file. Never re-implement path checks.
- Create/truncate the file with mode 0600 (`os.OpenFile(..., O_CREATE|O_TRUNC|O_WRONLY, 0o600)`).
- Write the same records as `--json` (also when `--json` is not given), but with a second mapper whose
  `truncate` is 0 (tool output untruncated), and the same final `result` record. Every string passes
  `sess.Redact`. Close the file before exit (also on error exits 1, 3, 4, 5).
- Audit the runner for unredacted output: stderr lines, error messages from config/session/provider,
  final text, JSON records, transcript. A config secret (an `{env:NAME}` value) must never appear.

E2E tests in new `e2e/headless_transcript_test.go`:
- `TestHeadlessTranscript`: `--transcript out/t.jsonl` (create `out/` first): file exists, mode 0600,
  every line parses, last line `result`; a tool output of 3,000 characters appears in full in the
  transcript but truncated (`…[truncated]`) in `--json` stdout.
- `TestHeadlessTranscriptOutside`: `--transcript ../t.jsonl` and `--transcript /tmp/x.jsonl` → exit 2,
  no file created, the fake provider saw 0 requests. Also a symlink inside the start dir pointing outside → exit 2.
- `TestHeadlessSecret`: config apiKey `{env:FAKE_KEY}` with `FAKE_KEY=SECRET123`; the fake echoes
  `SECRET123` in its text and in a tool call argument (e.g. `bash` `{"command":"echo SECRET123"}`);
  run with `--json --transcript t.jsonl` and once without `--json`: `SECRET123` is absent from stdout,
  stderr and the transcript file.

## Verification
`.harness/verify/v11/T303.sh` exits 0. It runs the three e2e tests and, as negative checks with the built
binary, that a transcript path outside the start dir exits 2 without creating the file.
