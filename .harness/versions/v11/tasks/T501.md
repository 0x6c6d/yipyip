# T501: Paste text shown expanded

Phase 5 · Model: haiku: small, mechanically verifiable TUI display fix (Plan routing example: v11 R99 shown fix) · Depends-on: T000 · Covers: R99

## Brief
A paste in the TUI input is stored in `m.pastes` and shown in the input as a placeholder
`[Pasted text #N …]`. After Enter the transcript block must show the full pasted text, not the
placeholder. The text sent to the model is already expanded; keep it unchanged. The input field keeps
showing the placeholder while typing; the input history keeps its entries as they are today.

Change only `internal/tui`:
- `internal/tui/model.go` `Command`: `m.sendUser(m.pastes.expand(text), m.pastes.expand(text))`
  (shown = expanded; compute it once).
- `internal/tui/skills.go` `runSkill`: shown = `m.redact(m.pastes.expand(text))`.
- `internal/tui/input.go` `sendQueue`: the user block added per queued message shows
  `m.pastes.expand(q)` instead of `q`.
Blocks are rendered through the redactor already; do not bypass it. Check `m.pastes` may be nil
(`expand` on nil must be safe; read `input.go`).

New test file `internal/tui/paste_shown_test.go` (look at `internal/tui/queue_test.go` and
`input_test.go` for how tests build a `Model` with a fake-provider session, send a paste
`tea.KeyMsg{Type: tea.KeyRunes, Runes: ..., Paste: true}` and press Enter):
- `TestPasteShown`: paste `"line one\nline two\nline three"`; before Enter the input view contains
  `[Pasted text`; after Enter the rendered transcript (`View()` or the blocks text) contains all three
  lines and no `[Pasted text`; the fake provider's last user message equals the same three lines.
- `TestPasteShownQueued`: while a turn is busy, paste three lines and press Enter (queued); after the
  turn ends and the queue is sent, the transcript contains the three lines and no `[Pasted text`.
