# T403: Approve flag and manual mode

Phase 4 · Model: opus: the runner answers the approval gate; a wrong default would run unapproved tools (Consequential A6, Risk: approvals) · Depends-on: T302 · Covers: R93, R94

## Brief
1. `--mode auto|manual` (parsed by `parseArgs` into `f.h.mode`): `runHeadless` sets `sess.SetMode`
   accordingly; default (empty) is `agent.ModeAuto`. The stored mode in the config is never used and
   nothing is written to `config.json`.
2. `--approve` names (`f.h.approve`): each must be `all` or a registered tool name. Add to
   `internal/agent/session.go` an accessor `func (s *Session) ToolNames() []string` (sorted names of
   every tool the main agent offers: registry tools plus `spawn_agent`, `wait_agent`, `cancel_agent`,
   `question`). An unknown name → `yip: unknown tool <name> in --approve` on stderr, exit 2, before any
   model call (also in auto mode).
3. `EvApproval` handling in the runner: approved when the list contains `all` or `ev.Approval.Tool` →
   `ev.Approval.Respond(agent.Allow)`; otherwise `ev.Approval.Respond(agent.Deny)` (the model gets the
   usual denial result from the gate). Every gated call produces one `approval` record (agent, tool,
   summary, decision `approved`/`denied`); without `--json` stderr gets `approval <tool> <decision>`.
   Summary = redacted, single-line, at most 200 runes: for `bash` the `command` argument, for
   `web_fetch` the `url`, for `web_search` the `query`, for file tools the `path`, else the raw args.
   The gate decision logic itself stays in `internal/agent/approval.go` (do not modify it). Never use
   `AllowAlways`.

E2E tests in new `e2e/headless_approve_test.go` (fake: `bash` `{"command":"echo hi > ran.txt"}` then text `ok`):
- `TestHeadlessApprove`: `--mode manual --json` → exit 0, an `approval` record with `tool` `bash` and
  `decision` `denied`, `ran.txt` absent, the fake's next request has a tool message for that call (the
  denial). Same with `--mode manual --approve bash --json` → `decision` `approved`, `ran.txt` exists.
  `--approve all` behaves like a named approval.
- `TestHeadlessApproveUnknown`: `--approve nosuchtool` → exit 2, 0 requests at the fake.
- `TestHeadlessAutoNoApproval`: default mode, no `--approve` → `ran.txt` exists, no `approval` record.
- `TestHeadlessManualOtherToolDenied`: `--mode manual --approve write_file` and a `bash` call → denied.
