# T203: Session FromAgent and ApplyTo helpers

Phase 2 · Model: opus: cross-cutting refactor of the v10 save/resume path (Consequential A10) · Depends-on: T000 · Covers: R91

## Brief
Move the agent-session ↔ `SessionData` conversion out of `internal/tui` into `internal/session` so
the TUI and the headless runner share it. `internal/session` may import `internal/agent` (agent does
not import session; keep it so: no import cycle).

New file `internal/session/agent.go`:
```go
// FromAgent builds the session data of sess: ID = id, Created = created, StartDir, Model, Effort,
// Mode, token counts, LastContext, Conversation (every history entry incl. tool calls with
// Type "function"), Title (session.Title of the first user message), Turn{Started, Interrupted:
// interrupted || active}. TUI-only fields stay empty but non-nil: History []string{}, Pastes with an
// empty Entries map, Queue []string{}. ok is false when the history has no user message.
func FromAgent(sess *agent.Session, id, created string) (d *SessionData, ok bool)
// ApplyTo restores d into sess: history (RestoreHistory) and tokens (RestoreTokens). It does not
// change model, effort or mode (callers decide).
func ApplyTo(d *SessionData, sess *agent.Session)
```
Then use them in `internal/tui/save.go` (`assembleSession`: call `FromAgent`, then fill History,
Pastes, Queue from the TUI state) and `internal/tui/resume.go` (`restoreInto`: call `ApplyTo`, keep the
mode/effort/`setGlobals` logic in the TUI). Behaviour and saved bytes must stay identical: all existing
`internal/tui`, `internal/session`, `cmd/yip` and `e2e` tests (Session, Autosave, Retention) pass unchanged.

Tests in `internal/session/agent_test.go` (build an `agent.Session` against `providertest` with a
temp config, like the agent package tests do; run one turn with a tool call + text):
- `TestFromAgent`: fields as above; `ok == false` for a fresh session; tool calls preserved.
- `TestFromAgentRoundTrip`: `FromAgent` → `Store.Save` → `Store.Load` → `ApplyTo` into a new session →
  `History()` equal to the original; token counts equal.
- `TestApplyToKeepsModelAndMode`: `ApplyTo` with data whose Model/Mode differ leaves the target's model and mode unchanged.
