# T406: Dir, overrides and system-append

Phase 4 · Model: opus: `--dir` defines the only write area (Consequential A2) and overrides must never write config · Depends-on: T201, T302 · Covers: R94, R96, R98

## Brief
In `runHeadless` (`cmd/yip/headless.go`):
- `--dir <path>`: start dir = `filepath.EvalSymlinks(filepath.Abs(path))`; missing or not a directory
  → `yip: <path>: not a directory` (or the stat error, redacted) on stderr, exit 1. This start dir is
  used everywhere the current one was: `config.Load` (project `yipyip.json`), PathGuard, crash log,
  agent session, skills, session store, `--transcript` resolution. Never call `os.Chdir`. Without
  `--dir` the start dir stays the symlink-resolved working directory.
- `--model <id>`: after the stored model is applied, `sess.SetModel(id)`; error → `yip: <redacted err>`,
  exit 2, before any model call. `--effort <level>`: `sess.SetEffort(level)` (low, medium, high);
  error → exit 2. Never call `config.SaveSettings` or write any config file.
- `--system-append <text>` → `agent.Options.SystemAppend` when building the session (the option
  exists in `internal/agent`; do not change agent code).

E2E tests in new `e2e/headless_dir_test.go`:
- `TestHeadlessDir`: run with the process cwd = a different temp dir and `--dir <work>`; fake calls
  `write_file` `{"path":"a.txt","content":"x"}` then `write_file` `{"path":"../escape.txt","content":"x"}`
  then text: `work/a.txt` exists, `escape.txt` exists neither in the parent of work nor in the cwd,
  the second `tool_result` has `ok` false. A `yipyip.json` in `work` with `"default_model":"fake/m2"`
  is honoured (fake request `model` is `m2`).
- `TestHeadlessDirMissing`: `--dir /nonexistent/x` → exit 1, 0 requests.
- `TestHeadlessOverride`: global `config.json` (the `providertest.ConfigJSON` config) plus the stored settings
  `"effort":"high","mode":"manual"` (default_model `fake/m1`); run with `--model fake/m2 --effort low` → request `model` is `m2`; `config.json`
  byte-identical afterwards (compare bytes and mtime); stored `mode: manual` is ignored (a `bash` call
  runs without an approval record). `--model nope/x` → exit 2, config unchanged; `--effort extreme` → exit 2.
- `TestHeadlessSystemAppend`: `--system-append "APPEND-XYZ-9"` → the fake's first request has a system
  message containing `APPEND-XYZ-9`; a second run without the flag does not.
