# T202: Shared MaxModelCalls counter

Phase 2 · Model: opus: concurrency and a money brake shared by main agent and subagents (Consequential A4, Risk "money") · Depends-on: T000 · Covers: R95

## Brief
Add a model-call budget to `internal/agent` that counts every provider request of the main agent and
of all its subagents. Files: `internal/agent/session.go`, `internal/agent/loop.go` (and
`internal/agent/subagent.go`/`agenttools.go` only if subagent runs do not go through `runLoop`), new
`internal/agent/modelcalls_test.go`.

API:
```go
// in Options
MaxModelCalls int // 0 = unlimited; otherwise the total number of provider requests of the session
// exported error
var ErrModelCallLimit = errors.New("model call limit reached")
// accessor
func (s *Session) ModelCalls() int // provider requests made so far in this session (all agents)
```
Rules:
- One atomic counter per `Session` (`sync/atomic`), shared by the main agent and every subagent;
  incremented exactly once per provider request (one `Stream` call; retries of the same request
  inside the provider client are not new calls), checked *before* the request: when
  `MaxModelCalls > 0` and the counter already equals `MaxModelCalls`, the request is not made and the
  loop returns an error that wraps `ErrModelCallLimit` (`errors.Is` works) with a message naming the
  limit, e.g. `model call limit reached (2)`. Exactly n requests reach the provider; a turn that
  finishes within n calls ends normally.
- In the main agent the error is reported like other loop errors (an `EvError` event whose text
  contains `model call limit reached`, then `EvTurnDone`). In a subagent it fails that subagent; the
  main agent's next request is then refused too, so the turn ends with the error. Make sure the turn
  error path keeps the history valid (existing `closeOpenCalls`).
- The counter is not reset by `Reset()` (the budget is per session/run). `MaxModelCalls == 0` keeps
  today's behaviour exactly (main unlimited, subagents 500 per run).
- No data race: `go test -race ./internal/agent/` must pass.

Tests (`modelcalls_test.go`, fake provider `providertest.NewFunc` that always returns a `glob` tool
call `{"pattern":"*"}` so the loop never ends by itself; auto mode):
- `TestModelCallLimitMain`: `MaxModelCalls: 2` → fake saw exactly 2 requests, an `EvError` containing
  `model call limit reached`, `ModelCalls() == 2`.
- `TestModelCallLimitSubagents`: `MaxModelCalls: 3`; the main agent's first reply calls `spawn_agent`
  (task "x") and the subagent's replies are endless `glob` calls → total requests seen by the fake == 3.
- `TestModelCallLimitWithin`: `MaxModelCalls: 5`, fake replies plain text → turn ends without error, `ModelCalls() == 1`.
- `TestModelCallsUnlimited`: no limit, 3 tool rounds then text → 4 requests, `ModelCalls() == 4`.
