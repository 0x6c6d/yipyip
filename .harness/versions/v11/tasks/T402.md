# T402: Answer flag and question exit

Phase 4 · Model: opus: the runner replies to the question gate and cancels the turn and its subagents · Depends-on: T302 · Covers: R90, R92

## Brief
In `runHeadless` (`cmd/yip/headless.go`, the `runner` struct) handle `agent.EvQuestion`:
- Always emit a `question` record (with `--json` / `--transcript`) carrying the redacted question text,
  options and `multiple`; without `--json` print `question: <text>` on stderr.
- Keep a counter of questions asked in this run (main agent and subagents, in event order). The n-th
  question (1-based) gets `f.h.answers[n-1]` via `ev.Question.Respond(answer)`, passed verbatim (an
  option label or free text; the question tool already maps it).
- A question beyond the given answers: `ev.Question.Cancel()`, then cancel the turn (`sess.Cancel()`,
  which also cancels subagents; verify that in `internal/agent/loop.go`), wait for it to end, and finish
  with reason `question`, exit code 3. The `result` record has `exit_code` 3 and reason `question`;
  without `--json` the final text printed is whatever main-agent text exists (may be empty) and stderr
  gets `yip: unanswered question`.
- Do not answer questions from any other source; never block forever: a question during shutdown is cancelled.

E2E tests in new `e2e/headless_question_test.go` (question tool call args like
`{"question":"Pick?","options":["A","B"]}`; inspect `e2e/question_test.go` for the exact shapes and how
the answer appears in the next request's `tool` message):
- `TestHeadlessAnswerOrder`: fake asks question 1 (options A, B), then question 2 (free text), then
  replies text `end`. `--answer B --answer "my words" --json` → exit 0; the tool result for question 1
  carries `B`, for question 2 `my words`; two `question` records in order.
- `TestHeadlessExit3`: one question, no `--answer` → exit 3; `--json` last line `result` with
  `exit_code` 3, reason `question`; a `question` record containing `Pick?`; the fake saw exactly 1 request.
- `TestHeadlessExit3Extra`: two questions, one `--answer` → first answered, second ends the run with exit 3, fake saw 2 requests.
