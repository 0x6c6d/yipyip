# T401: Slash prompts and skills

Phase 4 · Model: sonnet: dispatch logic reusing existing skill loader and built-in list · Depends-on: T102 · Covers: R87

## Brief
Headless prompts that start with `/` (`cmd/yip/headless.go`):
- Load skills with `skills.Load(home, startDir)` (warnings go to stderr as `warning: <text>`, redacted).
- Built-in slash commands win over skills (same rule as the TUI). Export from `internal/tui` a
  function `func IsBuiltinCommand(name string) bool` (in `internal/tui/skills.go`, wrapping the existing
  `shadowed`/`slashCommands` lookup; `name` without the slash) and use it.
- `/<name> args` where `<name>` is a loaded, non-built-in skill → the user message is the skill body,
  plus `"\n\n" + args` when args are given (exactly as `runSkill` in `internal/tui/skills.go` builds it),
  passed through `sess.Redact` before `Submit`. The turn then runs as usual.
- Every built-in (`/model`, `/agents`, `/help`, `/init`, `/compact`, ...) and unknown `/x` → exactly one
  stderr line `yip: /x is not available with -p` and exit 2, before any model call (with `--json`,
  stdout gets only a `result` record with reason `usage` and exit_code 2, if the record helper exists;
  otherwise nothing).

E2E tests in new `e2e/headless_skill_test.go`:
- `TestHeadlessSkill`: project skill `.yipyip/skills/greet/SKILL.md` (frontmatter `name: greet`,
  `description: d`, body `SKILL-BODY-7`); `yip -p "/greet world"` → exit 0; the fake's user message is
  `SKILL-BODY-7\n\nworld`.
- `TestHeadlessSlashModel`: `-p /model` → exit 2, exactly one non-empty stderr line containing `/model`,
  0 requests at the fake.
- `TestHeadlessSlashUnknown`: `-p /nosuch` → exit 2, 0 requests.
- `TestHeadlessSkillShadowed`: a skill named `help` is not run; `-p /help` → exit 2.
