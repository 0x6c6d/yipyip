# T301: JSONL record mapping

Phase 3 · Model: sonnet: pure data mapping with unit tests (Plan routing: JSONL event mapping) · Depends-on: T101 · Covers: R89

## Brief
New file `cmd/yip/headless_events.go` (+ `cmd/yip/headless_events_test.go`): the record types of the
`--json` trace and the mapping from `agent.Event`. No I/O wiring here (another task does it).

Records are structs whose first field is `Type string \`json:"type"\`` so `encoding/json` writes
`"type"` first. Shapes (JSON keys):
- `text`: `agent`, `text`
- `tool_call`: `agent`, `name`, `args` (string, redacted)
- `tool_result`: `agent`, `name`, `ok` (bool), `output` (string)
- `subagent`: `id`, `state`, `task`, `model`
- `question`: `agent`, `question`, `options` ([]string), `multiple` (bool)
- `approval`: `agent`, `tool`, `summary`, `decision` (`approved` or `denied`)
- `retry`: `text`
- `error`: `agent`, `text`
- `result`: `session_id`, `exit_code`, `reason`, `final_text`, `model_calls`, `subagents`,
  `tokens` (`{"in":N,"out":N}`), `duration_ms`, `tools` (object name → count), `files_changed`
  ([]string, never null: `[]`). No `cost` key (no price config exists).

API:
```go
type mapper struct {
    redact   func(string) string // every string field passes it
    truncate int                 // max runes of tool_result output; 0 = untruncated
    sub      func(id string) (task, model string) // subagent lookup; may be nil
}
// records maps one event to zero or more records (EvInfo, EvCheckpoint, EvTurnDone → none).
func (m mapper) records(ev agent.Event) []any
type resultRecord struct { /* fields above */ }
func encodeLine(w io.Writer, rec any) error // json.Marshal + "\n", HTML escaping off
```
Details: `tool_result` output longer than `truncate` runes is cut to `truncate` runes plus
`…[truncated]`; `ok = !ev.IsError`. `subagent` records come from `EvSubagent`: the event carries the
id in `AgentID` and `"<id> <status>"` in `Text` (see `newManager` in `internal/agent/agenttools.go`);
task and model come from an optional `mapper` field `sub func(id string) (task, model string)` that the
runner fills from `sess.Subagents()` (nil → empty strings). Do not change `internal/agent`. `question` from `ev.Question` (question text, options, multiple).
`approval` records are built by the runner (`approvalRecord(agentID, tool, summary string, approved bool)` helper here).
Text deltas: `records` returns one `text` record per `EvText` event (the runner may merge).

Tests (`headless_events_test.go`):
- `TestRecordTypeFirst`: for every record kind, the encoded line starts with `{"type":"<kind>"`.
- `TestToolResultTruncated`: 5,000-rune output with `truncate: 2000` → 2000 runes + `…[truncated]`; `truncate: 0` → full.
- `TestRecordRedacted`: with `redact` replacing `SECRET123` by `[redacted]`, no encoded record of any kind contains `SECRET123`.
- `TestResultFields`: encoded `resultRecord` has exactly the keys `type, session_id, exit_code, reason,
  final_text, model_calls, subagents, tokens, duration_ms, tools, files_changed`; empty `files_changed` encodes as `[]`.
