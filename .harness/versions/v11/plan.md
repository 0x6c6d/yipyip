# Plan v11: headless mode + paste display fix

_Source: `.harness/versions/v11/spec.md` (2026-11-05). Core plan: `.harness/Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R86–R100 (headless `yip -p` one-turn runner with JSONL trace, exit codes, limits,
isolation flags; paste placeholder expanded in the transcript; docs), changed R85 CLI rule (headless flags accepted).
**Explicitly deferred:** long-running stdio protocol, server/HTTP mode, MCP, images, other TUI changes, loop skill
changes, price configuration (so `cost` is never emitted, A3), checkpoint autosaves in headless runs.

## Architecture changes
- **cmd/yip** (changed): `parseArgs` accepts `-p/--prompt` (`-` = stdin), `--json`, `--answer` (repeatable),
  `--approve` (repeatable, comma list), `--dir`, `--model`, `--effort`, `--mode`, `--timeout`, `--max-model-calls`,
  `--system-append`, `--no-save`, `--transcript`, `--resume <id>`; `--flag=value` and `--flag value` forms; headless
  flags without `-p` → usage error, exit 2. `--help` lists all of them plus exit codes.
- **cmd/yip/headless.go** (new): `runHeadless(f, d, stdin, stdout, stderr, cs)`; no Bubble Tea program. Loads config
  for the start dir, sets up crashlog + `Watch` like `runUI`, builds `agent.Session`, applies stored model/effort
  (never mode), then the overrides (never `config.SaveSettings`), restores `--resume`, submits, consumes
  `NextEvent` until `EvTurnDone`, answers `EvQuestion` (`--answer`) and `EvApproval` (`--approve`), saves, prints.
- **cmd/yip/headless_events.go** (new): event → JSONL record mapping (`type` first via ordered struct fields),
  `result` record, stderr progress lines, transcript writer; every string passes `sess.Redact`.
- **internal/agent** (changed): `Options.SystemAppend string` (appended to the system prompt after a blank line;
  also on `/new`-style resets); `Options.MaxModelCalls int` (0 = unlimited) = one atomic counter shared by the main
  agent and every subagent, checked before each provider request; when exceeded the call is not made and the run
  ends with `ErrModelCallLimit` (exported, `errors.Is`-able, reported in the turn's error event); `ModelCalls() int`.
- **internal/session** (changed): `FromAgent(sess, id, created string) *SessionData` + `ApplyTo(d, sess)` helpers
  shared by the TUI save/resume path and the headless runner (TUI-only fields stay TUI-filled).
- **internal/tui** (changed, R99): `Command` and `runSkill` pass `m.pastes.expand(text)` as `shown`; `sendQueue`
  adds one block per queued message with its placeholders expanded; `help.go` gains a headless section.
- **e2e** (new): `headless_test.go` drives the built binary (existing `cliBinary`/`runCLI`) against `providertest`.
