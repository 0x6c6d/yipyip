# T102: Global AGENTS.md reader and system prompt section

Phase 1 · Model: opus: reads a file outside the start directory into prompt content sent to the provider, with truncation and secret redaction (Consequential assumptions 3 and 5) · Depends-on: T101 · Covers: R109, R110, R111, R112, R12

## Brief
yip must put the user-wide instructions file `<cfg.GlobalDir>/AGENTS.md` (normally `~/.config/yipyip/AGENTS.md`)
into the system prompt, under the heading `# Global AGENTS.md`, directly before the project `# AGENTS.md`
section. `config.Config.GlobalDir string` already exists (set by `config.Load` to `<home>/.config/yipyip`;
`""` means no global file).

Current code, `internal/agent/prompt.go`: `buildSystemPrompt(startDir string, guard *tools.PathGuard, red *config.Redactor, webSearch bool) string`
appends `"\n\n# AGENTS.md\n" + red.Redact(notes)` when `readAgentsFile(guard)` returns content. `readAgentsFile`
resolves `AGENTS.md` with `guard.Resolve`, `os.Open`s it, checks `f.Stat()` is a regular file, reads at most
`maxAgentsChars*utf8.UTFMax` bytes, applies `strings.ToValidUTF8(…, "�")` and `truncateChars(…, maxAgentsChars)`
(30,000). Call sites: `NewSession` (`internal/agent/session.go`, ~line 152) and `(*Session).Reset` (~line 501),
both wrapped in `s.withAppend(...)`. `init.go` calls `readAgentsFile` for the `/init` prompt.

Change `internal/agent/prompt.go`:
- Split the reading into `readInstructions(path string) (string, bool)`: `os.Open(path)` (follows symlinks),
  `Stat` on the open file → regular files only, the same bounded read, `ToValidUTF8`, `truncateChars` 30,000.
  Any error → `("", false)`, silently (no log, no crash record).
- `readAgentsFile(guard)` keeps its exact behaviour and signature (PathGuard `Resolve`, then `readInstructions`);
  whitespace-only project files keep today's behaviour (do not add the whitespace rule to the project file).
- New `readGlobalAgentsFile(dir string) (string, bool)`: `dir == ""` → none; otherwise
  `readInstructions(filepath.Join(dir, AgentsFile))`; content that is empty or whitespace only
  (`strings.TrimSpace == ""`) → none. No PathGuard (the file is outside the start directory and only read).
- `buildSystemPrompt` gains a `globalDir string` parameter. Order: base prompt, then (if present)
  `"\n\n# Global AGENTS.md\n" + red.Redact(globalContent)`, then (if present) the existing
  `"\n\n# AGENTS.md\n" + red.Redact(projectContent)`. Truncate first, then redact (same as the project file).
  When no global file applies, the prompt is byte-identical to today's.
- Update both call sites in `session.go` to pass `cfg.GlobalDir` / `s.cfg.GlobalDir`, so a new session and
  `Reset` (`/new`, `/clear`) each read the file fresh. `--system-append` (`withAppend`) stays after both sections.
- Do not touch `init.go`: `/init` keeps embedding only the project file. Subagents already reuse `SystemPrompt()`.
- No new imports beyond `path/filepath` (no network, no exec).

Tests (new file `internal/agent/globalagents_test.go`, package `agent`; build sessions like
`newLoopSession(t, nil)` in `loop_test.go` does, then write files into `base.cfg.GlobalDir` or set
`cfg.GlobalDir` to a temp dir and call `NewSession(Options{Config: cfg, StartDir: dir})`). Note the prompt
contains the start dir path, so compare prompts of sessions sharing the same start dir. Top-level test names:
- `TestGlobalAgentsOrder`: global `GLOBAL-NOTE`, project `AGENTS.md` `PROJECT-NOTE` → both present,
  `"\n\n# Global AGENTS.md\n"` index < `"\n\n# AGENTS.md\n"` index; global-only case puts the section at the end.
- `TestGlobalAgentsAbsent`: subtests missing file, empty file, whitespace-only file, a directory named
  `AGENTS.md`, `GlobalDir == ""` → `SystemPrompt()` identical to the prompt without a global file.
- `TestGlobalAgentsTruncate`: 40,000-character global file → exactly 30,000 characters of it in the prompt;
  invalid UTF-8 bytes become U+FFFD.
- `TestGlobalAgentsRedact`: a value added to `cfg.Redactor` (e.g. `Redactor.Add("SEKRET-XYZ")`) inside the
  global file appears as `[redacted]`, never raw.
- `TestGlobalAgentsSymlink`: a symlink to a regular file is read; a dangling symlink adds nothing.
