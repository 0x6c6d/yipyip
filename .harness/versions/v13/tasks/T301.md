# T301: /help mentions the global AGENTS.md

Phase 3 · Model: haiku: one static help line, mechanically verifiable · Depends-on: T000 · Covers: R114

## Brief
yip reads a user-wide instructions file `~/.config/yipyip/AGENTS.md` (next to `config.json`) and puts it in the
system prompt before the project `AGENTS.md`. Tell the user where it lives in the help text.

Change `internal/tui/help.go`, function `HelpText()` (used by `/help` and `yip --help`): add a block after the
`Headless mode:` block and before `On exit:`, in the same style as the existing blocks:

```
Instructions:
  ~/.config/yipyip/AGENTS.md  global instructions for every project, added before the project AGENTS.md (/init never touches it)
```

Write it with `b.WriteString("\nInstructions:\n")` and one `b.WriteString("  ...\n")` line. Do not change the
command table or the keys. If an existing test in `internal/tui` pins the exact help text, update that expectation
(`cmd/yip` must stay unchanged; if a test there breaks, stop and report it). Always add `TestHelpGlobalAgents` in a new file `internal/tui/help_v13_test.go` asserting `HelpText()`
contains `~/.config/yipyip/AGENTS.md` and `global`, and that the `Instructions:` block comes before `On exit:`.

## Verification
`.harness/verify/v13/T301.sh` exits 0. It checks the help text through `HelpText()` and the built binary's
`--help`, runs the `internal/tui` tests, and (negative) fails if the `/init` command entry stopped saying it writes
the project `AGENTS.md` or if `internal/provider`, `internal/tools` or `cmd/yip` changed.
