# T201: e2e: TUI, headless and subagent requests carry the global note

Phase 2 · Model: sonnet: e2e tests on existing helpers, moderate judgment · Depends-on: T102 · Covers: R109, R111

## Brief
yip now reads the user-wide file `$HOME/.config/yipyip/AGENTS.md` (the directory of the global `config.json`,
exposed as `config.Config.GlobalDir` by `config.Load`) when a session is created and puts it into the system
prompt as a `# Global AGENTS.md` section before the project `# AGENTS.md` section. Reading it needs no approval
and works in `yip -p` too. Prove this end to end against the fake provider.

Files:
- `e2e/helpers_test.go`: add a field to `envOpts`, e.g. `globalAgents string // content of $HOME/.config/yipyip/AGENTS.md, "" = none`;
  in `newEnvServer`, write it to `filepath.Join(home, ".config", "yipyip", "AGENTS.md")` after the config dir is
  created and BEFORE `config.Load` / `agent.NewSession`. No other helper behaviour changes (existing tests keep
  passing untouched).
- New `e2e/globalagents_test.go` (package `e2e`) with top-level tests:
  - `TestGlobalAgentsTUI`: `newEnvServer(t, providertest.New(resp{Text: "ok"}), envOpts{contextLimit: 8000, globalAgents: "GLOBAL-E2E-NOTE\n"})`,
    also write a project `AGENTS.md` `PROJECT-E2E-NOTE` in the start dir before the session is built (or add a
    second opts field for it); submit a prompt with `e.submit`; the first request's `Messages[0]` is role `system`
    and contains `GLOBAL-E2E-NOTE`, with `# Global AGENTS.md` before `# AGENTS.md` / `PROJECT-E2E-NOTE`.
    Mode stays auto as the helper sets; no approval prompt appears in `e.Model.View()`.
  - `TestGlobalAgentsHeadless`: `srv := providertest.New(resp{Text: "ok"})`, `home, dir := headlessDirs(t, srv)`,
    write `home/.config/yipyip/AGENTS.md` = `GLOBAL-HEADLESS-NOTE`, run
    `runYip(t, home, dir, "", headlessEnv, "-p", "hello")`; exit code 0; the first request's system message
    contains `GLOBAL-HEADLESS-NOTE`; run it a second time with `--mode manual`
    (it must still exit 0 without any approval, since reading the file is not a tool call); `checkNoSecret`.
  - `TestGlobalAgentsSubagent`: TUI env with `globalAgents: "GLOBAL-SUB-E2E\n"`; the fake provider first answers
    with a `spawn_agent` tool call (`providertest.ToolCall{ID: "s1", Name: "spawn_agent", Arguments: `{"task":"sub task"}`}`),
    then text responses (use a response function, as `e2e/headless_limits_test.go` does, if order matters);
    find the request whose user message is `sub task`: its system message contains `GLOBAL-SUB-E2E`.
  - `TestGlobalAgentsAbsentE2E`: no global file → the system message contains no `# Global AGENTS.md`.

Use the existing helpers (`resp`, `call`, `mustContain`, `runYip`, `headlessDirs`, `headlessEnv`,
`e.Server.Requests()`); look at `e2e/init_test.go`, `e2e/headless_test.go`, `e2e/headless_limits_test.go`.
Do not change production code; if a test exposes a bug, report it instead of working around it.

## Verification
`.harness/verify/v13/T201.sh` exits 0. It runs the four named e2e tests and the whole e2e suite, and (negative)
fails if the e2e code sets `GlobalDir` directly instead of going through `HOME`, or if `internal/provider`,
`internal/tools` or `cmd/yip` changed since the v13 baseline.
