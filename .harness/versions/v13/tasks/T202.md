# T202: e2e: /new re-read and /init leaves the global file alone

Phase 2 · Model: sonnet: e2e tests on existing helpers, moderate judgment · Depends-on: T201 · Covers: R112, R113, R12

## Brief
yip reads the user-wide file `$HOME/.config/yipyip/AGENTS.md` when a session is created and when the system
prompt is rebuilt (`/new` opens a fresh session in a new tab, `/clear` resets the tab's session); it is not
watched. `/init` stays project-only: its user prompt embeds only the project `AGENTS.md`, it never reads or writes
the global file, but it runs under the normal system prompt, which carries the `# Global AGENTS.md` section.

The e2e helper `newEnvServer` (`e2e/helpers_test.go`) has an `envOpts.globalAgents` field that writes
`$HOME/.config/yipyip/AGENTS.md` before the session is built; `env.Home` is the temp HOME. Add tests to the
existing file `e2e/globalagents_test.go` (package `e2e`; create it if missing):

- `TestGlobalAgentsNew`: env with `globalAgents: "GLOBAL-V1\n"` and enough fake responses (`resp{Text: ...}`);
  submit a prompt → that request's system message has `GLOBAL-V1`; overwrite the file with `GLOBAL-V2`; submit
  another prompt in the same session → its system message still has `GLOBAL-V1` (not watched); run `/new` with
  `e.submit(t, "/new")`, then submit a prompt in the new tab → the latest request's system message contains
  `GLOBAL-V2` and not `GLOBAL-V1`.
- `TestGlobalAgentsClear`: the same with `/clear` instead of `/new`.
- `TestGlobalAgentsInit`: env with `globalAgents: "GLOBAL-INIT-E2E\n"` and a project `AGENTS.md` containing
  `PROJECT-INIT-E2E` (written before `/init`); fake responses: one `write_file` tool call for `AGENTS.md`, then
  text (see `e2e/init_test.go`). Before `/init`, snapshot every entry under `filepath.Join(e.Home, ".config", "yipyip")`
  (relative path, size, mode, mtime, content); run `e.submit(t, "/init")`; the `/init` request's user message
  contains `PROJECT-INIT-E2E` and does NOT contain `GLOBAL-INIT-E2E`; its system message contains
  `GLOBAL-INIT-E2E`; the snapshot after `/init` equals the one before (no file created, changed or removed).

Use only the existing helpers and the fake provider (`e.Server.Requests()`); no production code changes. If a
test exposes a real bug, report it instead of working around it.

## Verification
`.harness/verify/v13/T202.sh` exits 0. It runs the three named e2e tests and the whole e2e suite, and (negative)
fails if the e2e code sets `GlobalDir` directly instead of going through `HOME`, if `init.go` references the
global reader, or if `internal/provider`, `internal/tools` or `cmd/yip` changed.
