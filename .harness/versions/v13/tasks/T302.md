## Brief
Update the repo-root `README.md` (public-facing; never mention `.harness/`, loops, plans or tasks) for one new

The behaviour (take it from the code: `internal/agent/prompt.go`, `internal/config/config.go`, `internal/tui/help.go`):
- yip reads a user-wide instructions file `~/.config/yipyip/AGENTS.md` (the same directory as `config.json`
  and `skills/`, i.e. `$HOME/.config/yipyip`; `XDG_CONFIG_HOME` is not used).
- Its content goes into the system prompt of the main agent and of subagents under `# Global AGENTS.md`, placed
  before the project `AGENTS.md` from the start directory (so project instructions come later and win on conflict).
  In the UI and in headless mode (`yip -p`); no approval needed.
- Each file is cut to 30,000 characters; configured secret values are redacted.
- A missing, empty or whitespace-only file, or a path that is not a regular file (symlinks to a regular file are
  followed) adds nothing and is not an error.
- It is read when a session starts and again on `/new` and `/clear`; it is not watched.
- `/init` never reads or writes the global file; it only writes the project `AGENTS.md`.
