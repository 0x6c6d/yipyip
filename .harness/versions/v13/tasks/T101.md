# T101: Config.GlobalDir set by config.Load

Phase 1 · Model: opus: decides the config-dir lookup (Consequential assumption 1, R111) that controls which file enters the prompt · Depends-on: T000 · Covers: R111

## Brief
Add the directory that holds the global `config.json` to the loaded config, so the agent can find the
user-wide `AGENTS.md` next to it (`~/.config/yipyip/AGENTS.md`).

Change `internal/config/config.go`:
- Add the field `GlobalDir string` to `type Config` with a comment like
  `// directory of the global config.json (<home>/.config/yipyip); "" = no global files`.
- In `Load(home, startDir string, getenv func(string) string)`, set
  `GlobalDir: filepath.Dir(GlobalPath(home))` on the returned config. `home` is the value the callers already
  pass (`os.UserHomeDir()`, i.e. `$HOME`). Do NOT consult `XDG_CONFIG_HOME` or any other environment variable:
  the directory is exactly the one `GlobalPath(home)` uses today (`<home>/.config/yipyip`).
- Set it also when the global `config.json` is missing (a missing file counts as empty; the dir is still the
  place to look). If `home` is `""`, leave `GlobalDir` as `""` (no global file is looked up).
- Optional: a helper `GlobalAgentsPath(home string) string` returning `filepath.Join(home, ".config", "yipyip", "AGENTS.md")`.
- No other behaviour of `Load` changes; no file is created or read for this field.

Tests (new file `internal/config/globaldir_test.go`, package `config`):
- `TestLoadGlobalDir`: temp home with a `config.json`; `Load` → `cfg.GlobalDir == filepath.Join(home, ".config", "yipyip")`.
- `TestLoadGlobalDirMissingConfig`: temp home without any config file → same `GlobalDir`, no error, and the
  directory is not created by `Load`.
- `TestLoadGlobalDirIgnoresXDG`: `getenv` returns `/elsewhere` for `XDG_CONFIG_HOME` → `GlobalDir` is still
  `<home>/.config/yipyip`.

## Verification
`.harness/verify/v13/T101.sh` exits 0. It runs the three named tests, checks the exported field exists, runs a
supervisor probe that loads a config with `XDG_CONFIG_HOME` set and a missing config file, and (negative) fails
if `XDG_CONFIG_HOME` appears in `config.go` or if `internal/provider`, `internal/tools`, `cmd/yip` changed.
