# Plan v13: global AGENTS.md

_Source: `.harness/versions/v13/spec.md`, 2026-11-07. Core plan: `.harness/Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R109–R115, changed R12: read `~/.config/yipyip/AGENTS.md` into the system prompt
(main agent + subagents, TUI + `yip -p`) as `# Global AGENTS.md` before the project `# AGENTS.md`; 30,000-char cap,
redaction; re-read on session create and `Reset` (`/new`, `/clear`); `/init` stays project-only; `/help` + README.
**Explicitly deferred:** hierarchical/parent-dir lookup, `@file` imports, `CLAUDE.md` fallback, `/memory` or any
edit/create command, `~/.yipyip/`, file watching (spec §7).

## Architecture changes
- **internal/config** (changed): `Config.GlobalDir string`, set by `Load` to `filepath.Dir(GlobalPath(home))`
  (`<home>/.config/yipyip`); new `GlobalAgentsPath(home)` helper optional. No other config change.
- **internal/agent/prompt.go** (changed): the existing reader is split into `readInstructions(path)` (open, `Stat` on
  the fd → regular only, read ≤ 30,000×4 bytes, `ToValidUTF8`, `truncateChars` 30,000; empty/whitespace-only → none)
  used by the project reader (path via PathGuard `Resolve`, unchanged) and a new `readGlobalAgentsFile(dir)`
  (plain `os.Open(filepath.Join(dir, "AGENTS.md"))`, empty dir → none). `buildSystemPrompt` gains the global dir
  and appends `\n\n# Global AGENTS.md\n<redacted>` before `\n\n# AGENTS.md\n…`. Both call sites (`NewSession`,
  `Reset`) pass `cfg.GlobalDir`; subagents keep using `SystemPrompt()` (`agenttools.go`), so they inherit it.
- **internal/agent/init.go**: unchanged; it keeps embedding only `readAgentsFile` (project). A test pins this.
- **internal/tui/help.go**, **README.md**: document the file. **e2e**: new `globalagents_test.go`.
- No change to `cmd/yip`: `config.Load(home, …)` already receives `os.UserHomeDir()` in TUI and headless paths.
