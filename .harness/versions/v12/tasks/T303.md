# T303: TUI quit shutdown and SIGTERM/SIGHUP handling

Phase 3 · Model: opus: signal handling and exit ordering of the TUI, save-then-kill (Consequential assumption 5) · Depends-on: T301, T302 · Covers: R104a, R104d, R105, R106

## Brief
Already in place: `cmd/yip/main.go` `run` calls `tools.InitSubreaper()` and, as its first defer, `exitCleanup()`
(= `tools.KillAll(2 * time.Second)`), so after `launchUI` returns every leftover process yip started is reaped.
`internal/agent` exports `(*Session).Shutdown()` (cancels the running turn and every subagent, no wait).
Missing: the TUI does not cancel subagents at quit, and SIGTERM/SIGHUP (terminal closed, `kill <pid>`) are
handled by Bubble Tea's default handler, which does not save the session.

### Files
- `internal/tui/model.go`: `func (m Model) quit() tea.Cmd` additionally calls `Shutdown()` on the session of every
  open tab (skip nil sessions) before returning `tea.Quit`. Every existing quit path (Ctrl+C twice, Ctrl+D,
  `/quit`, `/exit`, the resume picker) goes through `quit()`.
- `internal/tui` (e.g. `model.go` or a new `signal.go`): exported `type SignalQuitMsg struct{}`; `Update` handles it
  exactly like `/quit`: `m = m.saveTabs()` then `return m, m.quit()`.
- `cmd/yip/main.go` `launchUI`: create the program with `tea.WithoutSignalHandler()` in addition to the existing
  options; before `p.Run()` install `signal.Notify(ch, syscall.SIGTERM, syscall.SIGHUP)` and a goroutine that, on
  the first signal, calls `p.Send(tui.SignalQuitMsg{})` and starts a 3 s fallback timer that calls `p.Kill()` if
  `Run` has not returned yet; `signal.Stop(ch)` when `Run` returns. Ctrl+C stays a key (raw mode), not a signal.
  `launchWith` and its error mapping are unchanged. Do not call `KillAll` here (`exitCleanup` in `run` does it
  after `launchUI` returns).
- Tests: `internal/tui/shutdown_test.go` and `e2e/cleanup_tui_test.go`.

### Tests (exact names)
- `internal/tui`: `TestQuitShutsDownSessions`: a model with two tabs whose sessions each run a turn (fake provider
  with a long `Delay`); `quit()` (e.g. via `/quit`) → both turns end (`Wait` returns within 3 s).
  `TestSignalQuitMsgSaves`: sending `SignalQuitMsg{}` to a model with a non-empty conversation saves the tab
  (use the existing save seam of `internal/tui/exit_save_test.go`) and returns a quit command.
- `e2e`: run the built binary (`cliBinary(t)`, `Dir` = start dir, `Env` with `PATH`, `HOME` and `headlessEnv` as
  the headless tests do, config via `headlessDirs(t, srv)`) without a pty: stdin is a pipe
  (`cmd.StdinPipe()`), stdout/stderr buffers. The fake provider's first reply is a `bash` call
  `setsid sleep 3051 >/dev/null 2>&1 & sleep 3051 >/dev/null 2>&1 & echo started > started.txt`, then `Text: "done"`.
  Type a prompt and Enter (`"go\r"`), wait until `started.txt` exists and the fake got its second request.
  Find sleeps by exact `/proc/*/cmdline`; gone = no `/proc/<pid>` or state `Z`; SIGKILL leftovers in `t.Cleanup`;
  every wait has a timeout so the test never hangs.
  - `TestCleanupTUIQuit`: write `"/quit\r"` → yip exits 0 within 5 s; no `sleep 3051` left.
  - `TestCleanupTUICtrlC`: write `"\x03\x03"` (Ctrl+C twice) → exits within 5 s; no `sleep 3052` left (use 3052 in
    its command).
  - `TestCleanupTUISigterm`: send SIGTERM to the yip process → it exits within 2.5 s after the signal, a session
    file exists under `<dir>/.yipyip/sessions/`, and no `sleep 3053` is left.
  - `TestCleanupTUISighup`: same with SIGHUP and `sleep 3054` (session saved, none left).
**Row fixed (pty):** Bubble Tea v1.3.10 cannot run without a terminal (it opens `/dev/tty` and exits with
"could not open a new TTY"), so a pipe-only run is impossible. The e2e tests therefore give yip a pty as its
controlling terminal, stdlib only and in test code only (no product change, no new module): open `/dev/ptmx`,
unlock it (`TIOCSPTLCK` = 0 via `syscall.Syscall(SYS_IOCTL, ...)`), get the number (`TIOCGPTN`), open
`/dev/pts/<n>`, and start the binary with `cmd.Stdin/Stdout/Stderr` = the slave and
`SysProcAttr{Setsid: true, Setctty: true}` (Ctty = 0). Type keys by writing to the master; drain the master in a
goroutine so yip never blocks on output. Signals are sent to the yip process directly (`cmd.Process.Signal`).
Put the pty helper in `e2e/cleanup_tui_test.go`. Do not fake the tests.
