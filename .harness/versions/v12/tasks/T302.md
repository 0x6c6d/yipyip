# T302: cmd/yip exit cleanup, headless and crash paths

Phase 3 · Model: opus: exit-path wiring of the reaper, signal handling, crash ordering (Risk: v12 reaper + exit paths) · Depends-on: T201, T301 · Covers: R103, R104b, R104c, R105

## Brief
`internal/tools` exports `InitSubreaper()` (sets `PR_SET_CHILD_SUBREAPER` so daemonizing children are
re-parented to yip) and `KillAll(grace time.Duration)` (SIGTERM every process started through `tools.BashRunner`
plus escaped descendants, wait up to `grace`, then SIGKILL; returns at once when nothing is left).
`internal/agent` exports `(*Session).Shutdown()` (cancels the running turn and all subagents, no wait).
Wire them into the binary so every exit of `yip` reaps, and test the headless and crash paths end to end.

### Files
- `cmd/yip/main.go`: in `run` (not `runWith`, so unit tests of `runWith` never reap the test process's
  children) call `tools.InitSubreaper()` first, then `defer exitCleanup()` as its first defer, where
  exactly this one line: `var exitCleanup = func() { tools.KillAll(2 * time.Second) }` (a package var so tests can swap it; no other
  `KillAll` call in `cmd/yip`). Because
  `runWith` recovers panics in its own deferred `crashExit` (exit code 2, crash record written) and the TUI/headless
  runs return before it, `exitCleanup` runs after the session save and after the crash record, on every
  return path of `run`. `main` stays `os.Exit(run(...))`.
- `cmd/yip/headless.go`: add `syscall.SIGHUP` to the existing `signal.NotifyContext(..., os.Interrupt, syscall.SIGTERM)`
  (same handling: cancel, exit 1, "yip: interrupted"). At the end of `runner.run` (every return after the turn
  was submitted) call `sess.Shutdown()` so running subagents are cancelled before `exitCleanup`. Right after
  `r.consumeTurn(evCtx)` returns add `forcePanic("headless-end")` (the existing test-only seam in
  `cmd/yip/crash.go`; empty `testPanic` in the shipped binary means no effect).
- New `e2e/cleanup_test.go` (package `e2e`). Use the existing helpers: `headlessDirs(t, srv)`,
  `runYip(t, home, dir, stdin, headlessEnv, args...)`, `crashBinary(t, mode)`, `runBinary(t, bin, home, dir, headlessEnv, args...)`,
  `cliBinary(t)`, `providertest.New(...)` with `providertest.Response{ToolCalls: []providertest.ToolCall{{ID: "c1", Name: "bash", Arguments: ...}}}`
  and `Response{Text: ..., Delay: ...}`. The bash command is e.g.
  `setsid sleep 3041 >/dev/null 2>&1 & sleep 3041 >/dev/null 2>&1 & echo started > started.txt` (one setsid escapee and
  one in the group; `started.txt` in the start dir proves it ran). Find sleeps by exact `/proc/*/cmdline`
  (`sleep\x003041\x00`), gone = no `/proc/<pid>` or state `Z`, SIGKILL leftovers in `t.Cleanup`.
- Nothing in `internal/tui` (a later task handles TUI signals).

### Tests (exact names, in `e2e/cleanup_test.go`)
- `TestCleanupHeadless`: bash turn then `Text: "done"`; `yip -p go` exits 0; `started.txt` exists; both sleeps
  gone within 200 ms after yip exited.
- `TestCleanupHeadlessTimeout`: bash turn, then a reply with `Delay: 30*time.Second`; `--timeout 2s` → exit 4,
  sleeps gone.
- `TestCleanupHeadlessMaxCalls`: bash turn, then a second reply; `--max-model-calls 1` → exit 5, sleeps gone.
- `TestCleanupHeadlessSignal`: bash turn, then a reply with `Delay: 30*time.Second`; start the built binary with
  `exec.Command(cliBinary(t), "-p", "go")` (Dir, Env as `runYip` does), wait until `started.txt` exists, send
  SIGHUP → exit 1 within 5 s, sleeps gone.
- `TestCleanupCrash`: `crashBinary(t, "headless-end")`, bash turn then `Text: "done"`; exit 2,
  `<dir>/.yipyip/crash.log` exists, sleeps gone.
- `TestCleanupOutsider`: a `sleep 3049` started by the test itself (not by yip) is still alive after a
  `yip -p` run (yip never kills what it did not start).
