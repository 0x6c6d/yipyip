# T301: agent Session.Shutdown

Phase 3 · Model: opus: turn and subagent cancellation (concurrency) on the exit path · Depends-on: T101 · Covers: R101, R106

## Brief
At exit yip must first cancel what is running (main turn and all subagents), then reap leftover processes
with `tools.KillAll(grace)` (exported by `internal/tools`; it SIGTERMs, waits up to `grace`, then SIGKILLs every
process group started by `tools.BashRunner`, which main agent and subagents share). This task adds the
cancel step to the agent and proves the combination.

### Files
- `internal/agent/loop.go` or `internal/agent/session.go`: add `func (s *Session) Shutdown()`.
- New test file `internal/agent/shutdown_test.go`.
No other files. Do not call `tools.KillAll` from non-test code in `internal/agent` (the callers in `cmd/yip`
and `internal/tui` do it at exit).

### `Session.Shutdown()` (exported, exact name)
- Cancels the running turn (as `Session.Cancel` does) and cancels every running subagent of the current
  subagent manager (`s.subs.CancelAll()`, taken under `s.mu`). A running `bash` command is then killed by
  `BashRunner`'s existing cancel path (unchanged).
- Does not wait for the turn or the subagents to finish (the caller bounds the exit delay).
- Idempotent and safe to call concurrently, when idle, and on a session that never ran a turn (no panic,
  returns at once).

### Tests (`internal/agent/shutdown_test.go`, exact names; no `t.Parallel`)
Build sessions like the existing subagent tests in `internal/agent/subagent_test.go` (`newSubSession`,
`providertest.NewFunc`, `isSub(req)`, `countTools(req)`, `spawn_agent`/`wait_agent` tool calls; auto mode via
`s.SetMode(ModeAuto)`). Use unique sleep durations, detect processes via `/proc/*/cmdline` (gone = no
`/proc/<pid>` or state `Z`), SIGKILL leftovers in `t.Cleanup`.
- `TestShutdownReapsMainAndSubagent`: the main agent's first reply calls `bash` with
  `sleep 3031 >/dev/null 2>&1 &` and `spawn_agent`; the subagent calls `bash` with `sleep 3032 >/dev/null 2>&1 &`
  and then hangs (fake response with a long `Delay`), and the main agent calls `wait_agent`. Once both sleeps
  are alive: `s.Shutdown()`, then `tools.KillAll(2*time.Second)` → both sleeps gone; the turn ends
  (`s.Wait()` returns within 3 s).
- `TestShutdownForegroundCommand`: the main agent runs `bash` `sleep 3033` (foreground); once it is alive,
  `s.Shutdown()` alone (no `KillAll`) kills it within 2 s (R106, existing cancel kill).
- `TestShutdownIdempotent`: `Shutdown()` on a fresh idle session returns at once, twice; concurrent calls
  from 4 goroutines during a running turn do not race (`go test -race`).
