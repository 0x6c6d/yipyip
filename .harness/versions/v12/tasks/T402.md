# T402: /help cleanup line

Phase 4 · Model: haiku: one help line plus one test · Depends-on: T000 · Covers: R108

## Brief
yip terminates every process its commands started when it exits (after a 2 s grace). Document this in the help
text. In `internal/tui/help.go`, `HelpText()` (used by `/help` and by `yip --help`) ends with a "Headless mode:"
block. Append after it a block:

```text

On exit:
  processes started by commands (also background jobs and servers) are terminated after a 2 s grace
```

i.e. `b.WriteString("\nOn exit:\n")` and `b.WriteString("  processes started by commands (also background jobs and servers) are terminated after a 2 s grace\n")`.
Add the test `TestHelpExitCleanup` in a new file `internal/tui/help_v12_test.go` asserting that `HelpText()`
contains the line `processes started by commands (also background jobs and servers) are terminated after a 2 s grace`
and the heading `On exit:`. Existing help tests must keep passing. Change nothing else.

## Verification
`.harness/verify/v12/T402.sh` exits 0. It runs `TestHelpExitCleanup` and all `Help` tests, checks that
`yip --help` prints the line, and (negative) that the line appears only once.
