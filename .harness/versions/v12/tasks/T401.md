# T401: System prompt exit sentence

Phase 4 · Model: haiku: one fixed sentence plus one test, mechanically verifiable · Depends-on: T000 · Covers: R107

## Brief
yip terminates every process its `bash` commands started when it exits, so the model must not expect
long-lived servers to survive. Add exactly this sentence to the agent system prompt built by
`buildSystemPrompt` in `internal/agent/prompt.go`, as one Go string literal (not split across literals),
unconditionally (with and without web search, AGENTS.md, etc.), placed with the other tool-usage rules:

```text
Processes still running when yip exits (including background jobs and servers) are terminated, so do not expect them to survive the session.
```

Add the test `TestPromptExitCleanup` in a new file `internal/agent/prompt_v12_test.go`: build a session the way
`internal/agent/prompt_v6_test.go` does (`providertest.New()`, `newLoopSession(t, srv)`), and assert that
`s.SystemPrompt()` contains the sentence exactly once. Change nothing else.

## Verification
`.harness/verify/v12/T401.sh` exits 0. It runs `TestPromptExitCleanup` and the existing `Prompt` tests, greps
the exact sentence in `internal/agent/prompt.go`, and checks (negative) that the sentence is not duplicated.
