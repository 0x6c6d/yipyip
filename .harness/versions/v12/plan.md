# Plan v12: no leftover processes after exit

_Source: `.harness/versions/v12/spec.md`, 2026-11-06. Core plan: `.harness/Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R101–R108: process-wide tracker in `tools.BashRunner`, `tools.KillAll(grace)` reaper
(SIGTERM → poll ≤50 ms → SIGKILL), Linux `PR_SET_CHILD_SUBREAPER` + `/proc` descendant walk, `KillAll(2s)` on every
exit path (TUI quit, TUI SIGTERM/SIGHUP with save, headless incl. timeout/max-calls/question/signal, crash exit 2),
subagents cancelled before reaping, one system-prompt sentence, `/help` line, README section, CLAUDE.md notes.
**Explicitly deferred:** spec §7 (detach/`nohup` allow-list, `/jobs`, bash background mode, other yip instances,
non-Linux subreaper, cgroups/namespaces, cleanup after SIGKILL of yip), panics in non-Bubble-Tea goroutines that
kill the process without passing through `run` (uncatchable, no reaping).

## Architecture changes
- **new `internal/tools/reaper_linux.go`** (+ `reaper_other.go` `//go:build !linux`: groups only, no subreaper/walk):
  package-level tracker (mutex, `map[pgid]*entry{active bool}`), `track(pid)`/`untrack`, `InitSubreaper()`
  (`RawSyscall(SYS_PRCTL, PR_SET_CHILD_SUBREAPER=36, 1)`, error ignored), `KillAll(grace)` (serialised by a mutex;
  2nd call finds nothing → returns at once). Only `syscall`/`os`/`strconv`/`time`; security-critical like `bash.go`.
- **changed `internal/tools/bash.go`**: `Run` registers `cmd.Process.Pid` (= pgid) right after `Start` as active,
  marks it inactive after `Wait`; entry dropped when the group has no live member. Cancel/timeout kill unchanged.
- **new `agent.Session.Shutdown()`**: cancels the running turn and `CancelAll` subagents (no wait); idempotent.
- **changed `cmd/yip`**: `run` calls `tools.InitSubreaper()` first and registers, as its first defer (so it runs
  after `crashExit` set code 2 and after the session save), `exitCleanup()` = `tools.KillAll(2*time.Second)`;
  `launchUI` uses `tea.WithoutSignalHandler()` plus its own `signal.Notify(SIGTERM, SIGHUP)` → `p.Send(tui.SignalQuitMsg{})`,
  with a 3 s fallback `p.Kill()` if the program has not ended; headless keeps its SIGINT/SIGTERM context, adds SIGHUP.
- **changed `internal/tui`**: `quit()` calls `Shutdown()` on every tab session; `SignalQuitMsg` = `/quit` path
  (`saveTabs` then quit); `/help` gains one cleanup line.
- **changed `internal/agent/prompt.go`**: one sentence, exactly: `Processes still running when yip exits (including
  background jobs and servers) are terminated, so do not expect them to survive the session.`

## Build Phases
### Phase 0: Preflight
- **Checks:** `test "$(uname -s)" = Linux` · `test -r /proc/self/stat` · `command -v bash setsid sleep` ·
  `git status --porcelain` empty · `make check` (green baseline)
### Phase 1: Tracker + KillAll for tracked groups (walking skeleton)
- **Goal:** `sleep 300 &` via `BashRunner` is tracked and killed by `KillAll`; `run` calls it on exit.
- **Key deliverables:** `reaper_linux.go`/`reaper_other.go`, `bash.go` registration, `cmd/yip` `exitCleanup` defer.
- **Exit criterion:** `go test ./internal/tools -run 'TestReaper(Background|TermIgnored|Idempotent|ExitedGroup|Bystander|Timing)' -count=1`
### Phase 2: Escapees (subreaper, /proc walk, zombie reaping)
- **Goal:** `setsid sleep 300 &` and double-forks are killed; zombies never stall the grace poll.
- **Key deliverables:** `InitSubreaper`, descendant walk (Assumption 1), zombie reap (Assumption 3).
- **Exit criterion:** `go test ./internal/tools -run 'TestReaper(Setsid|Subreaper|DoubleFork|Zombie)' -count=1`
### Phase 3: Exit paths
- **Goal:** every exit path reaps after save; subagents cancelled first.
- **Key deliverables:** `Session.Shutdown`, TUI `quit()`/`SignalQuitMsg`, `launchUI` signals, headless SIGHUP, e2e tests.
- **Exit criterion:** `go test ./internal/agent -run TestShutdown -count=1 && go test ./e2e -run 'TestCleanup' -count=1`
### Phase 4: Prompt, help, docs
- **Goal:** R107, R108 and CLAUDE.md architecture notes.
- **Exit criterion:** `go test ./internal/agent -run Prompt && go test ./internal/tui -run Help && test "$(grep -ci background README.md)" -ge 1`
