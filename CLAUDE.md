# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

yipyip is a terminal UI coding assistant written in Go (Bubble Tea), in the style of Claude Code and opencode. It talks to OpenAI-compatible chat APIs, edits files and runs shell commands in its start directory, can spawn subagents, can read one web page with `web_fetch`, loads user skills (`/<name>`), reads the user-wide `~/.config/yipyip/AGENTS.md` into the system prompt before the project `AGENTS.md`, and runs in a manual (approval) or auto mode. Its network traffic is restricted to the configured provider hosts (plus, for `web_search` only, the Brave host while configured, and for an approved `web_fetch` call, the host of its URL). It reads files anywhere but writes only inside the start directory. `yip -p` runs one turn headless (no TUI) with an optional JSONL trace (`--json`) and exit codes 0–5. On every exit yip terminates the processes its commands started (SIGTERM, 2 s grace, SIGKILL; a Linux child subreaper catches `setsid`/double-fork escapees). The spec is `.harness/harness.md`.

## Commands

Go 1.27, GNU Make; the module is `yipyip`. Tests run offline against the `httptest` fake provider in `internal/provider/providertest`.

- Install deps: `go mod download` (only `proxy.golang.org` is contacted)
- Test all: `go test ./...`; end-to-end only: `go test ./e2e/...`
- Lint: `gofmt -l .` (must print nothing) and `go vet ./...`
- Build: `make build` (also builds `bin/yip`, with the version from git)
- Install the binary as `yip` into `$(go env GOBIN)` or `$(go env GOPATH)/bin`: `make install`
- Combined check, exits 0 only if healthy: `make check` (`gofmt -l .` must be empty, `go vet ./...`, `go test ./...`, `go build ./...`)

## Architecture

- `cmd/yip`: `main`, `--version` / `--help`, start-directory handling, runs the Bubble Tea program; `crash.go` crash handling (a panic writes a fatal record, prints one stderr line and exits 2; the test-only `testPanic` seam is set with `-ldflags "-X main.testPanic=<mode>"`, empty in the shipped binary); startup prune of the session store (`pruneSessions`, keeps the newest 25 and the `--resume` session); `headless_args.go` headless flags (usage errors exit 2); `headless.go` `runHeadless`: one turn without Bubble Tea, auto mode by default, `--answer`/`--approve` replies, `--timeout`/`--max-model-calls` exit 4/5, save at run end and prune, `--no-save`, `--dir`, overrides never write config; `headless_events.go` JSONL records (`type` first, redacted; `--transcript` via PathGuard `Resolve`); `main.go` `run` calls `tools.InitSubreaper()` and defers `exitCleanup` (`tools.KillAll(2 * time.Second)`) after save and crash record; headless also handles SIGHUP and the `headless-end` `testPanic` mode; `launchUI` uses `tea.WithoutSignalHandler()` and turns SIGTERM/SIGHUP into `tui.SignalQuitMsg` (3 s `p.Kill()` fallback)
- `internal/crashlog`: `crashlog.go` stdlib-only crash log in `<startdir>/.yipyip/crash.log` with injected `Resolve` and `Redact`; `Fatal` and `Recovered` records, capped at 1 MiB down to 512 KiB; package default set with `SetDefault`
- `internal/config`: `config.go` loads `~/.config/yipyip/config.json` merged key by key with `yipyip.json`, and sets `Config.GlobalDir` (directory of the global config.json, `<home>/.config/yipyip`, set by `Load`); `env.go` resolves `{env:NAME}`; `search.go` the optional `search` block (Brave `baseURL`, `apiKey`); `redact.go` holds every resolved secret value for redaction; `settings.go` writes model/effort/mode
- `internal/session`: `agent.go` `FromAgent`/`ApplyTo`, shared by the TUI and the headless runner; `store.go` Store with Save/Load/List/Delete/`Prune` for `SessionData` (`session.go`; `Prune` keeps the newest files and deletes only valid session files, never the protected ones); atomic writes, confined to `<startdir>/.yipyip/sessions`; id = first 3 bytes of the SHA-256 of the content, as 12 hex chars
- `internal/provider`: `client.go` OpenAI-compatible streaming client, retrying failures before the first SSE byte; `sse.go` own SSE parser; `transport.go` host-restricted HTTP transport (the only place that builds HTTP clients); `NewSearchHTTPClient` is a separate search-only client (only the `search.baseURL` host, 20 s); `NewFetchHTTPClient(FetchOptions)` is a separate `web_fetch`-only client (any host, dial-time IP check refusing loopback/private/link-local/unspecified/multicast addresses, at most 5 re-checked redirects, 20 s, no cookie jar, no `Authorization`, `User-Agent: yipyip`; `ValidateFetchURL`); `search.go` Brave search client; `providertest/` httptest fake provider, fake Brave endpoint (`brave.go`) used by tests
- `internal/agent`: `session.go` session state and modes, `Options.SystemAppend` (appended to the system prompt), `Options.MaxModelCalls` (one counter shared by the main agent and subagents, `ErrModelCallLimit`, `ModelCalls()`), `ToolNames()`; `Session.Shutdown()` (cancel turn and subagents, no wait); `loop.go` agent loop (no model-call limit per main turn, 500 per subagent run); `approval.go` the approval gate shared by main agent and subagents (it also gates `web_fetch`; `agent.Options.FetchClient` is the test seam); `subagent.go` subagent manager (recovered subagent panics are logged with `crashlog`); `loop.go` also emits `EvCheckpoint` after each completed model round, so a turn that later panics keeps the rounds before it; `compact.go` compaction; `undo.go` per-turn file journal; `prompt.go` system prompt (`readInstructions`: regular file, 30,000 characters, invalid UTF-8 replaced; project `readAgentsFile` via PathGuard and global `readGlobalAgentsFile` via plain open under `GlobalDir`, empty or whitespace-only ignored; `# Global AGENTS.md` before `# AGENTS.md`, both redacted; re-read on `NewSession`/`Reset`; `/init` embeds only the project file); `init.go` `/init`; `question.go` question gate and tool
- `internal/skills`: `skills.go` loader for `<name>/SKILL.md` skill folders in `~/.config/yipyip/skills` and `<startdir>/.yipyip/skills` (project wins)
- `internal/tools`: `registry.go` tool registry; `files.go` `read_file`, `write_file`, `edit_file`; `search.go` `glob` (own `**`) and `grep`; `bash.go` `bash` (the only `os/exec` importer; `BashRunner.Run` fills the process tracker); `reaper.go`, `reaper_linux.go`, `reaper_other.go` process reaping: `InitSubreaper()` (Linux child subreaper, no-op elsewhere) and `KillAll(grace)` (kill set = live tracked groups plus escaped descendants found by the `/proc` walk; SIGTERM, grace, SIGKILL; zombies reaped per pid, never `Wait4(-1)`); `bash.go` and the reaper are the only places that start or signal processes; `websearch.go` gated `web_search` (registered only with a `search` block); `webfetch.go` gated `web_fetch` (always registered; 1 MiB read, 20,000 characters, untrusted-content marker); `htmltext.go` stdlib HTML-to-text converter; the web-like name guard in `registry.go` exempts exactly `web_search` and `web_fetch`; `pathguard.go` path resolution: `Resolve` confines writes to the start directory, `ResolveRead` lets `read_file`/`glob`/`grep` read anywhere
- `internal/tui`: `model.go` Bubble Tea model and keys; `commands.go` slash-command dispatcher; `help.go` `/help` text; `status.go` status line; `agents.go` subagent panel; `approval.go` approval prompt (shows the `web_search` query and the `web_fetch` URL); `blocks.go` and `highlight.go` conversation rendering; `markdown.go` own stdlib-only markdown renderer for assistant blocks (`renderMarkdown`: tables with box borders that wrap to the width, headings, lists, quotes, rules, links, inline styles; fences via `Highlight`; applied after redaction, falls back to the redacted source when a render would join a secret); `turn.go` turn clock, `Thinking…` line and finished marker; `subagents.go` live subagent blocks; `input.go` suggestions, history, paste placeholders and the queue; `mouse.go` wheel scrolling, copy-on-select and input click/select (`inputmouse.go`); `clipboard.go` clipboard writer (OSC 52 + `atotto/clipboard`, the only exec besides `bash.go`: fixed `wl-copy`/`xclip`/`xsel`, text via stdin, only redacted view text); `resume.go` `--resume` picker and restore, `sessions.go` `/sessions`, `tabs.go` tabs and `resetTab` (`/clear` empties the current tab in place; closing the last tab leaves one fresh empty tab, unsaved, no quit), `tabbar.go` tab bar with `×`/`+` hit zones, `tabclick.go` tab bar clicks, `tabkeys.go` swallows the removed tab hotkeys (only `Ctrl+T`/`Ctrl+W` remain), `question.go` inline question in the transcript, `settings.go` settings saves, `skills.go` `/skills`, skill dispatch and `IsBuiltinCommand` (used by the headless runner); submitted and queued lines show pastes expanded (`pasteStore.expand`), `save.go` session save on exit (tabs: up to 8, per-tab state, global model/effort/mode); `autosave.go` checkpoint and turn-end autosaves per tab (at most one a minute for checkpoints, a bounded exit wait, retention prune of 25 sessions protecting the open tabs); `crashguard.go` `Guard` wraps the model so a panic in Init, Update, View or their commands is recorded with `crashlog` and re-panicked; `blocks.go` `renderBlock` recovers a render panic, logs it and shows one error line in place of that block; `model.go` `quit()` shuts down every tab session; `SignalQuitMsg` saves like `/quit`; `help.go` has the "On exit" line
- `e2e`: end-to-end tests (`/init`, `/compact`, `/undo`, CLI, secrets, `Session`, `Question`, `Retry`, `Skill`, `WebFetch`, `Markdown`, `Crash`, `Autosave`, `Retention`, `Headless`, `Cleanup`, `GlobalAgents`) against the fake provider

Security-critical logic lives only in `internal/provider/transport.go`, `internal/tools/pathguard.go`, `internal/tools/bash.go`, `internal/agent/approval.go`, `internal/config/redact.go`, `internal/crashlog` (crash record writing) and `internal/tools/reaper*.go` (process reaping); other code calls these and never re-implements them. Non-test code never uses `http.DefaultClient`, `http.DefaultTransport` or `http.Get`/`Post`/`Head`.

## Delegation workflow: supervise, don't implement

For non-trivial implementation work, use the supervisor/worker loop (`/loop-coding`, full procedure in `.claude/skills/loop-coding/SKILL.md`) instead of implementing directly:

- Project flow, per version `vN`: spec (`.harness/harness.md` for v1, `.harness/versions/vN/spec.md` for later versions, written with `.harness/prompts/new-version.md`) → `.harness/prompts/generate-plan.md` → `.harness/versions/vN/plan.md` (+ the core `.harness/Plan.md`) → `.harness/prompts/generate-tasks.md` → `.harness/versions/vN/Tasks.md` (small index) + `.harness/versions/vN/tasks/<ID>.md` (brief) + `.harness/verify/vN/<ID>.sh` (verification) → loop runs the index row by row and reads a task file only when it dispatches that task; it never reads the folders of other versions.
- Done = a verification script that exits 0, never "looks right"; workers never touch the spec, prompts, skill or this section (the supervisor checks the diff).
- One fresh worker per task, `model` per task (haiku / sonnet / opus); the supervisor verifies and commits itself and never trusts the worker's report.
- Fail → concrete feedback to the same worker; still failing after 3 rounds → `blocked` and ask the user.
